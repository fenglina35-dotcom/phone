# v1364（网页）引用框不撑宽气泡、抖音群单独/合并调用

仅网页；私人包仍是 v1363 / iOS 1.0.423。

## 用户反馈
群里带引用的消息，对方的气泡被拉得和下面的引用框一样宽，空出一大块；抖音群也想像微信角色群一样设置谁单独调用、谁合并调用。

## 原因与改动
- 对方消息的 `.col` 是纵向 flex、默认 stretch，气泡跟着最宽的子元素（引用框）变宽。加 `.msg.them>.col>.bubble{align-self:flex-start}`，气泡按自己的字宽。我这边的消息本来就是 flex-end，不受影响。
- 抖音群聊天信息页加「模型调用」一行：每个成员（角色和网友）都能切「单独 / 合并」。没设置过仍是角色单独、网友合并。合并的人（包括合并进来的角色）一次请求一起写；合并请求里的角色按本名或备注都能认回来。

## 验证
浏览器：引用消息气泡宽度回到文字宽；抖音群三种设置下请求分组正确（默认、角色合并、网友单独）。
