# v1386 记得自己的生日

角色推荐名片、我加了那个人以后，ta不记得自己的生日：生日存在原来的人物卡上，加成微信好友后，提示词只告诉ta和别人的关系，没告诉ta自己的日子；而且人物卡加成好友后在关系网总览里不再显示，没地方改。

- 新增 `relSelfText`：加成好友的人，提示词开头带「# 你自己 你的生日是X月X日」（有纪念日也带），私聊、群聊、线下、共同生活都走 `relPromptFor`，都能看到。
- 这个人的关系网页面多一行「X的资料卡」，点进去可以改生日、纪念日、为人；资料卡上不再显示删除按钮，改为说明这张卡会一直跟着ta。
