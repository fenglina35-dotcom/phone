# v1366（网页）共同生活「点一下出一句」

仅网页；私人包仍是 v1365 / iOS 1.0.424。

## 用户要求
共同生活设置里加一个点一下角色出一句话的模式，免得跟不上观看速度：第一句角色先说，后面每句都是点屏幕任意地方才出；点到最后没反应，就是说完了。

## 改动
- 共同生活设置新增「台词播放」：自动一句句出（默认）/ 点一下出一句（settings.tapAdvance）。
- 点一下模式：第一句照常自动出，之后不再按计时器，改成等点击（cohabTapWait）。点屏幕任意空白处或气泡都算；按钮、输入框、设置、顶栏照常使用。这一句还在逐字出的时候点，先把这一句出完；再点才出下一句。等待时底部有「点一下屏幕继续 ▾」提示，说完后提示消失、再点没反应。
- 普通回复和查手机后的回应两条出台词的路径都用这个模式。
- 离开共同生活时，还没点出来的台词直接收进记录，不会丢（自动模式下原来离开也会丢后面的句子，一并修好）。

## 验证
浏览器：假模型回 4 句，第一句自动出、点三下出完、第四下没反应，提示随之消失。
