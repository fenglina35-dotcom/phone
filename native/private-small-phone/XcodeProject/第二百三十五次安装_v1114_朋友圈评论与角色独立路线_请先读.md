# 第二百三十五次安装：v1114 / 私人 iOS 1.0.235（235）

本包是完整 Mac/Xcode 源码包，递归包含当前完整 `PhoneWeb.bundle`，不会覆盖任何历史安装包。

本次修复朋友圈发布后的角色互动：用户发布朋友圈后，角色依据真实正文和已有图文照片描述自主点赞或评论；真实模型评论保存后会立即显示，不再需要用户先在评论区补发消息才能刷新。角色在后续微信、共同生活和一次性线下场景中也能记得自己确实可见的用户朋友圈正文；真实照片没有文字描述时仍不会臆测画面。

API 路线改为按角色独立保存。角色聊天、通话、朋友圈、微信登录、查手机和一起听歌都使用该角色自己的路线；切换一个角色不会连带修改其他角色。未单独选择路线的角色继续使用全局默认路线，共同生活原有的独立模型路线设置保持不变。

同时保留 v1111 已确认成功的微信／共同生活双向连续剧情，以及现有后台主动消息、通话、真人好友、图片、媒体、微信总结、外卖、软件锁定和安卓安全启动功能。

Windows 已运行自动化、语法、版本、Bundle 字节一致性与 ZIP 结构检查；这不等于 Mac 已编译签名，也不等于真实 iPhone 已验证。请在 Mac 上打开 `PhoneCompanionTest.xcodeproj`，选择私人 App scheme 后重新签名安装。
