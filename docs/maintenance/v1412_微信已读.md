# v1412 微信已读

- 开关：`S.settings.readReceipt`，默认开，位置在「设置 → 角色、时间与消息 → 微信已读」，函数是 `readReceiptOn` / `readReceiptToggle`。
- 角色聊天：
  - 每条消息都有一个 `.msgread-line`，贴在气泡前端、和气泡底部对齐（`.msg>.col` 设为相对定位，标签绝对定位在气泡外侧）。
  - 她的消息：`roleMarkRead` 在 `aiReply` 开始「正在输入」时写入 `readAt`；后面已经有角色消息的也算已读。
  - 角色的消息：`roleSeenTick` 每 0.5 秒检查一次，聊天页打开、而且 App 在前台看着超过 0.7 秒，就写入 `seenAt`。
  - 每条都显示，读了不会再藏起来。
- 角色提示词：`roleReadPrompt` 写明「她已读超过 2 分钟但还没回」。
- 真人好友：
  - 原来的已读写在 `.msgt` 里，而新版微信样式把 `.msgt` 隐藏了，所以一直看不到。现在改成单独的 `.msgread-line`。
  - 对方发来的每一条也显示我读没读；私人包标完已读后由 `pfReadInPlace` 直接更新界面上的字。
  - 开关关掉时 `pfReadStatus` 返回空，`pfAckRead` 不再回执。
- 为了不破坏旧测试，`bubbleRow` 里 `const ts` 那一行保持原样，已读加在后面的 `readLine` 里。
