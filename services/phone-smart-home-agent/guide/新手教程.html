小手机网页智能家电控制：从零开始

适用于 Windows 电脑、苹果手机上的网页版小手机和已实测的 Meross HomeKit 床头灯。照顺序操作，不需要编程，也不要把任何密码或配对码发给别人。

当前只支持苹果：本教程与当前正式验收范围只包括 iPhone、苹果“家庭”App 和 HomeKit。安卓手机暂不属于当前支持范围，也不能用安卓端的控制成功代替苹果端验收。
买灯有两种方式：
  • 优先使用开发者推荐链接：点击打开已经实测过的淘宝候选商品。下单前仍要向卖家核对实际发货型号为 MSL430HK、支持 HomeKit，并保留退换保障；实物底部铭牌可能显示内部型号 MSL430。
  • 也可以自行在淘宝搜索：请选择明确支持苹果“家庭”/HomeKit、具有开关、亮度、RGB颜色和色温功能的完整灯具，并优先选择支持无理由退换的商品。

重要：自行搜索不等于一定匹配成功。当前 Windows 助手只正式实测并开放内部型号 MSL430；外观相同、仅写“支持 HomeKit”或其他型号的灯，即使能加入苹果“家庭”，也可能无法被电脑助手识别。未实测型号需要后续单独适配，不能把它当作已经兼容。

一、准备好这些东西

  • 一盏已确认内部型号为 MSL430 的 HomeKit 灯；如果是自行搜索购买，先保留包装并确认仍在退换期内。
  • 一台可以长期保持开机的 Windows 10/11 电脑。
  • 自己家里的私人路由器。灯连接2.4GHz；电脑可用网线、2.4GHz或5GHz，但必须与灯处于同一家庭局域网。
  • 苹果手机上的“家庭”App或 Meross 官方App，用来先完成灯具的正常配网。
不要使用酒店、商场、宿舍公共Wi‑Fi或开启“访客隔离”的网络。手机日常打开网页时可以使用流量或其他网络，但电脑与灯必须留在同一个家庭局域网。

二、先让灯能够被手机正常控制

1
给灯通电。手机连接自己家的2.4GHz Wi‑Fi。
2
按照灯具说明书，用苹果“家庭”App或 Meross App添加灯。HomeKit配对码只在官方添加过程中使用，不要截图发给别人。
3
在手机上分别测试开灯、关灯、亮度、颜色和色温。任何一项不正常，先不要安装电脑助手，应先解决官方控制或退换灯具。

三、安装 Windows 助手

1
打开压缩包中的“安装程序”文件夹，双击 SmallPhoneSmartHomeAgent-0.1.6-Setup.exe。
2
如果 Windows 显示“已保护你的电脑”，先确认文件名正是上面的 0.1.6 安装程序，再点击“更多信息 → 仍要运行”。这是因为当前安装包没有购买商业代码签名证书，并不代表可以跳过文件名核对。
3
安装完成后程序会自动打开，并创建桌面快捷方式。以后登录 Windows 时会自动运行。
4
如果 Windows 防火墙询问是否允许网络通信，只勾选“专用网络”，不要勾选“公用网络”，然后点击允许。
5
确认电脑与灯连接同一个私人路由器。如果电脑使用网线，这是正常的，不要求电脑也连接2.4GHz。

四、网页与电脑配对

1
打开网页版小手机，进入“微信 → 我 → 服务 → 智能家电”。
2
点击“生成十位配对码”。配对码十分钟后失效，只能给自己眼前的这台电脑使用。
3
把十位数字输入 Windows 助手，点击“寻找灯具并让它闪烁”。
4
准备绑定的灯会连续闪烁两次，随后自动恢复之前的开关、亮度和颜色。
5
亲眼确认闪烁的是自己的灯，再点击“是，这是我的灯”。没有看到、闪错灯或不确定时必须取消。
6
程序会固定这盏灯的唯一指纹。以后即使同一网络出现另一盏 MSL430，也不会自动改连。

五、完成验收

1
Windows 助手显示“唯一灯具指纹已固定”。点击“读取并验证现在的灯”。
2
回到网页点击“重新读取真实状态”，确认网页显示与灯的实际状态一致。
3
依次测试开关、亮度、粉色、蓝色和色温。每次都必须等到真实状态回读成功。
4
最后再和角色说“要不要帮我开灯”或“选一个你喜欢的颜色”。角色可以同意或拒绝；只有执行并回读成功后才能说已经完成。
日常使用：灯保持通电，Windows电脑保持开机，助手在后台运行。手机可以离开家庭Wi‑Fi。官方 Meross App、苹果家庭和灯具按键仍然可以继续使用。

六、常见问题

  • 找不到灯：确认灯已在官方App中可控；电脑和灯属于同一路由器；不要使用访客网络；暂时关闭路由器的AP隔离/设备隔离。
  • 发现多盏灯：首次绑定时只让准备绑定的那一盏 MSL430 在线，其他同型号灯暂时断电。绑定完成后可重新通电。
  • 灯没有闪：不要点击确认。取消后检查网络和灯具，再重新生成配对码。
  • 提示已绑定到其他家庭：回到原网页“智能家电”页面解除电脑连接；确认原绑定释放后再重试。
  • 电脑关机后不能控制：这是当前低成本方案的正常限制。网页会显示离线，不会伪造成功。
  • 换路由器：先用官方App重新给灯配网，再确保电脑加入新路由器。灯的HomeKit身份未重置时通常无需重新绑定；如果恢复出厂设置，则必须重新完成闪烁确认。

七、安全边界

  • 网页、云端和电脑助手不保存 Wi‑Fi 密码、HomeKit配对码或二维码。
  • 每个网页家庭有独立身份；十位配对码仅短时有效；电脑密钥由 Windows 加密存储。
  • 一盏灯的唯一指纹不能同时绑定给两个网页家庭。
  • 物理闪烁确认主要防止误连和普通串灯；它不能让不可信的公共网络变安全。请始终使用自己的私人家庭路由器。
