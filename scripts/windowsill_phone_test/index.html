窗台测速

单独的测试网页，不是小手机。测完的结果会自动传回电脑。

测之前

  1. 像平时用的样子测就行，充不充电都可以（充电时也要顺才算数）。
  2. 关掉低电量模式。
  3. 屏幕别自动锁：设置 → 显示与亮度 → 自动锁定 先选「永不」，测完改回来。
  4. 测的时候别碰屏幕，放平就行。

一、自动测速（约 1 分半）

窗台会自己换三种做法，每种开一次：先看全景，再凑近「共读」、凑近「一起听」，分开记下每秒画了几张，和每一步各用了多久。

二、自己试看

点一种画质打开窗台，像平常一样转一转、点东西。顶上中间是每秒帧数（60 最顺，30 以下会觉得卡）。点窗台左上角的小箭头回到这里。
