# 小手机 v1250 / iOS 1.0.360（360）安装与验收

这是 Mac 待编译的私人源码覆盖包，不是 IPA。公开网页已上线 v1249。

## 本次同步了什么

按你的要求，只把网页 v1249 里的两项同步进私人版，其余四项本轮不动。

**一、视频通话里的动作描写变成英文。**

原有的英文拦截是按**整条回复**判断的：只要回复里出现一个中文字，整条就整体放行。所以"中文台词 ＋ 英文旁白"这种混合回复从来不会被拦下来——视频通话里【】中的动作描写变成英文时，完全没有保护。这不是偶尔漏，是这种情况根本不在它的判断范围内。

同时提示词本身也有诱因：视频通话的格式要求原文写的是"动作行**可以**用中文"，那是许可，不是要求。

修复分两层，**一次模型调用都不多花**：
- 提示词改成"动作行**必须**用中文写"，线下格式锁补上"【】里的旁白必须用中文写"，从源头减少；
- 运行时只在一段【】里**一个中文字都没有**时，本地把那一段丢掉。台词里夹的英文单词、歌名、地名一律不动，隐藏标签不动；万一整条会被删空，就原样退回交给原来的纯英文拦截，绝不会产出空回复。这个判断不抛错，所以不会触发任何重新生成。

**二、共同生活开启后角色不会主动打电话。**

原先只要共同生活绑定了这个角色，所有不是你主动发起的来电都被直接挡掉。核查发现**面对面的情况本来就被另一道守卫挡着**（`roleOnlineProactiveBlocked` 里包含 `cohabOnlineQuiet`，只在你们同处一室时为真），所以删掉多余的那一道正好：角色**上班、外出、回家路上**可以给你打电话，你们在一起时仍然不会打。

本轮**没有**同步的四项（私人版保持原有行为）：完整备份跳过坏图、定时查岗错过时点补跑、群聊撤回可被角色感知、未结束约会自动归档。

## 安装步骤

1. 在 Mac 把压缩包解压到一个全新的目录。不要覆盖旧工程目录，也不要先删除 iPhone 上的旧小手机。
2. 打开 `PhoneCompanionTest.xcodeproj`，沿用原 Apple Account、Team、Bundle ID、签名和现有 entitlement（HomeKit、Screen Time、通知等不受影响）。
3. 核对所有 Target 的 Marketing Version 均为 `1.0.360`，Build 均为 `360`，原生桥契约仍为 `38`，然后覆盖安装到真实 iPhone。
4. 打开"设置 → 授权与数据"，核对版本显示为私人 `1.0.360 (360)`。

## 验收

**通话格式**：打几通视频电话，多聊几轮，确认【】里的动作描写都是中文；台词里如果角色说了英文单词、歌名或地名，应该照常保留不被吞掉。

**来电**：等角色进入上班、外出或回家路上的状态，确认他可以主动打电话给你；你们面对面在家时，确认他不会打电话（那时候应该直接说话）。

Windows 已完成全量自动化回归与核心聊天发布门禁（网页与私人两个入口，页面错误 0）。Mac 编译、签名和真实 iPhone 上的实际表现仍待你确认，不能据此直接称真机已经修好。
