# v1086 私人 App 安装说明

本包版本：网页 v1086；私人 iOS 1.0.211（211）；原生桥 25。

这次不是整版退回旧代码，只撤销 v1085 新加入且真机没有改善的 WebContent 降载、可见图片抑制和自动恢复策略；微信手动总结、伴生消息、解锁视角、后台通知、普通聊天、朋友圈和语音等现有功能均保留。另保留微信引用栏“×”可直接取消引用的修复。

## Mac 编译

1. 完整解压 ZIP 到一个全新目录，不要覆盖以前解压过的工程。
2. 先阅读同目录的《请在Mac编译前先读.md》。
3. 用 Xcode 打开 `PhoneCompanionTest.xcodeproj`。
4. 选择 `PhoneCompanionTest` 主 App、你的签名团队和真实 iPhone。
5. 确认版本显示为 1.0.211（211）后再编译安装。

## 真机先验收

1. 打开私人 App，确认主屏头像、三张照片和应用图片能正常出现，不应长期显示问号。
2. 连续进入微信、朋友圈、设置和情侣空间，确认点击没有被 WebContent 压力窗口暂停。
3. 在微信引用一条消息，再点引用栏右侧“×”，应立即取消。
4. 再验证普通角色回复、朋友圈回复、后台通知、伴生真实数据和外置语音仍正常。

Windows 自动测试通过不等于 Mac 已编译或真机已经修好；必须以本次新解压工程的 Mac 编译和真实 iPhone 结果为准。
