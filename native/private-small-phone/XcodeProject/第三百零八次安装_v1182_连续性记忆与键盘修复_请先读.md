# 第三百零八次安装：v1182 连续性、记忆与键盘修复版

本目录是私人 iOS `1.0.308 (308)`、网页与私人共用版本 `v1182` 的 Mac 待编译源码。原生桥 35 保持不变。

本包对应网页与私人版共同版本：网页源码和私人内置页面均为 v1182。

## 本轮可见修复

1. 微信重复查看同一批内容时，只把新增内容作为新发现；没有新增内容时不会再次制造同一条记录。
2. 已经在微信或共同生活说过“面吃完了”等完成状态后，角色不能倒退追问“面吃了吗”；真实模型最多纠正一次。
3. 角色主动要求记忆时，以角色本人作为“我”，保留用户自己的昵称和称呼。
4. 共同生活旁白／对话切换不再先收起键盘；私人 WKWebView 跟随原生键盘框架，输入栏应与网页版本保持同样的抬升和收起节奏。

## Mac 编译与真机验收

1. 在 Mac 完整解压本包，使用 Xcode 打开 `PhoneCompanionTest.xcodeproj`。
2. 选择原来的 Team、Bundle Identifier 和目标 iPhone，直接 Build／Run；不要先删除手机旧 App，以保留数据容器。
3. 启动后确认设置页可见 `v1182`，原生诊断可见 `1.0.308 (308)`。
4. 在共同生活输入框唤起键盘，不关闭键盘连续切换“旁白／对话”，确认焦点仍在输入框、输入栏始终位于键盘上方；再关闭键盘检查动画。
5. 分别复测重复查看微信、进食状态连续性和“角色要求记忆”的第一人称结果。

Windows 自动测试、浏览器预览和 ZIP 文件核验不能证明私人包已在真实 iPhone 上正常运行；完成签名、安装、启动和上述触控操作后，才能算真机验收通过。
