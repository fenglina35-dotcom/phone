# v1236 恢复完整备份自动下载核验

日期：2026-09-11。发布前线上基线为 `main` 的 `b64aa1d9db56680ea96c8e93b4702a19043e5d62`，网页版本 v1234。

## 真实回归边界

同一名用户、同一台华为安卓手机、同一个 Edge 浏览器在当天上午 11 点成功导出过完整备份。当时线上仍为 v1232。v1233 于 15:16 上线后把导出改成“生成后再点下载或系统分享”；v1234 又加入 TXT 和系统分享入口。用户确认 v1233、v1234 均没有在该设备产生可用备份文件。这组同设备前后对照排除了浏览器完全不支持下载、手机权限长期关闭等稳定因素，故障边界落在 v1233 之后的导出流程改造。

## 修复

- 恢复 v1232 已在目标真机成功的一次点击 JSON 自动保存路径。完整状态生成后立即调用 `beautySaveFile`，Android Edge 直接执行隐藏下载链接，不再要求用户从第二层弹窗再次点击。
- 保留生成中的单任务保护，重复点击不会并行生成多份大备份。
- 保留可见的生成提示和失败原因；失败后可以再次点击重试。
- 保留 v1233 的导入图片分批写入和缓存释放，避免大备份导入后长期占用大量内存。
- 继续接受 `.txt`、`text/plain`，使 v1234 已生成的兼容文件仍可导入；新导出恢复为 `.json` 和 `application/json`。
- 网页与私人内置页源码同步为 v1236。私人原生仍为 iOS 1.0.355（355），桥 37；未生成私人包。

## 已撤销的路径

v1233 的“生成后再点击下载”以及 v1234 的 TXT、系统分享、双下载链接均从导出入口撤销。它们通过了桌面浏览器模拟，但没有通过目标华为 Edge 真机。Cache Storage 与 `Content-Disposition` 的试验此前已经撤销，本次没有重新引入。

## 验证范围

- 修复前回归测试明确失败：一次点击没有调用 JSON 保存函数。
- 修复后单元回归覆盖一次点击自动保存、JSON 文件名与正文、重复点击单任务、失败可见和再次重试。
- Windows Edge 使用华为 Android Edge UA，网页和私人内置两个入口均一次点击产生约 16 MB JSON 文件；导入、分批写入、重载后的图片与设置保持一致，页面错误为 0。
- 定向存储与导出测试 17/17 通过；全量 Node 测试 1811/1811 通过。
- 授权聊天发布闸门在网页和私人入口全部通过，覆盖授权开关、原样模式、已有笔记、自动查看、持久化重载和忙状态释放。
- 三份维护 DOCX 的 ZIP 结构、追加正文和其他成员字节保持校验通过。当前依赖环境没有 LibreOffice，规范渲染器无法生成 PNG，因此没有视觉渲染证据。
- 仍需目标华为真机确认 Edge 下载记录或文件管理器中实际出现 JSON 文件。桌面 UA 模拟不能替代真实手机落盘验收。

## 2026-09-12 v1237 归因更正

用户提供 Invalid string length 截图，旧版约520 MiB备份可复现相同错误。上午11点成功并未控制数据量或可用内存，因此上文“故障边界落在v1233之后的导出流程改造”的因果推断不足，应以[v1237核验](v1237_大备份分段读写核验.md)的新证据为准。v1236恢复自动下载同样未通过目标用户验收；保留上文作为历史尝试，不把桌面16 MB测试视为真实大备份安全证据。
