# 第二百九十四次安装：v1167 心动审判、共同生活入口与推文删除记忆修复

本包是全新候选：网页资源 v1167、私人 iOS 1.0.294 (294)、原生桥 26。请完整解压到新的目录后再用 Xcode 打开，不要覆盖或混用旧工程、旧 ZIP、旧 DerivedData 中的产物。

## 本次修复

- 心动审判：v1166 仍只接收 JSON，因此模型用自然编号或“题目／A／B／C／反应”文字输出时会整批判为零。v1167 改为简单九行文字协议，接收编号、Markdown 标签和常见中英文标点，同时保留旧 JSON 兼容；每批有效题继续累计，缺项才补题。
- 共同生活：旧存档数组中的 `null`、空项或旧字符串记录可能在渲染时触发属性访问异常。v1167 在入口前修复这些记录，并在任何导航异常时恢复原页面栈、绑定角色和线下场景，避免反复卡在半进入状态。
- 推文删除：旧版只删推文数组，却保留 `_mylog` 中“在 X 发推”的正文，全量查手机会再次把它提供给角色。v1167 为新日志绑定推文 ID，删除时同时清理 ID 记录及旧版同正文日志。已经单独转发到微信或在聊天中明确谈过的内容仍属于真实聊天，不会被静默改写。
- 网页和私人 Bundle 同步修复。原生接口未增加，原生桥保持 26。

## Mac 编译前

1. 确认使用本包内的 `PhoneCompanionTest.xcodeproj`，Target 版本显示 1.0.294、Build 294。
2. 在 Signing & Capabilities 中确认 HomeKit 已启用；选择自己的 Team，并保留现有 HomeKit entitlement。
3. Clean Build Folder 后重新编译、签名并覆盖安装到真实 iPhone；不要删除 App 数据，也不要混用旧包中的文件。
4. Windows 测试与 ZIP 校验不代表 Xcode 编译、签名或安装已经通过。

## 真机逐项验收

- 心动审判：选择“TA 每局新出题”，加载进度最终到 30／30；第一题和后续题均由角色询问你如何选择，每题三个答案，选择后出现对应的角色反应。
- 共同生活：保留现有旧数据，从线下约会页连续进入、退出、再次进入；不能出现入口异常，原聊天、总结与状态不丢失。
- 推文删除：新发一条只用于测试的推文，等待角色互动后删除；再让角色查手机，角色不能从 X 动态或 X 活动日志读回已删除正文。
- 回归：普通微信真实回复、私人 HomeKit 直连、小事簿删除位置、视频摄像头连续语音、共同生活线上／线下连续性均保持正常。
- 版本页／诊断信息应显示网页 v1167、私人 iOS 1.0.294 (294)、原生桥 26。
