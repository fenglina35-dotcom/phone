# 第二百一十六次安装：v1091 拟人忙碌、真实时间间隔与录屏音轨修复

- 网页版本：v1091
- 私人 iOS：1.0.216（216）
- 原生桥：25

“拟人忙碌回复”是每个角色独立开启的可选功能。关闭时普通聊天和后台主动消息保持原逻辑；开启后也只有角色本人根据人设、职业、作息和当前真实时间，明确说出大约何时恢复回复，才会进入忙碌。约定时间前的新消息只保存，不调用模型、不消耗额度，也不显示系统提示；到点后通过真实角色模型一次接住等待内容，首次无可见回复时最多再走一次同模型重试，不使用固定角色台词。

角色每次回复都会获得最新后台真实时间和最近可见微信时间线。直接询问“刚才隔了多久”时会按真实时间戳回答，即使回来后又聊了几句也不会把之前的长间隔误说成最近几十秒。时间误差容许一到两分钟；默认未满一小时不主动抱怨“怎么这么久没理”，满一小时后才允许按人设自然在意，也不会每句话报时。

音乐页从录屏或视频导入时，会先提取其中的真实音轨再写入音乐库。MP4/MOV 的常见 AAC 音轨直接封装为可播放的 M4A，其他可解码视频转换为 WAV；写入后校验大小和首尾签名。旧版误存为原视频的歌曲在播放时也会尝试自修复。没有声音或不支持的音轨会明确停止，不会保存一个无法播放的假歌曲。

Windows 自动测试和本地页面流程不能代替 Mac 编译、签名或真实 iPhone 验收。安装前请保留旧包，按“请在Mac编译前先读.md”执行，并先核对本 ZIP 的 SHA-256。
