# v1402 节假日放假与手动请假

- 作息弹窗新增「给ta请假」：选开始、结束日期和原因（可不填），保存为 `source:'me'` 的请假。角色的作息提示会写明「这次假是她亲自给你请的」。请假列表里会标出「我请的」。
- 新增「节假日放假」开关（默认开）：
  - 法定假期按国务院安排放假，调休补班日照常上班（2025、2026 是官方安排；2027 先按估算）。
  - 情人节 2/14、520、七夕、圣诞也都放假一天，补班日撞上情人节时也放假。
  - 关掉开关后只按周一到周五上班、周末休息。
- `roleDayOff(c,t)` 统一判断请假 / 节假日 / 周末，用在 `whereNow`、`activitySpec`、`roleScheduleClaimIssue`、`roleSchedulePrompt`。共同生活的自动状态也会跟着走。
- 提示词里会列出近三周的节假日，后台推送配置也会把节假日当作休息日传过去。
- 作息弹窗里的开关之前被挤成宽度 0（只剩一个小圆点），这次放进了 `section`，可以正常显示。
- 扫脸恢复失败的提示改得更清楚：选中的那一枚手机验证不是这份授权绑定的；列表里有好几枚就换一枚，都不行就补绑，或者用新授权码进入。
- 私人包同步了代码，版本号不变（仍是 v1401 / iOS 1.0.430）。
