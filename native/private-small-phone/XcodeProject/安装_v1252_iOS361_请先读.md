# 小手机 v1252 / iOS 1.0.361（361）安装与验收

这是 Mac 待编译的私人源码覆盖包，不是 IPA。公开网页已上线 v1251。

## 本次同步了什么

这一版把网页那两批修复**全部**搬进私人版，之后两边不再有差异。

**一、表情包破图、主屏组件变黑、锁屏壁纸变黑——其实是同一个毛病。**

存档为了省空间，会把大图片**就地**换成一个内部引用（`idb:` 开头）。而好几处显示的地方直接把这个值当成图片地址用了：微信单聊的表情包画成破图；锁屏和主屏壁纸的地址无效。而主屏壁纸一旦没了，上面那些毛玻璃组件**下面就没东西可透**，于是整块变黑——这就是你说的"本来透明的组件有时变黑，滑一下又恢复"（滑动触发重绘，引用被还原回真图）。

现在表情包（单聊＋群聊）、锁屏壁纸、主屏壁纸、主屏照片组件、朋友圈配图和封面，全部先还原再显示，还原不出来时也不再写无效地址。

**二、AI 真图生成失败。**

设置页「测试出图」用的是方图，实际发照片用的是竖图；而原本的失败重试只去掉画质等参数，**尺寸从不退让**。所以站子只开通方图时，就会出现"测试永远成功、实际永远失败"。现在遇到尺寸被拒会自动退回方图再试一次（这种情况下出来的是方图）。

另外，内容审核被拦也是同样的 400，但换尺寸照样过不了。现在这种情况**不再浪费一次生图调用**，提示也会明确写"图片平台的内容审核拦下了这次请求，不是地址、密钥或模型名的问题"——原来的提示会让你去查站子和模型名，白折腾。

**三、私人云备份「立即备份」点了没反应。**

原生请求以前**完全没有超时**。只要有一次不回应，"正在备份"的标志就永远挂着，之后每次点击都在入口被悄悄丢掉，界面一直显示"正在备份，请保持 App 在前台"。现在加了 120 秒的上限，超时会明确报错并把状态释放掉，可以重试。

**注意**：这只保证"失败看得见、能重试"。真正让原生不回应的原因，要等下次带着错误信息的实测才能确认。

**四、顺带一起搬过来的：** 完整备份遇到坏图改为跳过并告知（不再整份失败）、定时查岗错过时间点当天会补查一次、群聊撤回角色能察觉且可撤角色的消息、开始新约会前先归档没结束的上一场、好友申请方向按来源区分、陌生来电知道是自己拨出的不再反问你是谁、小本子改由角色自己判断该记什么。

## 安装步骤

1. 在 Mac 把压缩包解压到一个全新的目录。不要覆盖旧工程目录，也不要先删除 iPhone 上的旧小手机。
2. 打开 `PhoneCompanionTest.xcodeproj`，沿用原 Apple Account、Team、Bundle ID、签名和现有 entitlement。
3. 核对所有 Target 的 Marketing Version 均为 `1.0.361`，Build 均为 `361`，原生桥契约仍为 `38`，然后覆盖安装到真实 iPhone。
4. 打开"设置 → 授权与数据"，核对版本显示为私人 `1.0.361 (361)`。

## 验收

- **表情包**：发一个表情，确认立刻就能看到图，不用退出再进。
- **主屏组件**：多切几次页面，确认原本透明的组件不再偶尔变黑。
- **锁屏壁纸**：反复进出锁屏页，确认壁纸每次都在，不再是黑的。
- **立即备份**：点一次"立即备份本机"。要么成功，要么在两分钟内给出明确错误——**不应该再出现点了没反应**。如果报错了，把错误原文发我。
- **小本子**：正常聊几天，看角色会不会自己往小本本里记东西。
- **陌生来电**：等一次陌生人打进来，确认对方不再反问"你是谁"。

Windows 已完成全量自动化回归与核心聊天发布门禁（网页与私人两个入口，页面错误 0）。Mac 编译、签名和真实 iPhone 上的实际表现仍待你确认。
