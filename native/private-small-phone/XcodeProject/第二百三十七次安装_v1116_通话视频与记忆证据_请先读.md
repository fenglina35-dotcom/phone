# 第二百三十七次安装：v1116 / 私人 iOS 1.0.237（237）

本版新增角色视频通话循环画面和统一的自动记忆证据校验。

- 角色设置 → 通话记录 → 视频通话角色画面，可上传 MP4、MOV、M4V 或 WebM；视频只保存在当前设备，不进入云同步。
- 视频通话中点按角色画面可放大，自己的摄像头或头像缩到右上角；再次点按恢复。
- 循环视频永久静音，应用退到后台只暂停画面，不中断角色说话、通话、摄像头或屏幕共享。
- 线上微信、共同生活和通话的自动长期记忆统一拒绝疑问句、截断原话、粗口片段、操作过程和无当前证据的推断。
- 本版不会自动删除已有记忆；请在“资料与记忆 → 记忆”中人工删除已经存在的错误条目。

Windows 已完成自动测试和实际浏览器界面核对；没有在本机完成 Mac 编译、签名或真实 iPhone 视频编解码验收，不能把本说明当作真机已验证结论。
