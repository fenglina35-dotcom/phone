# v1362（网页 + 私人包同步）角色群单独/合并调用、角色发红包转账、禁言后私聊、配对码重试

## 用户要求
角色也能想发红包就发；有人生成配对码失败（Load failed）；角色把我禁言后，微信私聊按群里发生的事给我发消息（像抖音那样）；角色群里可以设置谁单独调用模型、谁合并统一调用，这样更快。

## 改动
- 角色设置页「模型调用」：每个角色选「单独」或「合并」。默认情侣角色单独、其他人合并。单独：完整人设，走角色自己设置的路线（和私聊一致）。合并：这一轮所有合并角色一次请求，按【名字】分段拆回各人，没轮到的人写的段落丢掉，不算到上一个人头上。
- 角色红包/转账：提示改成想发就发；`[红包|金额|祝福语|个数]`、`[转账|金额|说明|给谁]`（gPayExtras）；转给别的角色，对方几秒后收下。
- 禁言私聊：角色禁言我时记 g.muteBy；6–16 秒后用 scheduleFeatureReply 在私聊发来消息（附群里最近 12 条）；私聊系统提示里知道这件事，回复里单独一行 `[群解禁]` 就解除（applyGroupUnmuteTag）。
- 公开版配对码：public-north-runtime 的 rpc 遇到 Safari「Load failed」等网络错误自动重试一次，还失败就提示「连不上配对服务器（网络中断或被拦截）」。原因是对方手机连公开 North 服务器的网络中断/被拦截（VPN、广告拦截、网络不稳），私人 App 走的是另一台服务器。

## 验证
浏览器 + 假模型服务器：单独角色走路线二、合并角色一次请求拆成多人；角色红包个数 2；转账给群友；禁言 → 私聊消息 → [群解禁] 解除。
