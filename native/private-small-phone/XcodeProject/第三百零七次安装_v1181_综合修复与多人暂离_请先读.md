本包对应网页与私人版共同版本：网页源码和私人内置页面均为 v1181，私人 iOS 为 1.0.307 (307)，原生桥 35。

本次合并当前工作区已经完成的全部修复，包括像素拼拼乐画作归档与共同完成信息、线下约会输入框兼容、主动消息与回复格式稳定、外卖链路复核，以及共同生活多人剧场的成员暂时离场／回场。暂时离场不等于永久请离，不会清除角色配置、历史消息或触发永久离场总结；当用户暂时离场时，继续使用原有“让TA回”，每次点击只让在场配角各发言一轮，再让主角发言一轮，不会自动无限对话。

## Mac 编译与真机验证

1. 完整解压本次 ZIP 到新的目录，不要覆盖旧工程或混用旧 DerivedData；不要先删除手机上现有的 App，以保留原数据并进行覆盖安装。
2. 用 Xcode 打开 `PhoneCompanionTest.xcodeproj`。
3. 确认各 Target 的 Version 为 `1.0.307`、Build 为 `307`，继续使用原来的 Team、Bundle Identifier、Automatic Signing、Provisioning Profile 和 Entitlements。
4. 连接私人 iPhone，完成签名、编译、安装和正常启动。
5. 设置页应显示网页核心 `v1181`、私人 iOS `1.0.307 (307)`、原生桥 `35`。

Windows 生成的是 Mac 待编译源码包；只有完成以上 Mac/Xcode 与真机步骤后，才能确认该私人版本可运行。
