# 第一百四十七次安装：v1026 手机验证重复绑定修复

## 本次版本

- 网页：v1026
- 私人 iOS：1.0.147（147）
- 原生桥：25
- 工程目录：`SmallPhone_v1026_PasskeyRebindRepair`

## 本次修复

1. 已有系统扫脸／指纹通行密钥时，再点手机验证不会继续把系统的“禁止重复创建”误报成授权失败。
2. 已绑定时明确显示“手机验证已经绑定，无需重复绑定”；设置按钮改为“检查 / 补绑手机验证”。
3. 第一次绑定及新设备补绑仍会正常创建通行密钥，不会跳过真实系统验证。
4. 系统取消、重复凭据、浏览器不支持和授权域名不匹配分别提示，不再全部混成同一个错误。
5. 新旧授权云端切换逻辑保持不变；未修改邀请码、现有浏览器名额、用户数据、聊天和内置／外置语音。

## 安装与核对

1. 在 Mac 新目录完整解压本包，不覆盖旧工程。
2. 打开 `PhoneCompanionTest.xcodeproj`，选择 `PhoneCompanionTest` Scheme 和真实 iPhone。
3. 执行 `Product → Clean Build Folder` 后覆盖安装，不删除旧 App、不清数据。
4. 设置页确认网页 v1026、私人 iOS 1.0.147（147）、原生桥 25。
5. 在“授权与数据”点“检查 / 补绑手机验证”。已经绑定的手机应提示“手机验证已经绑定，无需重复绑定”，不再出现旧的通用失败提示。

## 验证边界

- Windows 自动回归通过后，只能说明代码与自动测试通过。
- 尚未在 Mac 编译、签名，也尚未在真实 iPhone 验证本次系统通行密钥行为。
- 不能提前写成“真机已经修好”；最终结果以 v1026 真机点击验证为准。

## 稳定功能保护

本次没有修改普通微信回复、朋友圈、后台消息、AI 点数、伴生控制、通话、外置或内置语音。现有授权会话、通行密钥和用户数据不会被清空。
