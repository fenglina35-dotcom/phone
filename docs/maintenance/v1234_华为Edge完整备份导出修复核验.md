# v1234 华为 Edge 完整备份导出修复核验

日期：2026-09-11。发布前基线为 `main` 的 `8b6a8f36e3116cba3145930749a060314831704b`。

用户确认 v1233 在华为安卓手机的 Edge 浏览器里点击“导出备份”仍然没有反应，并授权修复、测试和网页推送。本次不生成私人版本。

## 原因判断

v1233 的导出测试使用 `northPreview`，该模式明确不注册 Service Worker，因此没有覆盖正式网页的控制环境。补测后，同一 Windows Edge 在不受 Service Worker 控制的入口可以下载约 16 MB 的 `blob:` 文件，在受控正式网页入口没有产生下载事件。这个差异是已经复现的软件变量。

v1233 的文件分享候选使用 `application/json` 和 `.json`。Chromium 和 MDN 公布的常见可分享文件类型列出了文本、图片、音频、视频和 PDF，但没有 JSON，因此 `navigator.canShare()` 可能返回 `false`，导致系统分享按钮不出现。真实华为手机没有远程调试条件，以上两项不能证明是设备故障的唯一根因。

## 实现

- 点击“导出备份”后立即显示持续的生成界面，不再只显示短暂提示。
- 生成完成后，支持文件分享的浏览器显示“华为 / Edge 系统保存”。分享文件使用 `.txt` 和 `text/plain`，正文保持完整 JSON。
- 提供 `.txt` 下载入口，响应类型使用 `application/octet-stream`；保留原 `.json` 普通下载作为备用。
- 导入入口同时接受 `.json`、`.txt`、`application/json` 和 `text/plain`，两种扩展名使用相同的 JSON 校验和安全导入流程。
- 生成失败显示错误原因和“重新生成”按钮；生成中的重复点击只恢复进度界面，不启动第二份任务。
- 网页和私人内置源码同步为 v1234。私人原生仍为 iOS 1.0.355（355），原生桥仍为 37；未生成私人包。

## 放弃的尝试

曾尝试把备份写入 Cache Storage，并由 Service Worker 返回带 `Content-Disposition: attachment` 的同源响应。测试确认响应正文和响应头正确，但受控 Windows Edge 仍未产生下载事件。该方案还会在缓存里额外保存可能包含模型密钥的整包数据，因此已经撤销，没有进入发布候选。

## 验证

- v1233 旧实现：新增的即时生成界面和 TXT 分享回归失败。
- v1234 定向测试：22/22 通过，覆盖生成失败、并发点击、取消分享、TXT 导入、图片导入安全顺序和存储回退。
- 全量 Node 测试：1821/1821 通过。
- 授权聊天发布闸门：网页和私人入口均通过既有手机查看权限、已有笔记、角色和账号隔离、原样模式、可见回复、忙状态释放、自动查看与持久化重载。HTTP 模型为隔离夹具。
- 完整备份浏览器回归：Windows Edge 使用 Android Edge UA；网页入口受 Service Worker 控制。双入口均生成约 16.02 MB 的 TXT 分享文件，文件名、`text/plain` 类型和正文一致；导入、保存、重载后图片和设置保持。私人内置入口的 TXT 实际下载也通过。
- 网页入口的系统分享面板由浏览器夹具代替操作系统面板，只证明代码在真实用户点击中交付了正确 File。真实华为 Edge 的系统面板、文件管理器落盘和长期使用仍待用户验证。
- 三份维护 DOCX 仅追加记录，原文本与其他 ZIP 成员校验保持。当前依赖环境没有 LibreOffice，无法生成 PNG 做视觉复核；这些 DOCX 是内部维护记录，不作为本次用户交付物。
