# 小手机功能与设置入口目录（v1334）

本目录从客服同一份公开资料导出，共 143 项。使用入口：微信 → 我 → 设置 → 帮助与反馈 → 功能目录；也可从微信 → 我 → 服务 → 客服中心进入。

说明：网页已实现的功能与私人原生能力分别标注；开发中入口不算可用功能。具体权限与服务连接以当前设备为准。

## 设置与数据

### 聊天模型与 API 密钥

- 入口：主屏 → 设置 → 网络连接 → 聊天模型
- 范围：网页与私人 App；原生权限功能以设备支持为准

入口：主屏 → 设置 → 网络连接 → 聊天模型。
从小手机主屏进入“设置 → 网络连接 → 聊天模型”，依次填写接口地址、API Key 和准确的模型名，先点“测试连接”，成功后再保存。Key 只填密钥本身，不要带 Bearer、引号、空格或换行；客服不会读取、显示或替你核对完整 Key。

### 角色语音与音色

- 入口：主屏 → 设置 → 声音与通话
- 范围：网页与私人 App；原生权限功能以设备支持为准

全局语音接口：主屏 → 设置 → 声音与通话，配置语音平台、地址、Key、模型和默认音色。单个角色：微信 → 通讯录 → 角色资料 → 右上角 ⋯ → 聊天与主动 → 语音音色与路线，可选自己的音色和路线；未单独选择时跟随全局。客服不会索要你的 Key。

### 备份与换设备

- 入口：主屏 → 设置 → 授权与数据
- 范围：网页与私人 App；原生权限功能以设备支持为准

从“小手机主屏 → 设置 → 授权与数据”进入备份与恢复。换设备或清理浏览器数据前，先导出完整备份；导入后检查角色、聊天和设置。只导出美化不会包含聊天、人设或 API 配置。

### 图片与 AI 真图

- 入口：主屏 → 设置 → 图片与识别 → AI真图
- 范围：网页与私人 App；原生权限功能以设备支持为准

角色真照片与图片接口在“小手机主屏 → 设置 → 图片与识别 → AI真图”配置；聊天识图通常使用当前支持图片的聊天或识图线路。地址、Key 和模型要对应同一平台，并先测试成功。

### 回复方式与手动回复

- 入口：主屏 → 设置 → 角色、时间与消息
- 范围：网页与私人 App；原生权限功能以设备支持为准

在“小手机主屏 → 设置 → 角色、时间与消息”管理各场景的手动回复。开启后，微信、游戏、角色扮演或线下约会会显示“让ta回/让TA回应”；关闭对应场景后才按该场景的自动流程回复。生成失败时不会用固定假话冒充角色。

### 聊天 API 多路线

- 入口：主屏 → 设置 → 网络连接 → API 路线
- 范围：网页与私人 App；原生权限功能以设备支持为准

入口：主屏 → 设置 → 网络连接 → API 路线。
在“小手机主屏 → 设置 → 网络连接”可保存四条聊天 API 路线，每条同时保存主模型和辅助模型。聊天或游戏中的路线按钮只切换已经配置好的路线，从下一次回复起生效，不会中断正在生成的回复。

### 联网搜索

- 入口：主屏 → 设置 → 网络连接 → 联网搜索
- 范围：网页与私人 App；原生权限功能以设备支持为准

入口：主屏 → 设置 → 网络连接 → 联网搜索。
在“小手机主屏 → 设置 → 网络连接”配置联网搜索。它用于确实需要最新网页信息的功能；普通角色聊天不会因为开启联网就自动暴露 Key，也不能绕过网站登录、支付或平台风控。

### 图片识别

- 入口：主屏 → 设置 → 图片与识别 → 图片理解
- 范围：网页与私人 App；原生权限功能以设备支持为准

入口：主屏 → 设置 → 图片与识别 → 图片理解。
进入“小手机主屏 → 设置 → 图片与识别”配置识图地址、Key 和模型并先测试。聊天里发送图片后，只有支持图片的线路才能理解；配置失败时不会假装已经看见图片。

### 语音转文字

- 入口：主屏 → 设置 → 声音与通话 → 语音识别
- 范围：网页与私人 App；原生权限功能以设备支持为准

入口：主屏 → 设置 → 声音与通话 → 语音识别。
外置语音识别在“小手机主屏 → 设置 → 声音与通话”相关入口配置；私人 AI 账户也可能提供内置识别。放映室提取字幕会使用已配置的识别线路，大文件处理时需保持页面开启并查看任务进度。

### 主屏外观与布局

- 入口：主屏 → 设置 → 外观与主屏
- 范围：网页与私人 App；原生权限功能以设备支持为准

在“小手机主屏 → 设置 → 外观与主屏”调整壁纸、主题、App 图标、组件和时间显示。主屏长按 App 或组件可拖动换位、换页；完整桌面顺序和数据工具在“设置 → 授权与数据 → 桌面布局”。

### 锁屏与屏保

- 入口：主屏 → 设置 → 外观与主屏 → 锁屏壁纸
- 范围：网页与私人 App；原生权限功能以设备支持为准

主屏 → 设置 → 外观与主屏 → 锁屏壁纸，可上传、更换或恢复默认；同页“时间颜色（主屏 / 屏保）”调整数字颜色。“主屏幕时间和日期”的开关在“角色、时间与消息”。屏保的显示不等于系统后台权限。

### 手机授权与私人 App

- 入口：主屏 → 设置 → 授权与数据 → 手机授权
- 范围：网页与私人 App；原生权限功能以设备支持为准

入口：主屏 → 设置 → 授权与数据 → 手机授权。
在“小手机主屏 → 设置 → 授权与数据”查看手机授权、手机号账号和恢复方式。已经绑定的设备优先使用系统扫脸或指纹恢复；安装包版本、网页核心版本和原生桥版本是三项不同信息，不能只看其中一个判断是否更新成功。

### 存储、清理与数据安全

- 入口：主屏 → 设置 → 授权与数据
- 范围：网页与私人 App；原生权限功能以设备支持为准

在“小手机主屏 → 设置 → 授权与数据”查看存储、备份和清理工具。清缓存、清聊天、清空全部数据的范围不同，执行前必须看页面说明并先备份；不要通过客服发送 Key、Token、支付密码、银行卡资料或内部源码。

### 使用说明与常见报错

- 入口：主屏 → 设置 → 使用说明书 · 常见报错
- 范围：网页与私人 App；原生权限功能以设备支持为准

入口：主屏 → 设置 → 使用说明书 · 常见报错。
小手机主屏的“设置 → 使用说明”包含快速开始、聊天模型、语音、AI 真图、备份和常见接口报错。401 通常是 Key 无效，404 常见于地址或模型名错误，429 是请求过快或额度限制，Failed to fetch 多与网络或跨域有关。

### 回复长度与温度

- 入口：主屏 → 设置 → 网络连接 → 聊天模型
- 范围：当前 API 路线；保留已有设置

主屏 → 设置 → 网络连接 → 聊天模型，有“温度设置”和线上聊天、共同生活/线下、信件、通话四项回复长度。四项未设置时默认 4096；已有保存值不会被强行改写。长度是模型输出预算，不等于中文字数；平台仍可能限制上限。温度影响生成随机程度，模型不支持时以接口行为为准。

### 辅助模型

主屏 → 设置 → 网络连接 → 辅助模型。用于次要功能；填写模型名，地址和 Key 可按页面说明沿用主线路。切换主副模型不等于复制其他角色设定。

主屏 → 设置 → 角色、时间与消息。可设置微信自动总结模型、长期记忆引用上限、对话总结引用上限、每轮记忆合计上限和线下约会总结模型。改引用上限不等于删除已存记忆。

主屏 → 设置 → 角色、时间与消息。可设置时间感知、角色所在时区、角色主动记忆频率；设备时间与角色时区需分清。

主屏 → 设置 → 授权与数据。私人 App 支持时进入手机号账号和云备份，按页面登录/绑定及查看备份状态。网页本地导出与私人每日云备份不是同一条链路，客服不能宣称已经备份成功。

### 邀请码网络报错

- 入口：主屏 → 设置 → 授权与数据 → 手机授权

主屏 → 设置 → 授权与数据 → 手机授权。邀请码激活还需授权服务可达；网页加载成功不代表授权接口已连通。“只支持POST请求”是直接打开接口时的响应，不等于邀请码错误。备用入口接回原授权服务，不另建管理员用户库；健康检查成功仍需实际激活并核对后台登记。不要反复消费或公开完整邀请码。

### 版本与更新

- 入口：主屏 → 设置
- 范围：按页面对应范围；原生能力仅在支持设备显示

主屏 → 设置。设置中查看当前已加载版本。网页核心、私人内置网页和原生安装包版本不同；网页更新不等于私人 App 已重新安装。更新前保留本地数据，不要把清除全部站点数据当作普通刷新。

## 微信与角色

### 聊天气泡

- 入口：微信 → 通讯录 → 角色资料 → 右上角 ⋯ → 资料与记忆 → 微信气泡美化
- 范围：网页与私人 App；原生权限功能以设备支持为准

全局默认气泡：微信 → 我 → 设置 → 界面与显示 → 全局聊天气泡。只改一个角色：微信 → 通讯录 → 角色资料 → 右上角 ⋯ → 资料与记忆 → 微信气泡美化。共同生活和线下约会气泡在各自页面的“外观”调整。

### 角色顶部心情

- 入口：微信 → 我 → 设置 → 界面与显示 → 顶部心情
- 范围：网页与私人 App；原生权限功能以设备支持为准

在“微信 → 我 → 设置 → 界面与显示 → 顶部心情”开启。开启后，角色有新的心情或心声内容时，会固定显示在角色聊天顶部；当前还没有有效的新心情内容时不会显示旧内容或空白气泡。点气泡可以查看完整内容。

### 扫码添加好友

- 入口：微信 → 首页右上角 ＋ → 扫一扫
- 范围：网页与私人 App；原生权限功能以设备支持为准

入口：微信 → 首页右上角 ＋ → 扫一扫。
在“微信 → 我”点右上角二维码可打开“我的二维码”。另一台小手机从微信首页右上角“＋ → 扫一扫”，可用相机或相册识别二维码并发起好友申请。二维码只编码小手机好友 ID，不包含聊天、密钥或支付资料。

### 聊天收藏

- 入口：微信 → 我 → 收藏
- 范围：网页与私人 App；原生权限功能以设备支持为准

在角色聊天里长按文字、语音或图片，选择“收藏”。随后到“微信 → 我 → 收藏”查看；语音可重复播放，图片可打开，点“取消收藏”即可删除该条收藏。

### 朋友圈与相册

- 入口：微信 → 我 → 朋友圈
- 范围：网页与私人 App；原生权限功能以设备支持为准

“微信 → 我 → 朋友圈”会按本周、本月和月份整理已经发布的朋友圈图片。点击图片可查看；长按并确认删除，会删除图片对应的整条朋友圈，文字和互动也会一起删除。

### 附近的人与新朋友

- 入口：微信 → 通讯录 → 新的朋友
- 范围：网页与私人 App；原生权限功能以设备支持为准

入口：微信 → 通讯录 → 新的朋友。
微信 → 通讯录可查看“新的朋友”；微信 → 发现 → 附近的人，可浏览资料和处理交友。生成角色与真人好友是不同入口；真人好友在“微信 → 通讯录 → 小手机好友”用好友 ID 添加，或通过扫一扫识别二维码。遇到骚扰可拒绝、删除或拉黑。

### 群聊

- 入口：微信 → 首页右上角 ＋ → 发起群聊
- 范围：网页与私人 App；原生权限功能以设备支持为准

入口：微信 → 首页右上角 ＋ → 发起群聊。
从微信首页右上角“＋ → 发起群聊”选择成员即可建群。群聊外观会跟随微信深浅主题，已有群成员、消息与聊天记录不会因为换主题而改变。

### 通知与后台消息

- 入口：微信 → 通讯录 → 角色资料 → 右上角 ⋯ → 聊天与主动 → 主动消息
- 范围：网页与私人 App；原生权限功能以设备支持为准

单个角色主动联系：微信 → 通讯录 → 角色资料 → 右上角 ⋯ → 聊天与主动 → 主动消息、每天次数和额外间隔。全局开关与后台通知：主屏 → 设置 → 角色、时间与消息。微信提示音：微信 → 我 → 设置 → 聊天 → 通知声音。私人端支持时可配置“关闭小手机后仍可主动联系”，还需绑定伴生设备和系统通知权限；普通网页被系统结束后不能保证通知。

### 微信账号切换

在“微信 → 我 → 设置 → 切换账号”管理小号和角色微信登录。切换身份不会合并不同账号的聊天；移除登录记录也不会删除角色或原有聊天。

## 表情包与聊天

### 表情包设置

- 入口：主屏 → 设置 → 聊天与媒体 → 角色的表情包
- 范围：按用途分为自己的表情、角色素材和单角色偏好

表情包分三处：
1. 让角色发的素材：主屏 → 设置 → 聊天与媒体 → 角色的表情包，可上传图片、URL 添加、批量上传、管理文件夹。
2. 自己发的表情：微信 → 角色聊天 → 输入框旁的笑脸 → 自定义表情 → ＋ 添加 / 批量。真人好友聊天也可点 ＋ → 添加表情 / 批量添加。
3. 只给某个角色指定分区或禁用：微信 → 通讯录 → 角色资料 → 右上角 ⋯ → 资料与记忆 → 人设 → 聊天偏好 → 常用表情包分区 / 不让角色发表情包，保存后生效。
“微信 → 我 → 表情”目前显示动态表情开发中，不是上述素材的管理入口。

### 自己的表情包

- 入口：微信 → 角色聊天 → 输入框旁笑脸 → 自定义表情
- 范围：当前本机自己的表情库

入口：微信 → 角色聊天 → 输入框旁笑脸 → 自定义表情。
进入角色聊天，点输入框旁笑脸，在“自定义表情”点“＋ 添加”上传图片并写含义，或点“批量”。真人好友聊天可从“＋ → 添加表情 / 批量添加”导入。自己的表情库和供角色使用的素材库是两处设置。

### 角色表情包素材

- 入口：主屏 → 设置 → 聊天与媒体 → 角色的表情包
- 范围：全局素材库，角色可限制分区

主屏 → 设置 → 聊天与媒体 → 角色的表情包，支持“上传图片”“URL添加”“批量上传”“管理文件夹”。填写含义帮助角色选择。角色的使用分区在其人设编辑页“聊天偏好”选择。

### 表情包分区与禁用

- 入口：微信 → 通讯录 → 角色资料 → 右上角 ⋯ → 资料与记忆 → 人设 → 聊天偏好 → 常用表情包分区
- 范围：只影响当前角色

入口：微信 → 通讯录 → 角色资料 → 右上角 ⋯ → 资料与记忆 → 人设 → 聊天偏好 → 常用表情包分区。
先到 主屏 → 设置 → 聊天与媒体 → 角色的表情包 → 管理文件夹，整理素材。然后到 微信 → 通讯录 → 角色资料 → 右上角 ⋯ → 资料与记忆 → 人设 → 聊天偏好，选择“常用表情包分区”并保存；不选分区可用全部，选择后只用所选分区。开启“不让角色发表情包”可单独禁止当前角色发表情。

### 表情与语音频率

- 入口：主屏 → 设置 → 聊天与媒体
- 范围：全局倾向；单角色禁用仍有效

主屏 → 设置 → 聊天与媒体 有“角色发表情频率”和“角色发语音频率”。表情频率可选关闭、偶尔、适中、经常；它调整倾向，不保证每条回复都发送。单角色禁止表情在其聊天偏好里设置。

### 动态表情页面状态

- 入口：微信 → 我 → 表情
- 范围：开发中入口

“微信 → 我 → 表情”目前是“动态表情开发中”说明页，没有可用的动态表情仓库。已有的自定义表情在聊天笑脸里添加；角色素材到 主屏 → 设置 → 聊天与媒体 → 角色的表情包管理。

## 智能家电

### 智能家电与小灯

- 入口：微信 → 我 → 服务 → 智能家电
- 范围：网页 Windows 助手 / 私人 App HomeKit，能力不同

微信 → 我 → 服务 → 智能家电。网页需连接已配对的 Windows 助手；支持的私人 App 可允许访问苹果家庭、读取并选择灯具。可控制开关、亮度、颜色/色温并重新读取真实状态；离线或未连接不能当成控制成功。

### 私人智能门锁

- 入口：微信 → 我 → 服务 → 智能家电 → 门锁
- 范围：仅支持的私人 App

微信 → 我 → 服务 → 智能家电 → 门锁。仅支持 HomeKit 的私人 App：读取苹果家庭门锁，选择目标设备，可关锁或通过 Face ID 解锁；真实状态和权限以设备回读为准。网页没有这条原生门锁能力。

### 私人智能空调

- 入口：微信 → 我 → 服务 → 智能家电 → 空调
- 范围：仅支持的私人 App

微信 → 我 → 服务 → 智能家电 → 空调。仅支持 HomeKit 的私人 App：读取苹果家庭空调，选择设备，控制开关、模式与目标温度；可用模式及温度范围按设备能力显示。网页没有这条原生空调能力。
