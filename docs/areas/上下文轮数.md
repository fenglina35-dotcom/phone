# 上下文轮数（带给角色的聊天记录）

## 现在怎么算
- 一轮＝你在他回复前说的全部（不管几条）＋他那一次回复（不管几个气泡、几句、几段旁白）。
- 微信：`lastRounds`（src/app/004）。你连发几条到他回之前算一轮；他隔 5 分钟以上主动发来算新一轮；一通电话整段算一轮。系统提示（type sys）不算。设置项 `S.settings.hist`。
- 共同生活 / 单次约会：`offlineHistoryMessages`（src/app/023）先把同一方连续的话合并，再按轮截。设置项：共同生活 `cohabSettings(d).contextLimit`，约会 `S.settings.offHist`。
- 角色扮演：rpAI将本局台词/旁白映射双方后复用lastRounds；设置rpData(id).settings.hist，默认30轮、10–100轮，旧数字保留、单位改轮；不改原文/存档/总结。
- 电话：`callPromptHistory`（src/app/040）同人连说合成一段，从最新往前装，本通电话最先；默认 30000 字（上限 40000），最新六成内容不压缩，更早的单条超过 1800 字才压缩。

## 线上线下互相同步（SYNC_ROUNDS_V1，2026-11-04）
- 设置→聊天与媒体「线上线下互相同步」，`S.settings.syncRounds`，默认 20 轮（2~60），`syncRoundsLimit()`。
- 共同生活/约会看微信电话：`offlineOnlineRoundRows`（lastRounds 取 N 轮，电话一通算一轮、最多最后约 1500 字）；看现场：`syncSceneRowCount`。合并后 `offlineTimelinePromptRows` 最多 30000 字。当前现场条目只留前 40 字（全文在它自己的历史里），锚点保留原文；刚从微信回来、历史被省略时不缩。
