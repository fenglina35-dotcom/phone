## Mac 安装步骤

1. 不要先删除 iPhone 上现有的小手机 App，以免失去原数据容器。
2. 完整解压本次 ZIP 到一个全新目录，打开 `PhoneCompanionTest.xcodeproj`。
3. 在 Xcode 中确认各 Target 的 Version 为 `1.0.306`、Build 为 `306`，继续使用原来的 Team、Bundle Identifier、Automatic Signing、Provisioning Profile 和 Entitlements。
4. 执行 Product → Clean Build Folder，再连接原来的真实 iPhone，选择正确 Target 后直接 Run 覆盖安装。
5. 正常启动后确认设置页显示网页核心 `v1180`、私人 iOS `1.0.306 (306)`、原生桥 `35`。
