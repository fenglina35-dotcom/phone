# 第二百零九次安装：v1084 / 私人 iOS 1.0.209（209）

本包是完整 Mac Xcode 源码包，不是 Windows 编译出的 IPA。请新建目录完整解压，不要覆盖旧包，再用 Xcode 打开 `PhoneCompanionTest.xcodeproj`。

本次重点：

- 前台正常聊天不再提前创建服务器回复接力，避免刚回复完又调用一次模型并重复发同一组话；只有 App 真正退到后台才启用接力。回到前台时，有本地回复继续或已经显示才取消远端接力；本地已中断且没有回复时保留唯一接力。
- 后台服务器正确识别微信、电话和共同生活上下文；已完成的前台回合在生成前与发送前都会作废接力，客户端还会拦住完全相同的旧接力消息。
- 真实睡眠只使用最近七天 HealthKit 的最新睡眠段，合并重叠阶段但不重复累加；通话陪睡间隔不再冒充手表睡眠。
- App 达到每日限额时显示红色“今日限额已达到”，与角色或手动锁定分开，并在真实使用已超限时及时补锁；昨天的缓存报告不能触发今天补锁。
- v1083 的通话后台静默、挂断重计时、共同生活消息畅通和真实后台时间继续保留。

Mac 操作：

1. Xcode 打开工程后先执行 Product → Clean Build Folder。
2. 选择你自己的 Team 与签名，确认版本为 1.0.209、Build 为 209。
3. 编译并覆盖安装到真实 iPhone。
4. 真机重点验证：正常前台聊天不产生第二次后台模型调用；退后台后接力仍能送达；通话期间普通后台主动消息保持安静；睡眠与限额锁原因显示正确。

Windows 自动测试、浏览器页面检查和 ZIP 校验不能代替 Mac 编译、签名及真机结论。
