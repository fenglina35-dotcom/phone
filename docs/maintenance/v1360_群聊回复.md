# v1360（网页）群聊回复：收钱后开口、没回时说原因

仅网页；私人版未同步。

## 用户反馈
v1358 后群里转账、发红包，角色收了/抢了却不回话；每个角色的三个点闪一下就没了；后来正常说话也没人回。

## 查到的
- 转账、红包原来在发出的同一瞬间就叫角色回话，那时角色还没收钱/抢红包；收下之后没有任何触发，所以「收了不回」。
- groupRoleReplyItems 把模型报错和解析后为空都吞掉（catch(_){}），角色一个个显示三个点后安静退出，界面上看不出原因。本地用假模型服务器走完整 chatAPI 流程，普通说话、转账、红包都能回；用户手机上的真实失败原因只有提示出来才能确定。

## 改动
- 群转账：角色收下后再 aiGroupReply（点名收款人）。
- 我发的群红包：角色抢完后再统一 aiGroupReply；群记录里的红包写明谁抢了多少。
- 一轮下来一个角色都没说上话、又不是大家选择沉默：弹提示「群里没人回上：原因」（接口报错原文，或「回复里没有能发出来的内容」），并记在 g.replyFail。
