# v1344 网页 / 私人源码同步（不打包，私人版本号仍为 v1341）

基线：origin/main `339fc654`（网页 v1342 / 私人 v1341 / iOS 1.0.400）。

## 1. 旧转账被收款时显示成文字「[收款]」

- 现象：角色主动消息里出现一条纯文字气泡「[收款]」，转账卡片没有变成已收款。
- 根因：`modelOutputUnfiltered()` 已恒为真（原文模式全局默认），回复循环在原文模式下既不去掉行首尾空白，也不做 `normTag`。模型写成 ` [收款]` 或 `[内心|…] [收款]` 时，去掉内心标签后留下前导空格，`^\[收款…\]$` 匹配失败，整行被当普通文字发出。
- 修复：原文模式下，只有「整行就是一个方括号标签」的行才去空白并 `normTag`，普通文字仍保持原文。
- 验证：浏览器实测两种写法都执行收款、生成回执卡片，气泡里不再出现「收款」。

## 2. 角色联网搜索结果卡片

- 现象：聊天里直接显示 `[联网|雅马哈 Disklavier 白色立式钢琴 外观]`，没有搜索结果。
- 根因：联网执行代码位于 `if(!_rawOutput){…}` 块内，原文模式恒为真，所以角色的 `[联网|…]` 从未执行；循环里过滤该标签的判断也带 `!_rawOutput`，于是标签原样显示。
- 修复：联网执行移出该块（它是执行角色决定，不是输出过滤）；标签在任何模式下都不显示。搜索成功时由角色发出 `weblink`（`webShare:true`）结果卡片：标题为搜索词，列出前两条结果与来源域名，点开是完整结果列表，每条带摘要与原网页链接（仅 http/https）。程序主动联网（天气、新闻等）成功时同样发卡片。搜索失败或未开启联网时不发卡片、不显示标签。
- 历史上下文：角色自己发的卡片以「我把联网搜到的…结果卡片分享给你」进入模型历史；用户转发的旧网页卡片样式与文案不变。

## 3. 外卖偏好乱记

- 现象：「好想出国啊…不喜欢呆在中国了…」被记成「不喜欢」外卖偏好；「我想喝燕麦牛奶粥」「我都吃完丢了…」被记成「不喜欢 皮蛋瘦肉粥」。
- 根因：兜底规则只要句子里出现喜欢/不喜欢就把整句当商品；模型的 `[外卖记忆|…]` 标签没有核对用户本轮是否真的表达了该态度。
- 修复：兜底只接受 20 字内、无句读、像食物或已点名品牌的目标；模型标签的态度必须能在用户本轮原话里找到对应词（喜欢/不喜欢/默认/忌口/删除），且目标必须是食物、品牌或最近真实订单。已记下的错误条目不自动删除，用户可在「角色学会的外卖偏好」里点删除。

## 4. 白色主题表情包黑色包边

- 根因：`.estk .s` 固定深色底 `#2c2c2e`，白色主题没有覆盖。
- 修复：`.wxlight .estk .s` 白底细描边，说明文字改灰。网页与私人三个外壳同步。

## 5. 代付卡片商品名被截断

- 根因：代付请求、代付成功、婉拒代付三种卡片的商品名为单行省略。
- 修复：标签与金额同一行，商品名单独一行完整换行显示，卡片随内容增高。

## 6. 删除抖音私信黑屏

- 根因：在私信页「···」里删除整个会话后仍停留在 `dydm` 页，`renderDyDM` 找不到会话返回空字符串。
- 修复：删除的正是当前打开的会话时退回上一页；X 私信同一函数同样处理。

## 7. 日常事件从来不记

- 根因：证据必须逐字包含在「最后一条」用户消息里。用户连发多条时，模型引用前面那条即被丢弃；全半角标点差一个字符也被丢弃。
- 修复：证据可来自本轮（上一条角色回复之后）用户连发的任一条，比对时忽略空白与中英文标点差异；已发生/已解决的降级判断只看证据所在那条原话。伪造（原话里没有）的证据仍然拒绝。
- 注意：该功能默认关闭，需在「查手机 → 日常事件簿」里打开。
