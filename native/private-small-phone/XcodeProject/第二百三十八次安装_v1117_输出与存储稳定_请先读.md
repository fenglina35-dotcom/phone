# 第二百三十八次安装：v1117 / 私人 iOS 1.0.238（238）

本版集中修复模型输出安全、存储用量显示、真人好友头像稳定性和无二维码订单卡片。

- 线上微信前台与后台主动消息会拦截明确的内部分析、指令解析和思维链；异常结果最多限次纠正，仍不合格时不会把内部内容显示成角色消息。
- 混在正常微信里的明确第三人称动作或环境旁白只删除异常行，正常对话和功能标签保持原样；纯旁白才进入纠正流程。
- 模型漏掉内心标签时只补取内心，不重写可见回复；补取失败会隐藏过期内心，角色正文仍然正常显示。
- 私人 App 的存储用量把主存档与保护副本分开说明，避免把安全双副本误认为图片重复增长。
- 真人好友头像会先转成可跨设备读取的安全缩略图，并在本地缓存失败时保留原始回退，不再依赖另一台设备无法识别的本地图片键。
- 真实外卖订单即使暂时没有付款二维码，也会显示订单事实卡片并安排角色自然回复；只有平台明确回执为已付款或后续状态时才允许说已付款，重复回调不会重复建卡。

Windows 已完成专项与全量自动测试；本机没有 Mac 编译签名环境，因此没有声称完成真实 iPhone 编译、签名、真机模型链路或真实支付链路验收。
