# 第三百零九次安装：v1183 共同生活键盘与安卓唱片配色修复版

本目录是私人 iOS `1.0.309 (309)`、网页与私人共用版本 `v1183` 的 Mac 待编译源码。原生桥 35 保持不变。

本包对应网页与私人版共同版本：网页源码和私人内置页面均为 v1183，并完整保留 v1182 的连续性、记忆和多人剧场修复。

## 本轮可见修复

1. 私人版共同生活恢复单一键盘布局所有者：WKWebView 保持固定，私人内置页面不再同时触发 `resizes-content`，避免输入栏上下弹动以及下半屏短暂全黑。
2. 共同生活已打开键盘时切换“旁白／对话”不再强制重新聚焦，保持当前输入焦点，避免键盘收起后又立刻弹回。
3. 安卓主屏唱片颜色增加直接可点的兼容色块；原生颜色选择器同时响应输入与完成事件，改色时不重绘整页。
4. 音乐 App 内的自定义唱片颜色同样采用不重绘页面的即时更新，且继续与主屏唱片颜色互不影响。

## Mac 编译与真机验收

1. 在 Mac 完整解压本包，使用 Xcode 打开 `PhoneCompanionTest.xcodeproj`。
2. 选择原来的 Team、Bundle Identifier 和目标 iPhone，直接 Build／Run；不要先删除手机旧 App，以保留数据容器。
3. 启动后确认设置页可见 `v1183`，原生诊断可见 `1.0.309 (309)`。
4. 在共同生活输入框唤起键盘，不关闭键盘连续切换“旁白／对话”，确认焦点仍在输入框、输入栏始终位于键盘上方；再关闭键盘检查动画及是否出现黑屏空区。
5. 在安卓设备打开“外观与主屏 → 主屏组件”，先点兼容色块，再用系统颜色选择器，确认主屏唱片立即变色且重新打开后仍保留。
6. 分别复测 v1182 的重复查看微信、进食状态连续性和“角色要求记忆”的第一人称结果。

Windows 自动测试、浏览器预览和 ZIP 文件核验不能证明私人包已在真实 iPhone 上正常运行；完成签名、安装、启动和上述触控操作后，才能算真机验收通过。
