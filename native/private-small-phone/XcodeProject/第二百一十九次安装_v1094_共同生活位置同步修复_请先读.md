# 第二百一十九次安装：v1094 共同生活位置同步修复

- 网页版本：v1094
- 私人 iOS：1.0.219（219）
- 原生桥：25

本版修正线上微信与共同生活顶部状态的同一轮位置同步，并完整保留 v1093 已有功能：

1. 旧状态为“上班／外出／回家路上”时，角色若真实输出卧室、客厅等共同生活位置标签，会先完成到家状态再写入房间，不再静默拒绝位置。
2. 即使模型没有输出隐藏标签，用户明确提出一起去某个家中房间且角色本轮明确带、抱、牵或陪用户过去，也会在同一轮同步成“在家 · 在该房间”。
3. “要不要去”“等回家再去”、拒绝、仍在路上等询问、延后和否定语句不会被误判为已经到家。
4. 不制造角色台词、不额外调用模型；只依据本轮用户原话与角色真实回复更新共同生活状态。

Windows 已执行自动化与包结构校验，但不能替代 Mac 编译、签名和真实 iPhone 验收。安装后请重点复测：顶部为“回家路上”时在线上说“去卧室说”，角色明确同意并带你过去后，顶部应立即变为“在家 · 在卧室”。
