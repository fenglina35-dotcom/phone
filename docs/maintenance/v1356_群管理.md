# v1356（网页）群管理

仅网页；私人版未同步（私人仍为 v1357 / iOS 1.0.422）。在 v1354 群聊改版基础上。

## 用户要求
群管理做成独立页面（群管理员说明 + 添加成员 → 选择群成员）；管理员可以禁言、踢人，和抖音一样；只有情侣关系的管理员才能禁言群主；角色相关设置单独一页，删掉与聊天信息页重复的旧按钮；真人群旧弹窗（群成员/备注/气泡/邀请/清空/解散）不再出现。

## 规则（gmCanActOn）
- 群主可以管所有人（除自己）；最多 3 个管理员（GROUP_ADMIN_MAX）。
- 管理员只能禁言/踢普通成员，不能动群主和其他管理员。
- 角色群：群主是我；只有 `S.couple.cid` 且是管理员的角色能禁言我，谁也不能踢我。
- 被禁言：角色群的角色本轮起不再发言；我被禁言时输入框换成“你已被禁言，X后解除”，sendGroup 拦截。

## 角色群
- 管理员角色可在回复里单独一行写 `[禁言|名字|分钟]` `[解禁|名字]` `[踢出|名字]`（groupRoleAdminTags），按上面的规则校验，群里出现系统提示；gContext 告诉每个角色当前管理员、被禁言的人，以及自己有没有权限。
- 「角色设置」页（gsettings）：群头像、谁会回复、回复条数、群关系网、补充关系、气泡美化。

## 真人群
- 管理员名单、禁言通过隐藏群消息 `group_admins`（只认群主发）/`group_mute`（群主或管理员）同步，各自小手机校验后生效，不显示成消息。
- 服务器 `phone_friend_group_remove_member` 只允许群主调用：管理员踢人发 `group_kick_request`，群主的小手机同步时校验后代为执行（每条申请只执行一次）。
- 群管理页里保留「群聊气泡美化」。

## 已知限制
- 真人群管理员踢人要等群主小手机打开同步；禁言靠各成员的小手机执行。
- 两台真机未实测。
