# 第一百四十八次安装：v1027 X 网友评论风格

## 本次版本

- 网页：v1027
- 私人 iOS：1.0.148（148）
- 原生桥：25
- 工程目录：`SmallPhone_v1027_XNetCommentTone`

## 本次新增

1. X「我的主页」增加“网友评论风格”，可选择“友善”“恶劣”或“一半一半”。
2. 旧用户第一次打开时默认“一半一半”，保持原先混合评论体验。
3. 设置同时作用于本人发推后的自动网友评论，以及推文详情右上角刷新生成的网友评论。
4. 只改变网友评论；角色本人的模型评论、其他人的推文、X 私信、微信、朋友圈和抖音不受影响。
5. “恶劣”可以生成挑刺、抬杠、阴阳怪气或黑粉式吐槽，但明确禁止威胁、仇恨歧视、人肉隐私、暴力和违法内容。

## 安装与核对

1. 在 Mac 新目录完整解压本包，不覆盖旧工程目录。
2. 打开 `PhoneCompanionTest.xcodeproj`，选择 `PhoneCompanionTest` Scheme 和真实 iPhone。
3. 执行 `Product → Clean Build Folder` 后覆盖安装；不要删除手机上原来的私人 App，以保留现有数据。
4. 设置页确认网页 v1027、私人 iOS 1.0.148（148）、原生桥 25。
5. 打开 X → 我的主页，依次选择三种网友评论风格，发一条测试推文并查看自动评论；进入推文详情后点右上角刷新，再核对新评论风格。
