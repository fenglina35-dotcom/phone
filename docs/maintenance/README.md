# v1318 / v1319 · 共同生活的外观、多选删除和「让TA回」，四个毛病三个根子

她发来两张截图：共同生活和一次性约会。共同生活那边「让TA回」点不动、点下去弹出删除消息，
没有外观、不能换背景气泡，不能多选删除，换回经典主题按钮还会消失。
**四个现象，量下来是三个互不相干的根子。**

## 一、「让TA回」点不动 —— 层叠上下文，不是按钮本身

`elementsFromPoint` 打在按钮正中央，返回的第一个是 `.scroll.offscroll`，按钮排第二。

`.offstage>*{position:relative;z-index:1}` 给舞台的**每个直接子级**都发了 `z-index:1`。
`.cohab-settings-wrap`（设置面板，按钮的定位父级）和 `.cohab-scroll`（消息列表）因此都是 1，
列表排在后面就赢。按钮自己写着 `z-index:6` 一点用都没有——**它被关在设置面板那个
层叠上下文里面，最高也只能到 1**。所以每次点都落在消息上，`offMsgMenu` 弹出来，
那个弹窗里第一个按钮就是「删除」。她说的「点到了删除消息的按钮」一字不差。

改法一行：`.cohab-settings-wrap{z-index:6}`。
按钮还绝对定位在 `top:43px`（已经掉出 39px 高的父级），所以同时给舞台加 `cohab-has-reply`，
让 `.cohab-scroll` 空出 46px，按钮不再骑在第一条消息上。

**经典主题按钮"消失"是同一件事**，不是另一个 bug：抬层之后，经典主题下那颗实心的
`.cohab-debug-reply` 照样看得见、点得到（量过 `elementFromPoint` 返回按钮本身）。

## 二、没有「外观」 —— 三列网格塞了四个孩子

`.cohab-meta{display:grid;grid-template-columns:1fr auto 1fr}`，
里面却是 span + time + 外观 + 测试控制 **四个**。第四个被挤到 31px 高的第二行，看不见。
量出来：外观在 x=359（贴着右边缘），测试控制掉到 y=65（那一行只到 y≈59）。

三个按钮收进一个 `<span class="cohab-meta-acts">`，那一行又是三个格子。
390px 和 320px 两个宽度都量过，三个按钮同一行、都在屏幕内。

## 三、不能多选删除 —— 又是"功能整条在，只差入口"

1. **第一次**：只把里面那层 `:before` 的白渐变撤成 `transparent`。她说「还是有明显的

- **描边在 `:before` 上，剪成环**：同一条轮廓正着走一圈、再往里缩 `0.75px` **倒着**走一圈，

按钮和输入框是圆角矩形，不能用多边形，改用 `padding:.8px` ＋ `mask-composite:exclude`
把中间挖掉——一样是环，一样中间不糊白。输入框那圈的白和提亮都单独调轻
（`.5` 对 `.72`、`1.34` 对 `1.72`），因为她说过「输入框两边白色的晕染太多，
上面的字都看不清，那个小话筒也看不清」。

**一条规矩留给以后**：任何铺满整块形状的白，只要**压在 `backdrop-filter` 下面**，
就一定会被糊成一片奶白雾。要么白不存在于内部（环 / 边缘渐晕），要么白不在模糊层下面。

测试卡死的是结构，不是数值：环的点数必须是「外圈 n ＋内圈 n ＋两个接缝点」、
两条桥必须完全重合（否则环会豁口）、环宽必须在 0.6–1.3px、身子那一层一点白都不许画、
描边层不许带 blur、按钮那圈必须真挖空且不超过 1.2px。

### 第二轮：她说高光太粗、还有一道很明显的分界线

那个 6px 的折射圈是错的。圈有宽度，圈的内沿就是一道台阶，她一眼就问「你这个包边是什么，为什么会有这种很明显的分界线包边」。**现在整个换成两层剪影：**

- `.imsg-b` 按**外轮廓** `clip-path` 剪，它的 `background` 就是那条高光；
- `.imsg-b:before` 按**同一条轮廓往里缩 1.15px** 的内轮廓剪，装的是里面那层玻璃。

父元素的底色只能从这 1.15px 的缝里露出来——**缝多宽，高光就多细**，而且是真的沿着轮廓描的，连小尾巴都描得上，没有宽度就没有分界线。内轮廓不是手写的，是拿外轮廓做多边形内偏移算出来的（每条边沿内法线平移 1.15px，再和相邻边求交），所以两条轮廓点数一一对应、形状不会走样。脚本在 `scratchpad/p3/poly.py`。

按钮和输入框照同一套，只是它们有 `border-radius`，`:before` 直接 `inset:1px;border-radius:inherit` 就够了。为此气泡和按钮里的内容都包了一层 `<i>`（`position:relative;z-index:1`）——绝对定位的 `:before` 会盖住普通文字，不抬起来字就没了。

**高光跟着背景变颜色**（她要的「不是只有白色」）：描边那层自己带 `backdrop-filter:brightness(1.62) saturate(1.75)`，**不带 blur**——糊了就吸不到颜色。背景是暖的高光就偏暖、是蓝的就偏蓝；上面再叠一条 140° 的白渐变让它有虚有实。这条白渐变写在**基础样式**里而不是 `.hasbg` 里，所以**没换背景的时候也有高光**，这也是她点名要的。

**小尾巴改瘦了**：照她给的真 iMessage 截图，伸出从 8.2px 收到 **5.8px**、高从 15px 收到 **10px**，气泡身子的左边缘从 9px 挪到 7px，padding 跟着从 23px 改成 21px。
