# 小手机 v1268 / iOS 1.0.368（368）安装与验收

Mac 待编译的私人源码覆盖包，不是 IPA。公开网页已上线 v1268。上一包是 **v1267 / iOS 367**。

## 这一包里有什么

### 一、群聊按性格出场了

以前你一说话，系统就随机抓 1～3 个人接话，谁都一样。现在是主角＋配角：

- **恋人是主角**，你每说一句他一定接，但不固定第一个说——第一第二都可能
- **管理员优先**，一轮最多几个你自己定（默认 2 个）
- **其余的人靠性格**：每个人有个 0～100 的「话痨度」，从人设里猜出来的（活泼、社牛、话痨 → 高；内向、安静、社恐 → 低）。话痨的人经常冒泡，内向的人光靠性格永远说不上话
- **踩中他在意的词**才会把内向的人拽出来。比如吃货的「饿、吃、外卖」，你说「我好饿」他就出来了
- **可以冷场**。你随口说句「困了」，没人在意就真的没人接——这才像真的

话痨度和在意的词都能手动改：群成员页每个人右边有个「话痨度 XX」，点一下就能调。

一轮最多几人、管理员占几个、冷场几小时自己聊起来、一天最多自己聊几次，都在群设置 → 说话的规矩里。

### 二、群里冷场太久会自己活起来

超过你设的小时数没人说话，你一打开群就有人冒泡。一天有次数上限（默认 3 次），不会一直烧钱。设成 0 就关掉。

### 三、管理员能禁言、踢人了

角色自己决定要不要动手，按他的性格来。规矩是代码卡死的，不是靠他自觉：

- 普通成员发指令**不算数**
- **不能踢群主，不能踢管理员**
- **只有你的恋人能禁言你**，别的管理员一律驳回

群里会出系统提示：谁被谁禁言了多久、谁被移出了、谁被拉回来了。这些消息角色也看得见，所以下一轮他们都知道发生了什么。

被移出的人在群设置 → 被移出的人里能拉回来。

### 四、你被禁言的时候

输入框会灰掉锁死，上面写着「你被 XX 禁言了，还剩 43 分钟」。

**你自己解不开**，按钮都没有。旁边有个「去私信他」，点进去求他。他在私信里知道自己在群里禁言了你、还剩多久，放不放、要你说什么才放，完全按他性格来。他心软了就在私信里放你出来，群里同步解开。

### 五、火花改了

- 你和他**当天都**在抖音发过消息 → **+1**（一天最多一次）
- 有一方没发 → **定格不动**
- **永远不清零**，隔多久回来都还在，接着往上长

以前是漏一天就直接归零。

### 六、其他

- 抖音私聊他能**连发 1～4 条**了，不再每次只回一条
- **红点进页面就全清**（粉丝、访客、群通知），不用一个个点。顺带修掉了上一版我改坏的粉丝红点
- **IP 属地跟人设走**：人设里写了杭州就显示浙江，没写就按这个人固定一个（不会一刷一变），也能手动改。性别同理

## 装之前

- **不要**先删手机上的旧 App
- **不要**把源码覆盖到旧工程目录

解压到全新目录，打开 `PhoneCompanionTest.xcodeproj`，沿用原来的 Team、Bundle ID、签名和 entitlement，确认全部 Target 都是 **1.0.368 (368)** 之后覆盖安装。
