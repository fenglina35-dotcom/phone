# 小手机 v1256 / iOS 1.0.363（363）安装与验收

这是 Mac 待编译的私人源码覆盖包，不是 IPA。公开网页已上线 v1255。

## 这一版修了什么

**一、后台消息不再"接力赛"。**

你发完消息、他答完、你切后台再回来，服务器还会一遍遍重新生成，每一次都以为是第一次开口，全堆在锁屏上进不了聊天。

原因是：取消服务器任务的函数，全项目**只有一个调用点**——App 在前台自己把回复发出来。别的路都不取消，任务租约每两分钟到期就重新领走、**重新调一次模型**。

现在两条路都会取消。特别是"送不进去"那条（你在共同生活、线下、通话里）：**停掉服务器那边，但故意不确认收件**——他说的话留着，等你出来后补进聊天，**一个字都不丢**。另外服务器端补了重跑上限兜底。

**二、选了英文，不会再把混进来的中文念出来。**

两处漏洞，都只在"送去发声的那份文字"上，**屏幕上显示的和通话格式一个字没动**。现在所有语音合成的唯一入口加了一道语言锁，清不干净也绝不会把整句变成哑音。粤语和日语本来就用汉字，不在范围内。

**三、`[保持安静]` 不会再被当成一句话发给你。**

他决定这次不说话，结果小手机把他"决定不说话"这五个字推给了你。判定函数一直都在，只是推送那条路从不调用它。现在三条路都认得。

**四、真人好友点气泡能撤回了。**

撤回从来没被删过，缺的是气泡上的点击入口。现在点自己发的气泡会弹出「消息操作」：复制文字、收藏对方的表情、撤回。群聊头像的长按@和双击拍一拍不受影响。

**五、信件有自己的回复长度了。**

信以前是**写死 700／620，跟你任何设置都无关**，所以长一点的信必然被自己的上限截断。现在设置页「回复长度（共同生活/线下）」旁边多了一格 **「回复长度（信件）」**，默认 1200，最高 8192。

**六、回复被截断会自动补完，而且不再算成"重新生成"。**

以前这次补完调用完全不受控，补完的结果还被拦截记录当成第二份候选，所以你才会看到"内容对不上、像重复调用了一次"。现在补完保留（这样你把回复长度设短也不会断在半句），但不再计入候选。

**七、拦截页能看懂了。**

以前"被后续候选或本机处理替代"把"又花了一次钱"和"只是拆了个气泡"写成同一句。现在分开写，顶上直接写明 **「本轮模型调用：1 次（没有重新生成）」**。

**八、「通话防跳出角色」按你要求删掉了。** 它其实早就是关着的（判断条件恒为假），所以这是零行为变化的清理。

**九、两边跑偏的地方补齐了。** 线下和共同生活里，模型要是把思考过程吐出来，私人版以前不会拦，现在会。

## 安装步骤

1. 在 Mac 把压缩包解压到一个全新的目录。不要覆盖旧工程目录，也不要先删除 iPhone 上的旧小手机。
2. 打开 `PhoneCompanionTest.xcodeproj`，沿用原 Apple Account、Team、Bundle ID、签名和现有 entitlement。
3. 核对所有 Target 的 Marketing Version 均为 `1.0.363`，Build 均为 `363`，原生桥契约仍为 `38`，然后覆盖安装到真实 iPhone。
4. 打开"设置 → 授权与数据"，核对版本显示为私人 `1.0.363 (363)`。

## 验收

- **后台接力**：发条消息，等他答完，切后台，过十几分钟再回来。锁屏上**不该**再堆同一件事的好几条；聊天里该有的一条不少。
- **共同生活里被拦下的**：在共同生活时让他发消息，结束后回微信，确认那些话会补进来，没有丢。
- **英文通话**：专挑他往英文里塞中文的那种句子听，应该只剩英文。
- **`[保持安静]`**：如果再看到这五个字被当成消息发过来，立刻告诉我。
- **真人好友撤回**：点一下自己发的气泡，确认菜单弹得出来；群聊里也试试长按头像@和双击拍一拍。
- **信件**：先去设置里把「回复长度（信件）」调到你想要的长度，再让他写一封，确认不再断在半截。
- **拦截页**：随便打开一次，看顶上的「本轮模型调用」写的是几次。

Windows 已完成全量自动化回归与核心聊天发布门禁（网页与私人两个入口，页面错误 0）。Mac 编译、签名和真实 iPhone 上的实际表现仍待你确认。
