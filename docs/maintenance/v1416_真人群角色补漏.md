# v1416 真人群角色补漏

- 角色的气泡和其他群成员一样：渲染时传 `_roleView`，`pfMentionsMe` 遇到它返回 false，所以不再加「@到我」的高亮框。提醒照常。
- 晚到的旧消息：打开群后才同步下来、但时间在打开前 15 秒以前的消息，只有点他名字、而且时间比他最后一次发言还晚的才算漏看补一句，其余不当新消息。
- 不会重复补回：补回漏看的 @ 时，起点取「上次在群里的时间」和「他最后一次发言的时间」中较晚的那个（`lastOwnSay`）。
- 主人被禁言，或者这个群被情侣空间锁了（`quietByRule`）时，角色也不说话。原来他走 silent 发送，会绕过禁言检查。
- 每次打开群后，他的第一句 `role_say` 会顺带 96px 小头像，后加入或清过记录的人也能看到他的头像。
- 验证：
  - 原来的场景（模拟群、模拟服务器）都重新跑过。
  - 新加的场景都符合预期：晚到的旧闲聊不触发；比他最后发言还早的晚到 @ 不触发；被禁言不触发；角色气泡没有高亮框；头像只带一次。
  - 网页版和私人版都测过。
