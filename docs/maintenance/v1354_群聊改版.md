# v1354（网页）群聊改版

仅网页；私人版源码尚未同步（私人仍为 v1357 / iOS 1.0.422）。

## 用户要求
群聊太旧：加号面板在输入框上面、引用框老旧、回复机械；要像抖音群那样社恐话少、活跃话多，按性格和在意的话题回复；我说话后第一个回的必须是情侣空间绑定的角色；正在回复要有三个点；右上角 ⋯ 做成真实微信「聊天信息」页（角色群和真人群都要）；按钮一律绿色；气泡小箭头对准头像中间；加人、移出成员、群二维码、查找聊天内容都是独立页面；二维码要真实可扫并能进群；黑白主题都兼容。

## 实现
- 面板：`#gpanel,#pfgpanel{order:2}`，和单聊 `#panel` 一样排在输入框下。
- 引用：`groupQuoteBar` 使用单聊的 `chat-quote-sent`，放在气泡下面。
- 回复：`groupReplyPlan` —— 情侣角色（`S.couple.cid`）必回且排第一，被点名的必回；其他人按人设关键词分 quiet / normal / lively，并按用户这句话与人设是否有两字重合判断“在意”；quiet 常不开口、开口只 1 句，lively 可多一条。模型可输出 `[不说话]` 主动沉默（非情侣角色不重试）。`groupTypingSet` 在生成期间显示三个点。
- 聊天信息页 `ginfo`：成员网格 +/−、群聊名称、群二维码、群公告（角色会读到）、群管理（原群设置弹窗）、备注、查找聊天内容、免打扰（角色群不响不弹；真人群 @我 仍提醒）、置顶、保存到通讯录（仅记住开关）、我在本群的昵称、显示群成员昵称、单独聊天背景、清空、投诉（仅提示）、退出/解散。
- `gpick` 加人/移出成员页；`gqr` 群二维码页；`gsearch` 查找聊天内容页（15 个分类，按消息类型筛选）。
- 气泡箭头：名字行固定高度 `.gname`，`.gnamed` 时头像下移 23px，浏览器实测箭头中线与头像中线重合。
- 群二维码：`smallphone_group=…&from=…&t=…&exp=…`（7 天）。服务器 `phone_friend_group_invite` 只允许邀请好友、没有凭码入群接口，所以扫码方发暗号 `group_join_request`（不存、不显示）→ 出示方同步时校验自己发出的未过期令牌 → 用现有好友邀请拉人 → 扫码方收到对应邀请自动接受。非好友先发好友申请，通过后自动申请。角色群二维码只在本机打开。

## 已知限制
- 真人群扫码进群要求双方是好友，且出示方的小手机需打开同步一次；要做到陌生人秒进需新增服务器函数。
- 真人群群名、我的群昵称不能改；群公告只存在本机。
- 两台真机扫码未实测。
