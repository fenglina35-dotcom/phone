# 小手机 v1240 / iOS 1.0.356（356）安装与验收

这是 Mac 待编译的私人源码覆盖包，不是 IPA。公开网页保持 v1239。

1. 在 Mac 把压缩包解压到一个全新的目录。不要覆盖旧工程目录，也不要先删除 iPhone 上的旧小手机。
2. 打开 `PhoneCompanionTest.xcodeproj`，沿用原 Apple Account、Team、Bundle ID、签名、HomeKit、Screen Time、通知和其他 entitlement。
3. 核对所有 Target 的 Marketing Version 均为 `1.0.356`，Build 均为 `356`，然后覆盖安装到真实 iPhone。
4. 打开“设置 → 授权与数据”，核对显示 `v1240 · 私人每日云备份` 和 `1.0.356 (356)`。点“刷新状态”只能证明账号小请求正常。
5. 保持 App 在前台，点“立即备份本机”。必须等到“手机号云备份已更新；今日自动备份已完成”，再点刷新状态确认云备份时间和大小已更新。出现超时或只停在“正在上传”不能算成功。
6. 首次成功手动备份后，每日备份才把这台设备视为已确认来源。第二天让 App 在前台空闲约 90 秒，核对当天只成功一次。若云端有其他设备更新，自动备份应停止并要求手动确认，不得直接覆盖。
7. 用“从云端恢复”检查恢复预览和数据量；确认后恢复，验收聊天、角色、图片及设置仍在。失败时旧云备份必须仍可见。

Windows 已验证分块顺序、失败中止、只在云端确认成功后记录当天状态，以及大存档导出/导入和核心聊天回归。Mac 编译、签名、真实 iPhone 网络上传、跨日调度和恢复尚未验证，不能据此称真机已经修好。
