# v1726 七项修复（网页 1726；私人源码同步，未升私人版本号、未打包）

她一次报了 7 个问题，这里逐条记录原因和改法。

## 1. 角色点外卖「商品或规格方案未通过校验」，之后每轮都重试
- 现象：她说「啥都行」，角色下单失败，显示的是笼统的「商品或规格方案未通过校验」；后面每轮回复角色都会再点一次，过一阵才停。
- 原因：
  - 笼统提示说明出错的是选商品那次模型调用本身，比如接口 5xx/超时、3 次调用预算用完、返回内容解析不了，而不是规格核对没过。v1656 只处理了规格核对没过的情况。
  - 失败后没有冷静期，模型看到「没下单成功」就会继续输出 `[点外卖|…]`。
- 改法：
  - `commerce-ui.js`（网页和私人两份相同）新增 `northRoleFallbackPick`：模型出错、返回解析不了、或「啥都行」时模型却说没有合适的，就按真实菜单挑在售、库存够、满足 must 关键词里最便宜的一份；必选规格用默认项，没有默认就用最便宜的。之后照样走 `northRoleCompleteMinimum` → 报价 → 付款前校验，不绕开任何检查。
  - `app.js` 新增 `roleOrderCoolingDown`：最近一次点单失败后 20 分钟内，除非她这一轮又提到外卖/饿/再试/想吃，角色输出的 `[点外卖|…]` 一律静默跳过。
## 2. 角色扮演「让TA回应」点了没反应
- 原因：`_rp` 只在 `rpOpen` 等几个入口里设置。从返回键、重开小手机等路径回到 rp 页时，`_rp` 是空的（或停在上一局），`rpReply` 直接 return。
- 改法：`renderRP(id)` 画哪一局，`_rp` 就对准哪一局；另外「剧情展开中」卡超过 3 分钟后允许重新点。
## 3. 放映室顶栏一串 `'+calIcon('back')+'`
- 原因：反引号模板里写成了单引号拼接，`'+calIcon('back')+'` 被当成字面文字显示出来。改为 `${calIcon('back')}`。
## 4. 订票后当天没有约会提醒
- 原因：新版机票、火车票（`flightV2` / `railV2`）在 `tvCheckDue` 里直接 return，老的「今天是约好见面的日子」提醒对新票不生效；新票只给角色发提示，她不在线时还可能被跳过。
- 改法：`tvV2DayNotice`：出行当天在每个同行或知情角色的聊天里放一条可见系统提醒，每张票只放一次；出发超过 12 小时的就不补了。
## 5. 云端：授权不可用、真人店铺刷不出来
- 授权本来就有 `license.smallphoneapp.com` 中转加备用项目，两条都不通才会报「暂时不可用」，属于服务器或网络可达性问题。
- 真人店铺 `northMarketRpc` 直连 `lkhlyfpssmrjkkzhuzag.supabase.co`，没有中转。这次在客户端给只读请求（店铺、菜单、订单、钱包、券、报价、角色查店）加了网络失败后 1.5 秒自动重试一次；下单、付款、发布、删除等写操作一律不重发。
- 根治需要在 Cloudflare Worker 的 `/rest/v1/rpc/` 白名单里加 `north_market_*` 的只读接口并部署。要用她的 Cloudflare 账号，本次没做。
## 6. 表情包过几天不显示、删除跳到最上面、要批量删除
- 原因：网址导入的表情只存了链接，图床或社交平台的链接会过期或防盗链；删除时整页 render 导致面板滚回顶部。
- 改法：
  - 导入后（以及启动后 20 秒一次）尽量用 CORS 把链接图下载成本机图片。图床不允许跨域下载的就只能保留链接，这类显示时加 `referrerpolicy="no-referrer"`，能躲开一部分防盗链。
  - `stkPanelRerender` 重画前后保存并恢复面板的滚动位置。
  - 新增「多选」→ 勾选 →「删除选中」。
## 7. 液态玻璃偶尔定格、查他手机第一次进去不是玻璃
- 定格原因：贴图最多留 2 张。去过信息页和查他手机后，主屏壁纸贴图被挤掉；切后台时 WebGL 上下文也可能被收走。之后 `lgDraw` 一直失败，只能大退恢复。现在发现没有贴图就先重新读一次壁纸，读好再画。浏览器实测：修复前绕一圈回主屏滑动重画次数是 0，修复后正常。
- 查他手机：壁纸还在从本机图库读取时只有占位、没有 img，旧代码直接跳过。现在每 300ms 重试一次，最多等 6 秒。

私人源码同步了 1–6；7 是网页独有的液态玻璃，私人包没有。
