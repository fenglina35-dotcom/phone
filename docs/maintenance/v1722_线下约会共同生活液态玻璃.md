# v1722 线下单次约会、共同生活用液态玻璃（网页先试）

她看完 v1720 信息页说「看着挺好的」，接着要线下的共同生活和单次约会：
「按钮还有页面除了背景其他的都是这种」。

## 做法

- 把 v1720 信息页那段改成通用的「场景」表 `LG_SCENES`：信息页一条、线下一条，各自写清
  页面根、滚动的那块、要做成玻璃的元素、尾巴怎么判断、根上 `:before` 上下压暗的数值。
- 线下只在**玻璃主题 + 换了背景**时生效：`.offstage.hasbg:not(.off-classic)`。
  旧的黑色文学风（classic）、没换背景时都保持原样。单次约会和共同生活共用。
- 做成玻璃的：顶栏 `.offnav`、信息栏 `.offmeta` / `.cohab-meta`、气泡、让TA回、在家状态胶囊、
  旁白/记下按钮、输入框、底部输入栏、共同生活设置面板和里面的格子/按钮、多人剧场那条和它的两个按钮、
  回来的横幅、外出面板、多选删除的按钮、「还有回复」箭头。
  **不套**：背景本身、旁白和日期（纯文字，没有框）、`input` / `select`（不能往里放画布）。
- 线下气泡染成她在「外观」里挑的颜色（`--offc-me` / `--offc-them`），浓度和原来半透明底一样
  （我的 .62、ta 的 .52）；其他栏和按钮染深灰，白字看得清。
- 通栏（顶栏、底部输入栏）左右贴着屏幕边：那两条边不弯，否则两个角会折出三角。
- 根上那层上下压暗（线下是 .44 / 22% / 72% / .58）改成着色器参数 `uShade`，玻璃里也照样压。
- 没变的不重画：每块画布记一个 key（位置、大小、分辨率、颜色），一样就跳过。
- 输入框打字变高、窗口改大小时，停下 140ms 再按新大小画一遍。
