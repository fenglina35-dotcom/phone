# 第一百八十二次安装：v1059 真实外卖匹配与生活功能整合修复版

## 版本

## 安装前

1. 把 ZIP 完整解压到全新目录，不要覆盖或拼接旧工程。
2. 用 Xcode 打开包内唯一的 `PhoneCompanionTest.xcodeproj`。
3. 这是 Windows 生成并检查结构的 MacReady 源码包，不是已签名 IPA；不要把它写成已经真机验证。
4. 覆盖安装前保留旧 App 数据，不要卸载、清缓存或删除旧资料。

## 在 Mac 上编译

1. 选择你自己的 Team，并确认现有 Bundle Identifier、App Group 和各 Target 签名正常。
2. 选择真实 iPhone，执行 Product → Clean Build Folder。
3. 运行主 App Scheme；系统权限按实际需要授权。
4. 覆盖安装后在设置页核对：网页 v1059、私人 iOS 1.0.182（182）、原生桥 25。

## 本次必验

- 外卖普通餐食：两个连续核心字可命中真实长标题；用户说“套餐”时必须选真实标题含“套餐”的商品。
- 撒汤：只搜“撒汤”时可选择第一份真实单人撒汤套餐，不能选双人、多人或无关汤品。
- 冰豆浆：作为完整商品处理，不能因“冰”字被当成温度规格；售罄或下架时如实停止，不换商品。
- 全流程：明确商品逐件完成且不重复，然后检查起送价与优惠券，最后只到官方待付款页；付款仍由本人完成。
- 共同生活：开关、进入、测试、返回可点击；开启模式本身不授权角色来电，只有当前明确命令后角色才可自行决定打或不打。
- 微信与群聊：转账状态只结算一次，角色通过真实模型知情；群聊回复串行且最多一次真实模型重试，不生成固定假话。
- 线下约会与性能：多行输入不覆盖正文；图片恢复和容量提示不再造成高频热循环或把网页配额冒充手机总空间。
- 回归保护：普通角色回复、朋友圈、后台通知、远控字幕、外置语音配置均保持原线路。

## 自动化部署包

私人 iOS ZIP 不包含电脑端登录态和外卖服务 `.env`。如需部署或更新真实外卖电脑自动化，请使用同批生成的 `SmallPhone_v1059_Friend_RealDelivery_Deploy_Sanitized.zip`；不要继续使用 v1058 的自动化包。部署时仍需保留本人专用 Edge、自己的 Supabase 和本机密钥，禁止复制 Cookie、验证码或支付资料。
