# 第一百二十九次安装：v1008 共同相册、朋友圈回复与稳定性修复

版本核对：网页 v1008；私人 iOS 1.0.129 (129)；原生桥 25。

请完整解压 `SmallPhone_v1008_SharedAlbumMomentsStabilityRepair.zip` 到一个全新目录。不要覆盖 v1007 或任何旧工程，也不要把旧工程中的 `PhoneWeb.bundle`、Swift 文件或配置复制进来。

在 Mac 上打开 `PhoneCompanionTest.xcodeproj`，选择 `PhoneCompanionTest` Scheme 和真实 iPhone，先执行 `Product → Clean Build Folder`，再编译安装。若设置页版本不是 v1008／1.0.129 (129)，立即停止，说明打开的不是本次全新工程。

真机按顺序验收：

1. 普通微信文字回复与电话先做冒烟，确认角色正常出字、出声，且没有被后台模拟任务占用。
2. 在微信聊出明确上下文后去朋友圈评论；角色必须知道当前在朋友圈评论区、能承接最近私聊，失败只显示重试，不得生成假回复。
3. 在情侣空间打开共同相册，验证用户上传的真实照片和角色聊天中真实发送的照片可见；删除、描述与重试只作用于相册记录，不得伪造照片。
4. 在角色设置确认“主模型／副模型”已单独显示；在“我 → 小号／切换身份”确认可登录角色微信。
5. 在查手机生活记录里分别关闭和开启“角色自动记录”；关闭时只允许手动记录，已有内容不得丢失。
6. 在“设置 → 聊天与媒体”立即模拟后台消息，确认通知送达；返回同一角色聊天页，必须看到与通知一致的真实消息且不能重复。
7. 连续切换多个 App、组件页、网页与私人 App，观察页面是否持续可点击、是否出现半屏／黑块，并记录机身温度。云备份、状态轮询和本地保存已降频，不能再与前台回复争用。

Windows 自动回归、独立云迁移和 Edge Function 部署不能替代本次 Mac 编译、签名和真实 iPhone 验收。
