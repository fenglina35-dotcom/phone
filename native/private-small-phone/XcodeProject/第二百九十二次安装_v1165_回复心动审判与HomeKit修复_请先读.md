# 第二百九十二次安装：v1165 回复、心动审判与 HomeKit 修复

本包是全新候选：网页资源 v1165、私人 iOS 1.0.292 (292)、原生桥 26。请完整解压到新的目录后再用 Xcode 打开，不要覆盖或混用旧工程、旧 ZIP、旧 DerivedData 中的产物。

## 本次可见变化

- 修复私人 v1164 中 `smartHomeRoleAvailable` 声明前残留补丁符号导致所有角色消息不回复的问题，并加入可选模块缺失防护。
- 心动审判由角色向用户提问；角色按人设决定刺激程度，黑卷更偏执、病态、占有；每个选项都有角色预先生成的同屏反应。
- 网页和私人版均有智能家电入口。网页走 Windows 助手；私人 iOS 直接请求 Apple 家庭／HomeKit 权限，不需要连接电脑，并以 HomeKit 回读确认控制结果。
- 保留小事簿等列表删除后保持当前位置，以及视频通话连续说话后摄像头防定格修复。

## Mac 编译前

1. 确认使用本包内的 `PhoneCompanionTest.xcodeproj`，Target 版本显示 1.0.292、Build 292。
2. 在 Signing & Capabilities 中确认 HomeKit 已启用；选中自己的 Team，让 Xcode 生成包含 HomeKit entitlement 的签名描述文件。
3. iPhone 必须登录拥有“家庭”数据的 Apple ID，并允许此 App 访问家庭。没有真实灯具时只能验证授权与列表，不能声称实控成功。
4. Clean Build Folder 后再编译、签名并安装到真实 iPhone。不要把 Windows 测试或 ZIP 校验当作 Xcode 编译通过。

## 真机逐项验收

- 普通聊天：发送任意正常文字，角色应真实回复；不得再出现 `Can't find variable: smartHomeRoleAvailable`。
- 心动审判：第一题及后续问题都应询问“你会怎么做”；角色模式显示由 TA 决定难度，选择答案后同屏出现对应角色反应。
- 私人智能家电：微信 → 服务 → 智能家电，应出现“允许访问苹果家庭”，而不是电脑配对码；授权后能选择灯具，并分别验证开关、亮度、颜色／色温及回读。
- 角色灯控：在微信或通话中让角色控制已选灯具，只有 HomeKit 回读匹配才算成功。
- 回归检查：从小事簿等长列表底部删除后不跳到顶部；视频打开摄像头并连续说至少两句，画面仍继续变化。
- 版本页／诊断信息必须显示网页 v1165、私人 iOS 1.0.292 (292)、原生桥 26。
