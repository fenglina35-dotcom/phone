# v1374 关系网各自视角

问题：关系的「来历」「过往」只存一份，两个角色看到同一句话。如果用「我/他」写，两边都会以为说的是自己，谁做了什么会乱。

改动：
- 来历、过往定为两个人都知道的客观经过：编辑页提示用名字写；给角色看时标「你们俩都知道的事实」，并说明里面的名字是谁就是谁。
- 新增「各自心里怎么看」（关系上的 `va` / `vb`，各 200 字）：只放进那一方自己的提示词，对方看不到；群聊、剧场共用的在场关系里也不带。可以写误会、心结、秘密。
- 推荐名片后角色自动立关系：要求来历用名字写，另外写自己心里怎么看，存到他那一边。

测试：tests/relation-network-v1370.test.mjs 新增各自视角用例；permanent-fix-guard 加 v1374。
