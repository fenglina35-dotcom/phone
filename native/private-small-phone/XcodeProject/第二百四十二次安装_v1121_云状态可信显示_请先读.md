# 第二百四十二次安装：v1121 / 私人 iOS 1.0.242（242）

本版修复手机号云备份状态与后台主动联系核验状态可能长期显示错误的问题。

- 账号或备份接口暂时不可用时，“最近云备份”显示“暂时无法确认”，不再把未知状态误写成“尚未上传”。
- 角色后台链路核验完成后会刷新当前“角色功能”页面，成功、失败和缺失项目都会显示真实结果，不再停留在“正在核验”。
- “立即备份本机”继续保留在私人 App 的手机号账号区域。
- 网页版云镜像继续保持只读，不能反向覆盖私人 App；网页端只提供“一键读取云端版本”。
- v1120 的影院开麦连续播放保护以及此前的共同生活、微信、角色锁定、朋友圈和外卖修复全部保留。

Windows 已完成账号与后台核验专项测试、全量 Node 回归和安装包内部结构校验。本机没有 Mac 编译签名环境，因此该压缩包是供 Mac/Xcode 编译安装的完整源码包，不冒充已签名 IPA。云端真实可用性仍取决于独立 Supabase 项目的认证与数据库服务；安装后应在云服务恢复时分别验证“刷新状态”“立即备份本机”和“重新核验”。
