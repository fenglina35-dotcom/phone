# 第二百一十四次安装：v1089 群聊退出与关心进度修复

- 网页版本：v1089
- 私人 iOS：1.0.214（214）
- 原生桥：25

真人群聊“退出群聊”所需的 `phone_friend_group_leave` 已部署到群聊实际连接的业务项目。非群主退出只删除本人群成员关系；群主仍需使用解散群聊，不影响其他成员和群历史。

角色会从最近四小时真实微信、通话和共同生活消息中提取吃饭进度。用户已经说“去吃饭／正在吃”后，角色若继续关心只能自然推进到“吃好了吗／吃得怎么样／吃了什么”，不能退回去再问“吃饭了吗”；已经说吃完后也不会再问吃好没有。这是给真实模型补充事实进度，不是删除消息或用固定台词替代角色。

后台主动消息使用同一进度事实，`phone-role-push` 已部署为 ACTIVE v17。超过四小时的旧饭点不会污染下一顿，询问角色“你吃饭了吗”也不会误记成用户自己的进度。

Windows 可以验证源码、自动测试、远程 RPC 可达性和 ZIP 结构，但不能代替 Mac 编译签名或真实 iPhone 上的群成员账号退出与角色实际话术验收。
