# v1404 桌面宠物

- 新增 `desk-pet.js`（网页和私人包同一份）：屏幕里的像素小机器人，形象是自己画的，不是官方素材。
- 入口：设置页最下面的「桌面宠物」，图标是待机的小机器人。私人包设置最下面重复的「小 K」入口删掉了，主屏的小 K 图标和实体小 K 的功能都不变。
- 设置页：开关（默认关闭）、名字（默认「小橘」）、只能绑定一个角色、大小、颜色、17 个表情动作按钮和 3 个移动动作（跑出去 / 过来 / 跳上气泡）、叫它回到屏幕中间。
- 表现：
  - 跟着绑定角色的内心、心情、最近消息、作息和节假日变化。
  - 停下来会呼吸、会眨眼，换动作、换表情时会过渡，不会硬切。
  - 你在听歌时戴耳机闭眼摇摆；你在打字时坐下敲键盘。
- 走动：
  - 聊天页把输入框上沿当地面，其它页面以屏幕底为地面。
  - 会跳上气泡、在气泡之间跳来跳去，会爬墙，偶尔跑出屏幕再跑回来。
- 互动：
  - 点一下冒爱心，连着点太多下会生气，再点就跑开；按住不动是摸摸。
  - 拖动可以放在任何位置：放在空白处就待一会儿，放在气泡上就趴在气泡上。
  - 角色来消息时它会跳到新气泡上；太久没动手机它会打瞌睡；隔一阵回到 App 它会挥手迎接你。
- 角色：
  - 提示词会告诉角色它叫什么、现在在做什么，并写明它和实体小 K 无关。
  - 角色在微信回复里另起一行写 `[桌宠|动作]` 就能控制它。这一行在主回复的逐行处理里被拦下，不会作为消息显示；另外三条回复路径和 CTLLEAK 也认这个标签。
- 验证：
  - 用模拟模型接口走真实的微信回复流程，确认跳舞、爱心眼、跑出去都生效，标签没有显示。
  - 网页版和私人版都检查过。
  - `scripts/check_chat_authorized_phone.cjs` 通过。
