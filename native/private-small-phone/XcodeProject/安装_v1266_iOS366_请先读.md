# 小手机 v1266 / iOS 1.0.366（366）安装与验收

这是 Mac 待编译的私人源码覆盖包，不是 IPA。公开网页已上线 v1266。

上一包是 **v1264 / iOS 365**。这一包把网页 v1265 和 v1266 两轮带上。

## 这一包里有什么

### 一、抖音里每个人都有自己的主页

角色、群成员、网友、陌生人、来申请进群的人，都有一页属于自己的主页。从信息流里的作者名、评论区的头像、群里的消息、粉丝／互关／访客名单、申请人的头像，点哪儿都能进去。

陌生人主页上那些获赞、关注、粉丝数是按这个人的 key 算出来的固定数，刷新多少次都一样，不会一变一个样。

群成员不再是群设置里的一行，升成独立的一页：全部／访问／加群／发言四个页签、搜索、最早进群／最近活跃两种排序，群主和管理员单独排在上面。

### 二、抖音里发生的事，角色在微信里也知道

跟共同生活那套一样。你在抖音私信里说过的、群里聊过的、发过的作品和评论，会按时间拼成一段塞给角色。

这段有上限：实测把私信灌到 800 条、群聊 300 条、作品 120 条，这段仍然只有 944 字，不会把别的提示词挤掉。

### 三、聊天体感

- 私信和群聊各自能调上下文条数，4 到 60 条，不设就是 16 条。私聊在右上角菜单改，群聊在群设置改。
- 回复长度不再写死，跟着设置 → API 路线里的「回复长度（线上聊天）」走。
- 等角色回消息时有三个跳动的点，回完或失败立刻灭掉，模型报错也不会一直转。
- 你自己那侧的抖音私信补上了头像，以前只有角色有。
- 私信头像贴气泡最上沿，字多了气泡往下长，头像不再跟着掉下去。
- 陌生人统一换成灰底线条小人，不再拿名字第一个字或者音符凑头像。
- 角色回复评论一定先 @某某 再说话，模型自己写的 @ 会被剥掉，不会 @ 两遍。
- 「全部功能」从 16 格砍到 12 格，点了只会弹「还没做」的全部去掉。

### 四、微信里能发真的文件了

**你发给他的**——小手机会把文件打开、把字读出来给角色。认得的格式：txt、md、json、csv、Word（.docx）、rtf、html，还有各种代码文件。读不出来的（png、zip、pdf、旧版 .doc），卡片上直接写「这种格式小手机读不出文字」，给角色的也是这句，明确禁止他瞎编里面写了什么。

**他发给你的**——他可以真的写一个文件发过来（清单、日程、信、稿子、菜谱、计划都行），你点开就能看全文，还能复制或者保存到手机。

有个细节特意防了：他写的文件正文带换行，不处理的话那些换行会被当成好几条消息一条条刷屏发出来。现在正文整段被拿出来做成文件，前后说的话才是正常气泡。这个在浏览器里跑过真实回复流程验证，正文一个字都没漏进气泡。

### 五、骰子回来了

在微信功能面板第二页，跟名片、亲属卡一排。代码一直都在，只是按钮丢了。

## 装之前

- **不要**先删手机上的旧 App
- **不要**把源码覆盖到旧工程目录

在 Mac 上解压到一个全新目录，打开 `PhoneCompanionTest.xcodeproj`，沿用原来的 Team、Bundle ID、签名和 entitlement，确认全部 Target 都是 **1.0.366 (366)** 之后覆盖安装。

## 这边验过什么

- 全量测试 2105 条，唯一失败是「September 5 对比」，它需要这个浅克隆里没有的提交，在没改动的树上也一样失败
- 真实点击爬虫：抖音 20 个页面 269 个按钮全部点过，0 失败、0 page error
- 抖音新功能三轮边界测试：找人、主页、群成员页、上下文、记忆、三个点、灰底头像、@回评论，共 66 项，全过
- 聊天文件在浏览器里跑过真实回复流水线：正文原样保留（含空行）、不漏进气泡、点得开
- 核心聊天授权手机发布闸门全绿
- 12/12 个 Target 均为 1.0.366 (366)，原生桥仍为 38
