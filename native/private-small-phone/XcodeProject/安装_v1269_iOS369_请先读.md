# 小手机 v1269 / iOS 1.0.369（369）安装与验收

Mac 待编译的私人源码覆盖包，不是 IPA。公开网页已上线 v1269。上一包是 **v1268 / iOS 368**。

## 这一包里有什么

### 一、群聊气泡一条条出来了

你截图里那种**一个框里同时 @ 两个人**的情况没有了——从第二个 @ 开始会自动拆成新的一条。

- **管理员**一次能发 **1～4 条**，跟微信一样
- **其余的人**保持一条
- 每条之间隔 0.4～1 秒冒出来，不再整块糊上去

### 二、收到消息有提示音

柔和的「叮～」。不是音频文件，是现场合成出来的，所以不占安装包体积、也不用联网。连着来好几条只响一次，不会像敲木鱼。

不想要的话：**设置 → 媒体 → 抖音消息提示音**，关掉就行。

### 三、火花挪到顶上了

私聊页头像名字旁边直接显示 🔥7，点一下告诉你今天续没续上。聊天区里原来那条撤掉了。

### 四、输入栏用上微信那一套

- **笑脸换成线条图标**，点开是**表情 + 表情包**，表情包跟微信**共用同一份**（设置 → 角色的表情包 里加的，两边都能用）
- **话筒**：打字，发出来是**语音条**，跟微信一个做法

角色看得懂你发的是表情还是语音，不会当成普通文字。

### 五、转账和红包

钱走**微信那套账本**，从你钱包扣，账单里查得到。

- **群里转账**要**指定转给谁**
- **群里红包**可以塞好几个**让他们抢**。谁手快看性格——人设里带爱钱、财迷、抠、穷的排前面。你自己也能抢

### 六、发作品重做了

底下只留 **文字 / 拍摄 / 从相册选**（直播先不做，也没放一个点不动的按钮）。

**文字** → 纯文字卡片，**8 种底色 + 6 种字色**随你挑

**拍摄** → 真的调后置摄像头拍；**从相册选** → 挑一张现成的

两条路都会进**发布页**：写文案、**@ 人**、发作品。

**角色是真的看图的**——发完之后会调你设置里的视觉模型看一眼，再基于看到的东西评论。

> 没配视觉模型的话，角色会被明确告知「你看不到这张图，不要编造里面有什么」。你可以在作品的「···更多 → 补一句画面描述」里自己写一句，他们就按那句来。

**被 @ 的人粉丝多（≥500）**，他的粉丝会跑到评论区来捧场，一边磕一边猜你俩什么关系。

## 装之前

- **不要**先删手机上的旧 App
- **不要**把源码覆盖到旧工程目录

解压到全新目录，打开 `PhoneCompanionTest.xcodeproj`，沿用原来的 Team、Bundle ID、签名和 entitlement，确认全部 Target 都是 **1.0.369 (369)** 之后覆盖安装。

## 这边验过什么

- 全量测试 **2161 条**，唯一失败是「September 5 对比」（缺一个这个浅克隆里没有的提交，不改动也一样红）
- 本轮专项浏览器验证 **44 项**：气泡拆分、@ 拆开、提示音、火花、表情面板、语音条、上下文措辞、群转账选人、抢红包手速、余额守卫、发作品各条路径、看不见图不许编
- 真实点击爬虫 **304 个按钮**全过，0 失败、0 page error
- 核心聊天授权手机发布闸门全绿
- 12/12 个 Target 均为 1.0.369 (369)，原生桥 38

**顺便说一件我自己出的岔子**：这一轮整块替换代码时，我误删了 5 个还在用的函数（私聊的时间戳、快捷语、点头像进主页那几个）。是点击爬虫先报错抓到的。现在补了一条测试专门扫这个——抖音里每个按钮指向的函数必须真的存在，删掉任意一个测试就变红，我验证过确实会红。
