# v1051／私人 iOS 1.0.169（169）安装说明

- 本次共享网页核心升级为 v1051，私人 iOS 升级为 1.0.169（169），原生桥仍为 25。
- 外卖全局搜索找到候选商家后，会进入每家店再进行一次准确的店内商品搜索，降低“外面搜到店、店内没找到目标饮品”的失败率。
- 商品已经加购但未达到真实起送金额时，会读取起送价、当前金额与大致缺口，安全停止结算并由角色按自身人设询问是否增加同款数量或换店；用户回答后继续原流程，不会静默卡住。
- 用户本轮未说明糖度、冰度、温度等规格时，后台保存的长期偏好仍作为默认选择；真实规格不明确时会先询问，不会假装已经下单。
- 微信“我 → 设置 → 界面与显示 → 显示归属头衔”现在可以调整项圈／归属印记气泡颜色和字体颜色，不会改变归属文字或角色关系。
- 普通角色回复、主副模型失败切换、朋友圈、后台通知、远控字幕、外部语音 base/key/voice/model、支付验证边界及私人主设备云镜像均保持原路线。
- 只使用本次唯一的 `SmallPhone_v1051_DeliveryShopSearch_TitleBadge_iOS169_MacReady.zip`。在 Mac 解压到全新目录，打开工程后先执行 `Product → Clean Build Folder`，再编译并签名安装。
- Windows 自动测试和包结构校验不能代替 Mac 编译、签名及真实 iPhone 验收；真实平台页面变化、人机验证、付款和最终确认仍由平台及本人处理。
