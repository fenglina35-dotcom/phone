# 第一百五十次安装：v1029 真实外卖与角色钱包

## 版本

- 网页：v1029
- 私人 iOS：1.0.150（150）
- 原生桥：25
- 建议全新工程目录：`SmallPhone_v1029_RealDeliveryWallet`

## 本次内容

1. 外卖软件内新增“虚拟外卖／真实外卖”入口。真实外卖默认关闭；关闭时维持旧虚拟外卖，开启后搜索、报价、订单、付款和配送状态只接受真实连接器回执，失败不回退虚拟。
2. 新增两个总开关：开启真实外卖、允许角色自动付款。每角色有独立外卖授权钱包，默认单笔上限 ¥100、每日上限 ¥200，可由用户自由充值和调整，角色无权更改。
3. 自动付款优先微信、其次支付宝；新地址、价格变化、短时重复、平台风险、余额或额度不足时只创建真实待付款订单。只有支付渠道返回 `paid` 才扣角色授权额度。
4. 真实订单在外卖软件里展示待付款、商家接单、备餐、骑手取餐、配送中、送达等平台状态。角色仅在真实状态变化后按自己人设生成提醒，没有固定角色台词。

## Mac 编译与覆盖安装

1. 在 Mac 新建 `SmallPhone_v1029_RealDeliveryWallet`，完整解压本次交付，不要覆盖 v1028 或更早工程目录。
2. 打开 `native/private-small-phone/XcodeProject/PhoneCompanionTest.xcodeproj`，确认 Marketing Version 为 1.0.150、Build 为 150。
3. 选择真实 iPhone 和正式签名，先 Clean Build Folder，再 Build／Archive；不要用 Windows 产物冒充 Mac 编译结果。
4. 覆盖安装前导出小手机数据备份。覆盖安装后不要先卸载旧 App，避免清除 Keychain、角色、聊天和外部语音配置。
5. 设置页核对网页 v1029、私人 iOS 1.0.150（150）、原生桥 25。

## 真机验收顺序

1. 真实外卖开关保持关闭，确认旧虚拟外卖搜索和聊天剧情仍可用。
2. 打开真实外卖，但不填连接器，确认界面只显示“真实服务未连接”，搜索失败不会出现虚拟商家或虚拟成功。
3. 配置经过审核的 HTTPS 连接器后，先只测真实搜索：淘宝闪购优先、美团外卖其次；评分、评价、优惠、配送时间只在平台真实返回时显示。
4. 关闭角色自动付款，测试角色只创建待付款订单；订单能在外卖软件查看并刷新真实状态。
5. 给单一测试角色补充极小额度，设置很低的单笔和每日上限，再开启自动付款；只用小额测试品验证微信优先、支付宝其次、`paid` 后扣额。
6. 分别验证新地址、报价变化、20 分钟重复单、超单笔、超每日、余额不足和平台风控都会转待本人付款。
7. 验证商家接单、备餐、取餐、配送、送达、取消／退款的真实状态变化，以及角色按本人语气提醒；无状态变化时不能编造提醒。
