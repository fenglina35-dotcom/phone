# v1662 像素少女与电子宠物断网自动重下

## 现象
- 有人打不开像素少女，页面中间显示：`undefined is not an object (evaluating 'window.PixelHomeBridge.request')`。
- 有人在情侣空间打开电子宠物时提示「组件尚未加载」。

## 原因
这些页面的脚本文件只要有一个没下载成功，就会出问题。部分网络访问 GitHub Pages 会偶发失败，以前既不会重试，也不会提示是哪个文件：
- 像素少女里 `bridge.js` 没下载成功时，`game.js` 照样执行，于是报 `PixelHomeBridge` 未定义。
- 电子宠物 `pet-game.js` 开机时没下载成功，之后一直打不开，只能整页重开。

每发一个新版本，所有文件都要重新下载一遍，所以原本能打开的人，也可能在某次更新后打不开。

## 修复（网页和私人包）
- `games/pixel-home/index.html`：改成用一段内联加载器按顺序载入小屋脚本。每个文件加载后检查它该有的对象（如 `PixelHomeBridge`），失败就换带 `retry` 参数的地址再试两次；都失败才提示是哪个文件、请检查网络。
- `sw.js` 的像素少女分支：
  - 缓存键去掉每次进入都不同的 `session` 参数，以前每进一次就多存一份 `index.html`。
  - 下载失败会重试 3 次；仍失败时，用以前缓存过的旧副本。
- `app.js`：新增 `northEnsureComponent` / `northOpenComponent`。像素少女（连同 `pixel-home-policy.js`、`pixel-wardrobe-info.js`）或电子宠物的组件缺失时，点开就现场重新下载，最多 3 次，成功后直接打开；失败才提示。原有的「组件尚未加载」提示保留，作为最后一道兜底。
- iframe 地址升到 `index.html?v=1662`。

私人包只同步了代码，没有升版本号，也没有打包。
