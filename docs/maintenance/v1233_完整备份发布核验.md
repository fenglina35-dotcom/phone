用户授权修复华为安卓 Edge 设置中完整备份导出无反应，并排查同机导入后的卡顿；要求网页推送、不打私人包、工作区整理干净。

## 影响和保护边界

共享的完整备份导出、导入和该导出弹窗关闭路径；其他音乐、美化下载仍用原流程。私人仅按函数同步完整备份功能和内置页版本，未覆盖私人 app.js、原生控制或公开 North 功能。网页和内置页 v1233；原生仍 iOS1.0.355（355）、桥37；未生成私人包。已有 v1232 覆盖包保持原字节。

## 原因与改变

旧导出在异步整理后直接点隐藏链接，3秒撤销 URL，没有捕获生成异常；新导出提供明确的生成状态、真实下载链接及能力检测后的系统分享。生成中的重复点击不会启动第二份备份；取消分享保留文件，关闭后延迟60秒释放 URL。只提示系统接收，不声称磁盘保存成功。JSON 去掉排版空白，语义与完整数据格式不变。

旧导入先缓存所有大图再统一精简。新流程收集同图引用，逐张确认落库后改成 idb 引用，释放本次新增缓存，每两张让出事件循环。保留原可见缓存，写失败的图片原文不提前替换；不删图片库。原有安全快照和核心保存顺序保持。

这是已验证的软件薄弱点及改进，不是华为真机所有无反应或卡顿的唯一根因证明。大文件 JSON 解析仍有一次同步开销；设备剩余内存、存储空间、浏览器下载权限仍会影响结果。
