# 外卖伴生程序维护者发布说明

此目录构建的是每位用户自己电脑上的外卖浏览器代理。朋友端绝不能包含 `SUPABASE_SERVICE_ROLE_KEY`、网页 `ownerSecret`、旧作者上游密钥或运行规则签名私钥。

构建安装器：

```powershell
npm ci
npm test
npm run dist
```

发布点单规则更新前设置 `SMALL_PHONE_DELIVERY_RUNTIME_VERSION` 为递增的三段版本号，再运行：

```powershell
$env:SMALL_PHONE_DELIVERY_RUNTIME_VERSION='0.1.1'
npm run release-runtime
```

只发布 `release/runtime-manifest.json` 和清单中对应的 ZIP 到网页的 `delivery-agent/` 路径。签名私钥位于仓库外的 `.smallphone-release-keys`，必须离线备份，不能提交、打包、截图或发给朋友。安装包只嵌入公钥。

上线顺序必须是：数据库迁移 → Edge Function → 运行规则文件 → 网页 v1112。部署新 Edge Function 前，先把仍使用旧作者后台的唯一 target 放入 `PHONE_DELIVERY_LEGACY_TARGETS`；不要使用通配符。朋友 target 不得加入该变量。

封闭试用验收顺序：配对 → 朋友专用 Edge 登录 → 本人核对脱敏地址 → 只搜索 → 低金额真实订单。任何账号、城市或地址串线都必须立即解绑并停止试用。
