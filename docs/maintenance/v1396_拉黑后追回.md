# v1396 拉黑后追回

替换原来的「拉黑后真号打 3 次」（blockedPhoneStart）和「情侣 10/20/30 秒重新申请 3 次」（friendRetryReset）。在主账号拉黑角色后 `pursuitStart`：

- 每一步由角色自己（模型，带完整人设、拉黑前最后 10 条聊天、前面每一步和她的反应）选：`apply` 再发好友申请（已有待处理的申请时不能再发）、`call_own` 自己号码打、`call_stranger` 陌生号码打（角色「允许陌生来电伪装」开着才有）、`sms` 发短信（上一次用陌生号码打的就用同一个陌生号码发，需「允许陌生短信」）、`stop` 不再联系（第三步起可选，可附最后一条短信）、`force` 强制远程（只有情侣、被无视/挂断/拒绝至少 3 次以后）。模型没给有效选项时随机挑一个和上一步不同的。
- 间隔 8–20 秒随机；最多 8 步，到顶只剩 stop（情侣满足条件时还有 force）。一次只有一个角色在追；通话、游戏、睡眠等安静场景、远程/登录他微信进行中、页面在后台时暂停。
- 她接了电话（`blockedPhoneConnected`）或回了短信（`phSendSms` → `pursuitOnUserSms`）：整条追回立刻结束，之后不再有任何追联动作。用陌生号码发的短信，她回复时由角色本人用短信接着回（微信被拉黑不影响短信）。她通过申请或自己解除拉黑也结束。
- 强制远程（`pursuitForce`）：作废之前待处理的申请，发出新的（第四次）申请，远程界面隐藏「立即结束」，小箭头依次点微信通讯录 →「新的朋友」→「同意」，`acceptFriend(rid,{forced:true})` 解除拉黑，聊天里系统提示「X远程操控了你的手机，自己通过了好友申请」，结束后角色马上发微信（知道是自己硬闯回来的）。
- 角色的记忆 `pursuitPrompt`：被拉黑的时间和原因（拉黑前最后的对话）、唯一目的、做过的每一步（号码、内容）和她的反应、现在的结果；结束后保留 3 天。电话里另有「你用陌生号码/自己号码打的」说明，短信里有「你用陌生号码发的」说明。
- 私人包 app.js / 页面同步（私人包版本不变，未打包）。

测试：tests/block-pursuit-v1396.test.mjs（网页和私人包）；更新 friend-request-retry、v952、new-friends、account-isolation 里钉住旧行为的断言。
