# v1380 剧场配角与家人设定

- 名片资料页的性别标志换成微信那种小人图标（女粉色带领结、男蓝色），名字也放大一点。
- 多人剧场配角：
  - 模型的 JSON 里台词带了没转义的引号（比如 那声"妈"），以前整段 JSON 原样当一句话显示。现在按一条条 {"type","text"} 抠出来（`theaterLooseBubbles`），原样输出模式和普通模式都适用。
  - 动作和台词分错（台词标成动作 → 全变成旁白；动作写成台词 → 长段旁白塞进气泡）时纠正（`theaterFixBubbles`）：没有「她/他/名字」、带「我/你」的是台词；以「她/他/名字」开头、不带引号和「我」的长句是动作；动作里引号说的话拆成一句台词。
- 生日、忌日：详细资料里直接写出「ta的生日是5月14日」「忌日是11月3日」，并要求没写的不要编。「你妈」「老妈」也算提到「母亲」（家人称呼同义词）。人物卡加成好友后，为人、生日照样从人物卡里取。
- 登录他的微信和关系网里的人聊天（`relFriendSys`）：对方知道自己是他的谁、对他的好感、有没有矛盾、为人、来历、心里的想法，以及他家里谁已经去世。查他手机生成内容（`relSpyNote`）也带上这些，已故的人不会有新聊天。
- 私人包的 cohab-theater.js 同步。
