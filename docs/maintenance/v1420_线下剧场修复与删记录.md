# v1420 线下剧场修复与删记录

- 旁白按钮：按钮亮着发出去的就是旁白，不亮就是气泡。旁白状态按场景 id 记在 `_offNarrateById`，删消息、重新渲染都不会让按钮自己变。输入框提示文字改到 `offFieldHTML` 里根据旁白状态切换。
- 多人剧场：被点名的人暂时离场后，不再整轮没人说话，改由在场的人接话，并弹出提示。
- 多人剧场：`theaterTurnOrder` 让每一轮所有在场的配角（两位微信来客、路人）都说一次，后说的能看到前面的人说了什么。点名谁，谁先说，然后主角，再其他人。
- 多人剧场：发送时「对谁说」以屏幕上的选择为准（`theaterSyncAddressFromUI`）。某人离场前正被点名，回到现场后会自动重新选中 TA（`t.addressAway`）；用户中途自己换了人就不动。
- 线下和共同生活：多选栏新增「删除聊天记录」，可以按某一天、一天前、三天前或全部删除，删除前会确认；删完后空下来的日期分隔一起去掉，总结记忆不动。
