# v1388 存储占用明细（私人 App）/ 私人包 v1389 iOS427

起因：iPhone 设置里「小手机」占 12.08GB，但设置页只显示主存档 7MB + 保护副本 21MB；存储条其实是整台手机的用量，容易误会。私人 App 的明细为防内存爆掉只给了一行「WebKit 媒体与数据库」。

- 原生新接口 `storage.usage`：后台线程量 App 容器里 Library/WebKit、Library/Caches、Application Support、Documents、tmp 和总量（只读文件属性）。
- 原生新接口 `storage.clearWebCache`：只清 WebKit 磁盘/内存/fetch 缓存。
- 明细：放映室视频/字幕/书架、音乐单独显示（文件型数据只读大小）；图片·聊天·语音用 `countIDBKeys` 只数个数，大小=网页数据总量−已知项；另列网页缓存、临时文件；顶部显示小手机一共占用多少；缓存超过 1MB 时出现「清理网页缓存」按钮。
- 存储条说明加一句「上面这根条是整台手机的存储用量」。
- 私人包 v1389 / iOS 1.0.427 (427)：同时带上 v1382 头像对齐、v1384 角色扮演能点开、v1386 记得自己的生日。原生桥合约版本仍为 42。
