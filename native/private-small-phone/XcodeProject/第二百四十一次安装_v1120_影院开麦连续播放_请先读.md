# 第二百四十一次安装：v1120 / 私人 iOS 1.0.241（241）

本版修复放映室开启持续麦克风时，iOS 音频会话切换导致正在播放的影片暂停。

- 开麦前影片正在播放时，若 iOS 录音会话打断播放，放映室会在原页面内受控恢复。
- 用户自己点下暂停后不会被强制恢复。
- 字幕提取为了等待进度而主动暂停时不会被误恢复。
- 页面切到后台、影片结束或离开放映室时不会被强制恢复。
- 网页和私人 App 内置页面使用完全相同的影院播放保护逻辑。
- v1119 的本地视频解析、图标美化、角色锁定、共同生活、朋友圈和外卖容错全部保留。

Windows 已完成影院专项测试、1240 项全量测试和安装包内部结构校验。本机没有 Mac 编译签名环境，因此该压缩包是供 Mac/Xcode 编译安装的完整源码包，不冒充已签名 IPA。开麦与 WKWebView 播放并行仍需在安装到真实 iPhone 后做最后一次设备验收。
