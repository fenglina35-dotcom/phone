# 第一百四十九次安装：v1028 X 个人主页布局修正

## 本次版本

- 网页：v1028
- 私人 iOS：1.0.149（149）
- 原生桥：25
- 工程目录：`SmallPhone_v1028_XProfileLayout`

## 本次修正

1. 将版本从 v1027 正式提升到 v1028，避免已加载 v1027 的设备把后续界面调整误判为同一版本。
2. X 个人主页顶部背景图高度由 100px 增加到 160px。
3. 主页不再直接显示“网友评论风格”卡片，三档选择移入“编辑资料”。
4. 友善、恶劣、一半一半的评论生成逻辑不变；设置后和用户名、简介一起点“保存”生效。

## 安装与核对

1. 在 Mac 新目录完整解压本包，不覆盖旧工程目录。
2. 打开 `PhoneCompanionTest.xcodeproj`，选择 `PhoneCompanionTest` Scheme 和真实 iPhone。
3. 执行 `Product → Clean Build Folder` 后覆盖安装；不要删除手机上原来的私人 App。
4. 设置页确认网页 v1028、私人 iOS 1.0.149（149）、原生桥 25。
5. 打开 X → 我的主页，确认背景区域已明显加高；点“编辑资料”，确认评论风格三档在弹窗内且保存后生效。

## 验证边界

- Windows 自动回归 932/932 已通过。
- 本包尚未在 Mac 编译、签名或真实 iPhone 验证，最终以 1.0.149（149）真机结果为准。

## 稳定功能保护

本次只调整 X 个人主页布局和版本识别，没有改动评论生成规则、角色回复、微信、朋友圈、共同生活、后台消息、伴生控制、通话或语音配置。两份 `app.js` 原有的电话页面已提交差异仍保留。
