# 私人空调可空服务编译修复

用户在 v1220 的 Xcode 构建截图中出现红色错误：For-in loop requires '[HMService]?' to conform to Sequence。源码 HomeKitClimateBridge.swift 第478行对 target.service.linkedServices 直接迭代。Apple HMService 官方 Swift 定义为 [HMService]?：https://developer.apple.com/documentation/homekit/hmservice 。这是真实编译失败证据，不是签名或部署问题。

修复范围仅私人原生一行：for linked in target.service.linkedServices ?? []。无关联服务时继续返回 nil，不强制解包、不生成假服务，不改变直接服务优先、写入后的回读及模式/风速能力判断。截图中门锁和报告两个并发隔离黄色警告保持不动，避免扩大修改范围。

旧源码新增静态回归1失败1通过；修复后2项通过。该测试只能防止已知错误写法回归，不能冒充苹果 SDK 编译。先前 Windows 测试遗漏了 HomeKit 可空类型，这次用户真机编译证据证实旧包未通过实际构建门禁。无本地 Swift/Xcode 工具，不能宣称整包已编译通过。
