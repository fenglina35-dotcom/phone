# v1340 / v1341 外置语音独立通道修复

## 用户可见问题

网页和旧私人版本填写自己的外置语音地址、Key、模型与音色后，测试可能提示“AI点数不足”或“没拿到语音”。外置账号本身有额度时也会失败。

## 已确认原因

小手机原有 MiniMax、Fish、Mossland 外置语音路径会先请求 Supabase `phone-ai`。2026-09-28 线上函数返回 HTTP 402，错误内容为 `exceed_edge_functions_invocations_quota`，代表 Supabase 项目的 Edge Functions 免费调用额度已耗尽。客户端把所有 402 都翻译成“AI点数不足”，所以界面把平台额度故障误报成了用户的小手机点数不足。

这不是 Fish、海螺或其他外置账号的点数判断。旧私人安装包虽然没有重新打包，仍会访问同一个线上 Supabase 中转，因此也会同时受影响。

## 修复范围

- MiniMax 海螺、Fish、Mossland、ElevenLabs、Hume 的合成请求改走 `https://license.smallphoneapp.com/functions/v1/external-tts`。
- MiniMax、Fish、Mossland 的音色列表也走同一独立通道，不再借用内置 AI 账户。
- Cloudflare Worker 只允许上述五个厂商的固定官方主机；MiniMax 同时保留小手机旧预设 `api.minimax.io` 和新版 `api.minimaxi.com`，其他任意上游均拒绝，避免成为开放代理。
- 转发使用用户填写的厂商 Key，不查询小手机账号、不读取点数、不扣点、不缓存、不重试，也不记录请求正文。
- 通用 OpenAI 兼容语音仍按用户填写的地址由客户端直连；它允许任意自建地址，不能安全放进公开转发端点。
- 外置配置缺少地址或 Key 时继续保持零请求；内置语音关闭时继续保持零生成请求。已有内置用户的余额、音色、退款与正常付费路径不变。
- Supabase 平台额度 402 改为明确提示“内置AI后台免费调用额度已用完”，不再误显示成用户点数不足。
- 外置测试直接显示厂商返回的 HTTP 状态和错误摘要，便于区分 Key、模型、音色、额度或网络错误。

## 仍需真实账号验证的边界

自动测试和线上到达验证均不保存也不使用用户的真实厂商 Key。真正生成音频仍需用户用自己的有效 Key、模型和音色完成一次测试；此边界不能用无效占位 Key 的厂商鉴权错误代替。
