# 第一百三十二次安装：v1011 模型线路、朋友圈与后台消息修复

版本核对：网页 v1011；私人 iOS 1.0.132 (132)；原生桥 25。

请完整解压 `SmallPhone_v1011_ModelRouteAlignment.zip` 到一个全新目录。不要覆盖 v1010 或任何旧工程，也不要把旧工程中的 `PhoneWeb.bundle`、Swift 文件或配置复制进来。

在 Mac 上打开全新的 `SmallPhone_v1011_ModelRouteAlignment/PhoneCompanionTest.xcodeproj`，选择 `PhoneCompanionTest` Scheme 和真实 iPhone，先执行 `Product → Clean Build Folder`，再编译安装。若设置页版本不是 v1011／1.0.132 (132)，立即停止，说明打开的不是本次工程。

本版按以下顺序真机验证：

1. 使用原来保存的 Mossland／Fish 等外置语音，让角色说话，确认能播放且不再出现 HTTP 401；不要重填或改写外置语音的地址、Key、音色。
2. 普通微信聊天发一条消息，确认回复速度和显示正常。
3. 在朋友圈评论角色动态，确认角色真实回复、知道自己正在朋友圈评论，并能参考近期微信聊天上下文；失败只保留重试，绝不生成假回复。
4. 在“设置 → 聊天与媒体”执行一次“立即模拟后台主动消息”，立刻把小手机退到系统桌面。等待服务器返回真实结果，确认系统通知与角色聊天消息都送达，且任务不会长期占用普通微信回复。
5. 冒烟验证文字／语音通话，确认字幕和声音没有回归。

Windows 自动测试和云函数部署结果不能替代 Mac 编译、签名及真实 iPhone 验收。
