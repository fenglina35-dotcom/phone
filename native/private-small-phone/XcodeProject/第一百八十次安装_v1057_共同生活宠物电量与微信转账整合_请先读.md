# 第一百八十次安装：v1057 共同生活、宠物、电量与微信转账整合版

## 版本

- 网页核心：v1057
- 私人 iOS：1.0.180（180）
- 原生桥：25
- 工程：`SmallPhone_v1057_CohabPetBatteryTransfer_iOS180_MacReady`

## 安装前

1. 解压到一个全新目录，不要覆盖旧工程。
2. 先保留旧 App 和旧工程，确认新包数据正常后再处理旧版本。
3. 这份是 Windows 生成并检查过结构的 MacReady Xcode 源码包，不是已经签名的 IPA。

## 在 Mac 上编译

1. 用当前正式版 Xcode 打开 `PhoneCompanionTest.xcodeproj`。
2. 在 Signing & Capabilities 里选择你自己的 Team，并确认 Bundle Identifier 可用。
3. 选择真实 iPhone 作为运行设备，执行 Build / Run。
4. 如果系统询问通知、相机、麦克风、定位或家庭控制权限，按实际需要授权。
5. 覆盖安装后先核对：网页核心 v1057、私人 iOS 1.0.180（180）、原生桥 25。

## 必验项目

- 共同生活：开关可用，点击一次只进入一次，能看到原角色和生活记录。
- 宠物：从食盆拖出食物投喂后不弹购买页；直接点击购买仍可打开。
- 网页电量：支持 Battery API 的浏览器恢复前台后更新；iPhone Safari 不支持时允许显示上次值或 `--%`，不能当成真实系统电量。
- 微信转账：待收、已收、已退都能进入明细；收款和退还只执行一次，返回聊天位置正确，黑白主题都可读。
- 回归保护：普通角色回复、朋友圈、后台通知、远控字幕和已保存的外置语音 Base URL、Key、模型、音色均保持原样。

## 重要边界

- 本包没有在 Windows 上完成 Xcode 编译、签名或真实 iPhone 验证，这三项必须在 Mac 和真机上完成。
- 不要为了安装清空 App 数据，也不要拿旧 Bundle 覆盖本包的 `PhoneWeb.bundle`。
