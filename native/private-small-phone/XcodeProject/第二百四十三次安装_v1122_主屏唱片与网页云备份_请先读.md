# 第二百四十三次安装：v1122 / 私人 iOS 1.0.243（243）

本版逐项修复主屏唱片颜色、网页版云同步入口、私人手机号故障显示与私人 App 图片维护卡顿。

- “主屏组件”里新增“主屏唱片颜色”，只改变桌面外面的圆盘，不改音乐 App 自己的唱片颜色；可一键恢复跟随当前主题。
- 网页版“授权与数据 → 云同步”重新提供“立即备份当前网页版”；若云 ID 已由私人 App 管理，仍会安全拒绝网页反向覆盖。
- 云同步弹窗的自动同步开关固定在弹窗内部，不再横向只露出半个白色开关。
- 私人手机号账号把“账号状态”和“云备份状态”分开：仅备份接口失败时保留本机登录状态；认证服务超时会明确提示，Keychain 凭证不会因此被删除。
- 私人 App 启动后不再自动执行一分钟一次的全图片库维护扫描，避免大图库反复遍历造成发热、卡顿或白屏；手动清理、图片加载和存档继续保留。

Windows 已完成专项测试、全量 Node 回归、真实网页界面验收和安装包内部结构校验。本机没有 Mac 编译签名环境，因此该压缩包是供 Mac/Xcode 编译安装的完整源码包，不冒充已签名 IPA。

重要：当前独立 Supabase 项目的 REST 接口能响应，但 Auth 健康检查和设置接口仍会超时。安装包已经避免误报账号丢失并缩短等待，但服务端恢复仍需 Supabase 项目恢复或由项目所有者在控制台重启后再真机验收；本地代码不能伪造认证服务器已恢复。
