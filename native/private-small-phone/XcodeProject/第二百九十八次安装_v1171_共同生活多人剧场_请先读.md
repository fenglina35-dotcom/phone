# 第二百九十八次安装：v1171 共同生活多人剧场

本包是私人版本全新候选：网页候选源码为 v1171，但本次不上传网页；私人内置页面为 v1171，私人 iOS 为 1.0.298 (298)，原生桥 35。请完整解压到新的目录后再用 Xcode 打开，不要覆盖或混用旧工程、旧 ZIP、旧 DerivedData 中的产物。

## 这次改了什么

- 共同生活新增独立“多人剧场”开关；关闭时仍是原来的你与主角两人节奏。
- 开启时固定一名主角，最多邀请一名现有微信角色作为来客，并最多加入一名临时路人；配角只能在主角真实回应之后偶尔补充一句，不能抢主角。
- 你、主角、微信来客和临时路人的气泡都显示独立署名，并可分别设置气泡颜色。
- 可设置你与主角、来客与你、来客与主角、路人与你、路人与主角的关系；输入前可选择本轮主要对谁说话。
- 微信来客被手动请离、自然退场或关闭多人剧场时，只把其在场期间亲历的内容总结一次到该微信角色自己的长期对话总结；失败会延后重试，不伪造固定角色记忆。
- 完整继承 v1170 的真人好友入口解耦、分批首屏和诊断链；未用公开旧文件覆盖私人修复。

## Mac 覆盖安装

1. 把 ZIP 完整解压到一个全新目录，不要直接在压缩包内打开工程。
2. 打开 `PhoneCompanionTest.xcodeproj`。
3. Target 版本必须显示 1.0.298、Build 298；签名使用原来的 Team 和 Bundle Identifier。
4. 不要先删除手机上的旧 App，直接对原来同一台 iPhone 执行 Run，以保留现有数据容器。
5. 启动后在版本页核对：网页核心 v1171、私人 iOS 1.0.298 (298)、原生桥 35。

## 本次重点验收

1. 在共同生活内确认多人剧场可随时开关，关闭后不改变原有共同生活进度。
2. 邀请一名微信来客、加入一名临时路人，确认四种气泡署名、颜色和关系设置准确，来客与路人不会被主角冒名。
3. 分别选择“对主角／来客／路人／所有人说”，确认主角仍先回应，配角每轮至多一名且台词短于主角。
4. 手动请离来客后回到该角色微信长期记忆，确认只新增一次本场总结，并能分清你、主角和来客本人。
5. 复核 v1170 真人好友私聊首屏、旧消息分批展开和消息发送没有退化。

当前只完成 Windows 代码与自动测试；尚未在 Mac 编译、签名、覆盖安装，也尚未在真实 iPhone 验证多人剧场和来客记忆。
