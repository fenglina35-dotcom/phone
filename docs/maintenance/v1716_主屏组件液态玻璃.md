# v1716 主屏组件液态玻璃（网页先试，私人版不动）

## 需求
用户按网上液态玻璃教程的参数图，想要主屏组件有「背后被推弯」的玻璃效果，并能逐项调参。之前 Codex 做的版本在真机上会掉材质、卡顿，滑主屏时一闪一闪，已经回退过几次（见 README 2026-10-11 一组记录）。

## 和失败做法的区别
- **以前**：
  - 每个组件拍背景快照，再设成组件背景。
  - 自动收集所有带 backdrop 的元素，监听 DOM 变化、滚动和离屏，反复重新装饰。
  - 读像素做兜底。
- **现在**：
  - 一个共用的离屏 WebGL 程序，把每个组件「烤」成一张静态 2D 画布，插在组件自己里面（`z-index:-1` + `isolation:isolate`）。画布随组件一起滑。
  - 组件位置按「它停好的那一页」计算。翻页时整页一起移动，这个位置不变，所以滑动、翻页一帧都不重算。
  - 只有壁纸、参数、组件大小或位置变化时才重烤，结果按 key 缓存（最多 24 张）。`render()` 之后同步装回缓存，不等下一帧。
  - 不监听 scroll，不用 MutationObserver，不用 getImageData，不用 toDataURL。
  - 画布装好之前组件保持原来的玻璃样子；装好后才去掉 `backdrop-filter`。WebGL 上下文丢失只影响以后的重烤，已经放进组件的画布不受影响，不会掉材质。
- **范围**：只处理 `#homeDesktop` 内的 `.hwid`、`.glass-second-portrait`、`.glass-second-photos`、`.dock`，嵌套的子块不处理。不碰微信、设置、线下、角色手机等页面。
- **兜底**：没有壁纸图片、不是玻璃主题、WebGL 不可用、壁纸无法读取（外链）时，保持原样。

## 着色器
圆角矩形 SDF。边宽（厚度）内按法线方向偏移采样，实现折射；RGB 分开采样做色散。

模糊使用壁纸的 mipmap bias：壁纸先缩放成 1024 宽、2 的幂高的纹理。之后依次处理饱和度、染色（黑 / 白玻璃）、迎光细边高光、内侧光带和背光边。DPR 上限为 2。

## 设置
设置 → 外观 →「液态玻璃」：
- 开关；黑玻璃 / 白玻璃 / 回到默认三个预设。
- 11 项滑杆：背景模糊、折射率、弯的力度、色散、厚度、边上散射、料、饱和度、高光、光的方向、背光边。
- 实时预览（用当前壁纸）。

参数存在 `S.me.liquidGlass`，有范围限制，0 值保留。

## 验证（桌面无头浏览器，DPR 2）
- 6 个组件装好画布。
- 0→1→0 翻页滑动 41 帧，重烤 0 次；连续 render 20 次，重烤 0 次；改一次参数，重烤 6 次。
- 关掉开关后画布和样式全部移除。
- render 平均耗时：开启 15.9ms，关闭 7.2ms。
- 没有 iPhone 真机 FPS 或内存验收，需要用户在真机上看。

## v1718 补充：翻页时实时折射
用户反馈：玻璃里的壁纸「定格」在组件原位，滑动时不跟着背后的壁纸变。

原因：v1716 只按组件停好的位置算一次，画布跟着组件一起滑，画布里的内容也就一起滑走了。

改动：
- 只在 `#appswipe` 的 `scroll` 事件（passive）里，用 requestAnimationFrame 每帧重画此刻露在屏幕上的组件。
- 组件当前位置用 `scrollLeft − 页号×页宽` 推算，不读布局。
- 滑动中按 0.6 倍分辨率画；停下 140ms 后用原分辨率再画一遍。
- 每张画布记住自己上次画的位置和分辨率，没变就跳过，所以静止时 `render()` 仍然 0 次绘制。
- 共用的 WebGL 画布只增不减，按视口区域画，不会每次都重新分配。
- 仍然不拍快照，不用 MutationObserver、getImageData 或 toDataURL；DOM 变化不触发重画。

验证（无头浏览器，软件渲染）：
- 滑动 21 步共绘制 122 次（每帧约 6 个组件）；回到第一页并停稳后绘制 13 次；静止时 render 两次，绘制 0 次。
- 中途截图里，玻璃内的竖条和外面的壁纸对齐。
- 真机的帧率只能在 iPhone 上看。
