# v1075 私人 App 安装说明

- 网页内核：v1075
- 私人 iOS：1.0.200（200）
- 原生桥：25

## 本次修复

- 角色生成图片时必须从已启用的角色衣柜中选择衣服，不再自由生成衣柜之外的服装。
- 优先选择符合当前场景类别的衣服；没有对应类别时，仍会从现有衣柜里选择一套，不会停止生成。
- 生成提示、衣物参考图与最终图片请求绑定同一个衣柜服装 ID，避免中途换衣、改色或额外叠穿。
- 只有衣柜完全为空或没有任何启用服装时才会停止，并提示先添加衣服。
- 保留此前的真实角色回复、朋友圈、后台通知、共同生活、外卖、通话、远控字幕和外置语音配置。

## 在 Mac 上安装

1. 解压 ZIP，只打开里面的 `PhoneCompanionTest.xcodeproj`。
2. 在 Xcode 选择你的签名团队和真实 iPhone。
3. 直接运行安装；版本应显示为 `1.0.200 (200)`。
4. 安装前不要删除旧 App，原有本机存档会继续保留。

本包在 Windows 上完成源码、完整 PhoneWeb.bundle 与 ZIP 的逐文件一致性检查；没有在 Mac 编译，也没有在真实 iPhone 上代替你安装验证。
