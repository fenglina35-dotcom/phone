# v1224 私人空调目标温度修复源码包 iOS 1.0.347（347）

本包以已发布 v1223 私人版为基线，只加入本次 ACN1-AIR 温度修复和必要的新版本标记。未纳入原工作区中其他未提交的聊天、线下约会、公开 North 或日常事件簿修改；卧室小灯、门锁和既有私人功能按 v1223 原样保留。

## 本次修复

- Heater/Cooler 空调在制冷时读取和写入 `CoolingThreshold`，制热时读取和写入 `HeatingThreshold`。
- 不再把同一配件其他服务中的通用 `TargetTemperature` 当成 ACN1-AIR 目标温度，避免加减按钮只能在 25℃ 与 26℃之间跳转。
- 页面、手动加减和角色状态使用同一个模式目标值；写入后仍须经过苹果“家庭”状态回读确认。

## Mac 安装与真机验收

这是 Mac 待编译源码包，不是已签名 IPA。请完整解压到新目录，打开 `PhoneCompanionTest.xcodeproj`；不要覆盖旧工程，也不要先删除旧 App。沿用原 Team、Bundle ID、Automatic Signing、App Group、HomeKit 和健康权限。六个 Target 的 Debug 与 Release 应为 1.0.347（347），设置页应显示私人 v1224。

覆盖安装后，先在制冷模式从 20℃连续加到 21、22、23℃，再连续减回；随后切换制热重复测试。每次同时观察私人 App、苹果“家庭”App和实体空调面板。角色应读取到与苹果“家庭”相同的开关、模式和模式目标温度。

ACN1-AIR 是红外伴侣，苹果“家庭”显示值不是空调主板的直接回传。如果苹果“家庭”本身与实体面板不一致，需要重新匹配或学习红外码；本次代码不能证明实体空调已执行。Windows 自动测试与源码 ZIP 校验也不能代替 Mac 编译、签名和真实 iPhone 验收。
