# 小手机智能家电助手（Windows）

这是网页版“小手机”的电脑端助手。当前正式支持与验收范围只包括苹果手机：必须先用 iPhone 的苹果“家庭”App/HomeKit 配置灯具。安卓手机暂不属于当前支持范围。电脑与 Meross `MSL430` 灯需要保持在同一个路由器下，iPhone 日常打开网页时不要求连接灯所在的 Wi-Fi。

## 普通用户安装

1. 双击 `SmallPhoneSmartHomeAgent-0.1.6-Setup.exe`，等待安装完成。
2. 打开网页版小手机，进入“微信 → 我 → 服务 → 智能家电”。
3. 点“生成十位配对码”。
4. 在电脑助手里输入这十位数字，点“寻找灯具并让它闪烁”。
5. 亲眼确认闪烁两次的是自己的灯，再点“是，这是我的灯”。程序会固定该灯的唯一指纹。
6. 助手显示“灯具已安全连接”后，回到网页点“重新读取真实状态”。

安装后助手会随 Windows 登录自动运行。日常使用时电脑必须开机，电脑和灯必须连接同一路由器；手机和网页可以使用别的网络。

## 明确限制

- 当前只支持并验收苹果手机、苹果“家庭”App 和 HomeKit；安卓暂不在支持范围内。
- 可优先购买开发者已经实测的淘宝候选商品：<https://item.taobao.com/item.htm?id=628614473300>；也可以自行搜索，但自行购买的其他型号不保证能被当前 Windows 助手识别。
- 当前只验收并开放完整型号 `MSL430`，不能把外观相似或其他型号当作已兼容。
- 一盏灯的唯一指纹只能绑定到一个网页家庭；首次绑定必须由用户观察实际闪烁后确认。
- 只允许开灯、关灯、亮度、RGB 颜色和色温。
- 每次动作后必须重新读取灯具；读回不一致、电脑离线、灯离线或超时都会报告失败。
- 不读取或保存 Wi-Fi 密码、HomeKit 配对码和二维码。
- 原 Meross App、HomeKit 和灯具按键仍可正常使用。

## 卸载

在 Windows“已安装的应用”中卸载“小手机智能家电助手”。卸载只删除电脑助手及本机绑定，不影响灯具、HomeKit 或 Meross App。
