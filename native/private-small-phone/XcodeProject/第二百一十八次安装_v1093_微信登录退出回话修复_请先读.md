# 第二百一十八次安装：v1093 微信登录退出回话修复

- 网页版本：v1093
- 私人 iOS：1.0.218（218）
- 原生桥：25

本版只修正微信登录完成后的回话送达链路，并完整保留 v1092 已有功能：

1. 退出后的角色回话按最后一条用户消息所在渠道返回。最后在线上微信聊天，就回线上；最后在共同生活，就回共同生活。
2. 共同生活开关开启不再自动抢走线上发起的登录结果。
3. 线上退出事实直接进入可靠回复调度，减少短时内存定时交接造成的丢失窗口。
4. 模型只说“看完了／改好了”等操作话时，最多做一次真实模型纠正；纠正失败但原话可见时保留真实原话，不制造固定角色台词。
5. 隐藏的心情、记忆和操作标签不算已经回复，必须真实新增一条用户能看到的角色消息才算送达。

Windows 已执行自动化与包结构校验，但不能替代 Mac 编译、签名和真实 iPhone 验收。安装后请重点测试一次“共同生活开启、最后在线上聊天、角色登录微信并退出”的完整一分钟流程。
