# 第一百五十三次安装：v1032 微信聊天视觉升级

## 版本

- 网页：v1032
- 私人 iOS：1.0.153（153）
- 原生桥：25
- 建议全新工程目录：`SmallPhone_v1032_WeChatChat_iOS153`

## 本包包含

- 当前线上真实外卖、角色钱包与完整结账连接器基线。
- 微信首页与聊天页的白天／夜间双模式、固定磨砂顶栏、透视底栏和置顶行色差。
- 微信底栏与聊天输入栏图标统一缩小、描边与居中；不模拟消息红点。
- 聊天表情面板和两页功能面板；第二页四项均匀分散并保持与第一页一致的间距。
- 角色消息下方时间仅隐藏显示；聊天中间时间保留数字并移除黑色块，不改动角色或聊天数据。
- 线下“让TA回”移至右上方并缩小，避免输入区域误触。

## Mac 编译与覆盖安装

1. 解压唯一 ZIP，将顶层文件夹放到 Mac 全新目录，不要覆盖旧工程。
2. 打开 `PhoneCompanionTest.xcodeproj`，检查开发者账号、Team、Bundle ID、签名证书和描述文件。
3. 依次确认五个 Target 可正常编译，然后安装到已有私人 App 的同一台 iPhone。
4. 使用相同 Bundle ID 直接覆盖安装，不要卸载旧 App，以保留本机聊天、图片、角色和外置语音配置。
5. 打开设置核对：网页 v1032／私人 iOS 1.0.153（153）／原生桥 25。

## 真机验收

1. 切换微信白天与夜间模式，检查固定磨砂顶栏、透明底栏、置顶行和缩小后的图标文字。
2. 打开任一角色聊天，检查磨砂标题、心情标签、输入栏三个等大图标与居中的加号十字。
3. 打开“+”面板并左右滑动，确认两页无跳动，第二页四项均匀分散。
4. 长列表上下滚动并反复开关表情、功能面板，确认标题不滚走、页面不跳顶且操作顺畅。
5. 抽查原有聊天、朋友圈、普通角色回复、外置语音、真实外卖与角色钱包没有回归。

Windows 自动复核 938/938 通过；仍须在 Mac 编译、签名并用真实 iPhone 覆盖安装验证。
