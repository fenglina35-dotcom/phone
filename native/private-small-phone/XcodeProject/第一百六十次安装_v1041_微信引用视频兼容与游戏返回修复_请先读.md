# 第一百六十次安装：v1041 微信引用、视频兼容与游戏返回修复

## 本次版本

- 网页：v1041
- 私人 iOS：1.0.160 (160)
- 原生桥：25
- 工程目录：`SmallPhone_v1041_QuoteVideoGame_iOS160_MacReady`

## 安装前

1. 不要覆盖旧工程目录，请把本次 ZIP 解压到一个全新目录。
2. 在 Mac 上打开 `PhoneCompanionTest.xcodeproj`。
3. 选择你原来使用的私人 Target、Team 和签名配置；不要更换 Bundle ID，也不要删除现有证书。
4. 本包是 Windows 生成的 Mac-ready 源码包，不是已经签名的 IPA，也没有在 Mac 上完成编译。

## 本次核对重点

- 在微信聊天里引用一条消息后，引用条位于输入框下方，可用右侧按钮取消；发送后引用内容显示在消息气泡下方。
- 引用存在时，“让TA回”固定在输入区上方，不遮挡系统键盘和底部四个输入按钮。
- 白天、夜间主题下引用条、气泡与磨砂输入栏均能正常显示。
- 安卓浏览器的两小时视频播放失败时只自动兼容重试一次，并给出准确的编码提示。
- 微信发现进入游戏大厅、再进入电子宠物后，可以依次返回游戏大厅和发现页，不发生循环。

## 数据安全

- 覆盖安装不会主动清理聊天、角色、真实好友、本地图片或外置语音配置。
- 不要卸载旧 App 后再装；请使用相同 Bundle ID 直接覆盖安装。
- 若 Xcode 要求迁移签名或 Bundle ID，请先停止，不要随意创建新的应用身份。
