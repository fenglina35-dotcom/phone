# 第一百九十六次安装：v1072 私人 App 形象工作室与外卖稳定版

本次版本：

- 网页核心：v1072
- 私人 iOS：1.0.196（构建 196）
- 原生桥：25

## 本次更新

1. 角色形象工作室的面部参考与衣柜均改为整齐双列卡片，识别长文收进详情，不再占满页面。
2. 上传固定脸并允许露脸后，普通人物照片必须保持同一张脸且清楚可辨；手机、手、头发、阴影和其他物品可以自然出现，但不能遮住关键五官。
3. 只有提示同时明确“全身”和“对镜”时，角色才可以偶尔用手机自然挡脸；半身对镜和其他人物照片仍必须露脸。
4. 测试生图不再被旧的纯场景或固定挡脸提示词覆盖；明确只拍场景、物品、食物或宠物时仍不会擅自加入人物。
5. 网页版补回可见电量位置；浏览器支持 Battery API 时会在恢复前台后刷新真实值，不支持时明确显示“不支持”，不伪造电量。私人 App 继续使用原生状态栏。
6. 外卖搜索、商品续选和角色交接任务的匹配与幂等保护继续同步到私人 Bundle，减少错误停止、旧消息重启和重复加购。
7. 私人包继续从磁盘完整递归收录实际 `PhoneWeb.bundle`，包含个人微信页和二维码离线依赖，避免遗漏被 Git 忽略但运行必需的文件。

## Mac 安装

1. 把整个 ZIP 复制到 Mac 后完整解压到全新目录，不要直接在压缩包里打开，也不要覆盖旧工程目录。
2. 打开 `PhoneCompanionTest.xcodeproj`，选择自己的 Team 和真实 iPhone。
3. 执行 Product → Clean Build Folder，再编译运行。
4. 覆盖安装后打开版本页，必须显示 `v1072 / 1.0.196 / 原生桥 25`；若仍显示 v1071 或 1.0.195，说明运行的仍是旧包。
5. 不要先删除旧 App；覆盖安装才能保留原手机数据。安装前仍建议先导出备份。

## 真机验收顺序

1. 打开普通微信、朋友圈、后台通知和外置语音设置，确认原有真实模型回复与语音配置仍在。
2. 打开角色形象工作室，确认面部参考与衣柜是双列卡片，详细识别文字仅在点开后出现。
3. 用固定脸生成普通人物照，确认脸部清楚且没有机械手机挡脸；再用“全身对镜照片”确认手机可以自然入镜但不是每次都强制挡脸。
4. 打开外卖并完成一次不付款的购物车流程，确认角色续选、搜索和规格处理没有停在旧任务。
5. 检查共同生活、通话、远控字幕、真实电量／位置／健康／屏幕时间和共同相册。
