# 第一百三十四次安装：v1013 内置语音、伴生关怀与远控稳定修复

版本核对：网页 v1013；私人 iOS 1.0.134 (134)；原生桥 25。

请完整解压 `SmallPhone_v1013_InternalVoiceCompanionStability.zip` 到一个全新目录。不要覆盖 v1012 或任何旧工程，也不要把旧工程中的 `PhoneWeb.bundle`、Swift 文件或配置复制进来。

在 Mac 上打开全新的 `SmallPhone_v1013_InternalVoiceCompanionStability/PhoneCompanionTest.xcodeproj`，选择 `PhoneCompanionTest` Scheme 和真实 iPhone，先执行 `Product → Clean Build Folder`，再编译安装。若设置页版本不是 v1013／1.0.134 (134)，立即停止，说明打开的不是本次工程。

本版按以下顺序真机验证，每项只验证一次：

1. 不修改现有外置语音配置，先让原来正常的外置语音说一句，确认仍有声音。
2. 打开“AI账户”，选择一个内置音色并点“测试内置语音”，确认页面显示内置测试成功并播放声音，不再出现“没有拿到语音”。
3. 再回到角色聊天测试外置语音，确认地址、Key、模型和音色均未被内置测试覆盖。
4. 在内置语音开关关闭和开启两种状态各核对一次：关闭时角色继续走外置，开启时角色使用所选内置音色。
5. 说一次明显难过的话，确认角色可触发新的心率读取；若角色明确怀疑隐瞒，也只把心率当关心线索，不得据此断言说谎。
6. 进行一次远控，确认打开、查看和执行时有阶段字幕，同一页面不会反复刷新。
7. 确认 v1012 已真机成功的朋友圈真实回复、后台通知、共同相册和外置语音没有回归。

Windows 自动回归 891/891、脚本语法和 ZIP 结构校验均不能替代 Mac 编译、Apple 签名及真实 iPhone 验收。
