连接这一台电脑

  1. 确认电脑和灯连接同一个私人家庭路由器。
  2. 网页打开“服务 → 智能家电”，生成十位配对码。
  3. 输入配对码后，观察哪一盏灯连续闪烁两次。
  4. 只有确定是自己的灯，才点击确认。
