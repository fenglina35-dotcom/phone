# v1191 网页监管触发修复

2026-09-06。用户报告聊天监管、选中抖音的软件监管均未收到消息。本次只发布网页；用户明确暂不提交私人版本，私人仍为 v1190 / iOS 1.0.316 (316) / 原生桥 35，不包含本次修复。未改动私人工程、内置资源或旧源码包。

## 已复现的原因与改动

旧聊天末条为 user、普通主动消息安静状态和遗留队列记录会永久阻挡监管事件。监管改用真实回复生成、通话、查手机和伴侣共同活动等必要互斥，不再借用普通主动消息的全部门禁。模型返回超过三行或心情标签与正文同行时，旧实现会丢弃有效回复；现在移除已知心情元数据并接收最多十条有效正文，仍拒绝操作标签、出戏内容，不伪造失败回复、不自动重试。普通主动消息的相似度过滤不再用于这个新的已观察事件。

前台短暂渲染阻塞不再按五秒窗口重置停留。未达到随机阈值就离开仍不触发；达到阈值并开始生成后允许离开原页面，角色只根据“刚才”的事实回复。关闭再打开权限也会撤销旧授权；换绑定、账号变化、新聊天消息、跨午夜及伴侣加入共同活动仍拦截旧回复。

无法确定用户原设备命中了上述哪一种状态。计时阈值是开始请求模型的时间，消息显示还需模型响应时间。没有新增用户可见系统提示，未读取另一个角色的聊天正文。
