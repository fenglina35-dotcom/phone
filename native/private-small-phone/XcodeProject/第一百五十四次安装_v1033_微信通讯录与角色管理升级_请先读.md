# 第一百五十四次安装：v1033 微信通讯录与角色管理升级

## 版本

- 网页：v1033
- 私人 iOS：1.0.154（154）
- 原生桥：25
- 建议全新工程目录：`SmallPhone_v1033_WeChatContacts_iOS154`

## 本包包含

- v1032 微信首页与聊天页的白天／夜间模式、固定磨砂顶栏、透视底栏和聊天输入区视觉。
- 通讯录固定磨砂标题与搜索区、A–Z 联系人索引，以及新朋友、仅聊天、群聊、标签四个真实可点击入口。
- 小手机原有好友与角色联系人均保留，并按联系人分类显示；顶栏小人按钮与微信“+”菜单的添加朋友入口互通角色编辑页。
- 仅聊天名单支持选择、添加和移出；通讯录标签支持新增、编辑、选择成员与删除。
- 发起群聊支持搜索、选择已有群、面对面建群和选择群聊中的朋友；不包含企业微信联系人入口。
- 微信“+”菜单可重复展开和收起，保留发起群聊与添加朋友；聊天心情与“让TA回”只保留小气泡，不增加灰色长条。

## Mac 编译与覆盖安装

1. 解压唯一 ZIP，将顶层文件夹放到 Mac 全新目录，不要覆盖旧工程。
2. 打开 `PhoneCompanionTest.xcodeproj`，核对开发者账号、Team、Bundle ID、证书与描述文件。
3. 编译全部 Target，并使用与旧私人 App 相同的 Bundle ID 覆盖安装；不要卸载旧 App。
4. 打开设置核对：网页 v1033／私人 iOS 1.0.154（154）／原生桥 25。

## 真机验收

1. 在微信通讯录长列表滚动，确认标题和搜索区固定、磨砂层不跳动，A–Z 索引可定位联系人。
2. 逐一打开新朋友、仅聊天、群聊和标签，验证新增、选择、移出、删除与返回均有效。
3. 从通讯录右上角和微信首页“+ → 添加朋友”分别进入角色编辑页，确认保存后原角色与小手机好友未丢失。
4. 切换白天／夜间主题，检查菜单、全屏子页、联系人列表与底栏颜色融合。
5. 抽查原有聊天、角色回复、朋友圈、后台通知、外置语音、真实外卖与角色钱包没有回归。

Windows 自动复核完成后仍须在 Mac 编译、签名，并用真实 iPhone 覆盖安装验证。
