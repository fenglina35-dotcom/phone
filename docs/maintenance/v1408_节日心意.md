# v1408 节日心意

- `HOLIDAYS` 之外新增 `LUNAR_FESTIVALS`（除夕、春节、元宵、端午、七夕、中秋，2025–2028）。`holidayOf` 两边都查，日历上也会显示这些农历节日。
- `checkCalendar`：
  - 不再让其他角色过节发祝福（原来的 `holidayGreet` 已不再调用）。
  - 情侣角色改走 `holidayCare`。
  - 纪念日标题带「生日」的，按生日来过。
- `holidayCare`：
  - 一定祝福，不允许 [保持安静]。
  - `holidayCareImportant` 判断为重要的日子（情人节、520、七夕、春节、除夕、中秋、圣诞、生日）一定要送 [送礼] / [红包] / [转账] 里的一样或两样；其余节日送不送由角色自己决定。
- `holidayCareWindow` 决定什么时候发：除夕、平安夜在 18 点后，跨年在 21 点后；重要节日 0:00–1:30 或 7:30 以后；其余节日 7:30 以后。
- 情侣角色的提示词：当天写明「记得这个日子」，并列出未来 3 天内的节日（`holidayUpcoming`）。
- 换背景：
  - `wechatBgRequest` 只认明确的要求（动词紧跟「背景」，或者「背景换成这张」），说的是照片里的背景不算。
  - 角色写了 [换背景] 但她这一轮没明确要求（`_wantBg` 为假）时直接忽略。
  - 提示词写明「只发照片不是让你换背景」。
- 桌面宠物设置页去掉名字下面那行说明。
- 验证：
  - 用模拟模型接口测了七夕：情侣角色发了祝福、520 红包和礼物，其他角色没有消息，同一天不重复发；劳动节的提示写的是送不送随意。
  - 只发图片时角色写 [换背景] 不会生效，明确说了才换。网页版和私人版都测过。
