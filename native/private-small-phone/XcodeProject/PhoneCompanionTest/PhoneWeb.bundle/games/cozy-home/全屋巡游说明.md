# 全屋巡游 v002

独立测试副本，原 v001、房屋正式网页、小手机和人物定稿未覆盖。存档使用 cozy-actor-test3- 前缀。

人物约 1.8m，玩家站立视点 1.50m。观察跟随相机仅用于诊断，关闭跟随后回到第一人称。

路线采用楼层与台阶高度检查：主层、书房过道、折返楼梯、地下工作室、玩偶小室；出口仍锁闭。门扇打开之后参与寻路碰撞，NPC 到门前手动发起开门动作。

随机巡游通过右侧按钮开启/关闭；关闭后会完成当前动作再停止选择新目标。每次到达后停留约 3—7 秒，随机选择其他房间，也可能操作附近已有灯或柜门。此功能是本地随机测试，不是真实语言模型。正式语言模型接入后关闭随机巡游，由模型通过同一接口决策。

近距离注视：仅约 2.5m 内、正前方 120 度视野，缓慢低头与小幅侧看；背后不追踪，走远恢复。睡眠、坐卧过渡、开门时不抢占头部动作。眼睛通过已有头部父子绑定跟随，避免重复旋转造成五官错位。

模型接口 window.cozyCharacter.command()：
- go_room: target 为 living/kitchen/bedroom/bath/office/hall/basement/cell。
- walk_to: x/y/z，其中 y 为 0 或 -3.15；路线自动经过台阶。
- control: target 从 targets().controls 获取，on 指定 true/false。支持房间主灯、独立灯、已有可开合柜门抽屉和冰箱门、电视、书房电脑。先抵达物件旁再执行，状态未改变会报告失败。
- set_door: target=bedroom/bath/office/stairs/cell，open=true/false。
- roam: active=true/false。
- 原 sit/sleep/get_up/expression/talk 保留。

座位已经扩展，详见 双人座位说明.md。门把手与柜把手尚未做精确手指接触；楼梯暂沿原走路动作移动。真实 iPhone 流畅度尚未验收。
