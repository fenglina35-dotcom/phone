# 像素少女素材加载修复（未发布）

范围：两边共有。基线网页/私人内置 v1212；游戏改动仅为下一版候选资源，尚未完成整批版本统一、提交、打包或推送。公开 North 迁移和快捷指令草稿另行维护，不能随本项未经完成就部署。

## 已核实与未核实

用户截图的“素材暂时没打开，刷新页面再试一次”来自 game.js 启动 catch。它只能证明启动失败，不能证明 Android 兼容性就是唯一原因。衣柜 data.js 为 24,099,049 字节，首次网络加载与解码存在成本。

真实旧 SW 在游戏缓存 open/match/put 失败时会拒绝整次请求；即使图片或脚本已从网络成功返回，put 配额错误仍导致资源加载失败。故障测试旧代码对应 3 项失败。旧图片加载硬依赖 image.decode，缺失此 API 的测试同样失败。不能用这些隔离复现冒充已复现用户那台手机。

## 修复与影响面

- 仅游戏路径的 SW 缓存变为可选：缓存不可用仍尝试网络；缓存写入不阻塞有效响应；真实网络失败继续失败，不返回小手机主壳。缓存键保留资源版本查询参数。
- 房间和衣柜共享素材加载器：脚本、图片具有超时和资源名错误信息；图片使用 onload/onerror，不硬依赖 decode；衣柜解码并发限制为 3；离屏画布无法使用时仅该游戏回退到 DOM canvas。
- 24 MB 衣柜数据改为启动时动态加载，界面能显示加载阶段；失败提供明确重试按钮。没有改变素材图像、模型选衣规则、衣柜微调、游戏存档格式或原生桥权限。
- 原生 file:// 继续用原本的 PNG base64 素材脚本，且保持串行，不并发污染共用的临时图片槽。
- 房间重试通过已鉴权的父入口 restart 建立新 token/保存序号，不直接重载旧 iframe。新增测试先模拟旧保存序号 50，确认直接 reload 会令后续照片未保存；修复后照片在父存档真实存在。旧 iframe 的迟到消息仍不能写入新会话。
- 衣柜独立页面没有父游戏存档序号，因此其失败重试只重载自身，不清除已保存衣柜。
- 公私游戏运行文件同步；旧 P82 导入脚本的加载模板同步，但没有重新运行导入器覆盖用户衣柜参数。

## 验证

- tests/pixel-home-loading.test.mjs：缓存 open/match/put 异常、离线缓存命中、真实网络失败、缺失 decode、图片失败/超时、解码并发、画布回退。
- scripts/check_pixel_loading.cjs：网页和私人实际入口，禁止 Service Worker 以便准确注入网络故障（SW 单独测试）；失败后重建游戏会话、缺失 decode/OffscreenCanvas、11 套衣柜、原配置保留、返回、照片写入父存档；两边通过。
- scripts/check_pixel_loading_file.cjs：两套真实游戏资源 file:// 加载、画布回退、照片导出、保存衣柜重载；通过。不等于 WKWebView 真机验收。
- scripts/check_pixel_home.cjs：网页和私人各 20 项场景回归通过，包含绑定、照顾、交互与状态隔离，页面错误为 0。
- scripts/check_chat_authorized_phone.cjs：两边真实提示词构造、授权开关/原文开关/已有资料组合、输入框/手动回复、自动查看、隔离与持久化通过，页面错误为 0；模型 HTTP 为隔离响应。
- 全量 Node 测试已通过，最后记录须以发布前再次运行结果为准。没有实际 Android 手机、Mac 签名或 iPhone 安装证据。
