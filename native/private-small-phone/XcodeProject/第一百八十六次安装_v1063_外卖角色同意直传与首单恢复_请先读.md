# 第一百八十六次安装：v1063 外卖角色同意直传与首单恢复

本包版本：网页核心 v1063；私人 iOS 1.0.186（186）；原生桥 25。

## 这次更新了什么

- 修复 v1061-v1062 的首单退化：用户本回合明确说“想吃、想喝、点一份、随便点”等，当前真实角色回复“好、行、可以、等着、没问题、交给我”等明确同意语时，会立刻把同一条需求交给自动化，不再把第二次隐藏模型补动作当作唯一入口。
- 放宽自然点单表达：支持品牌加商品、只说商品、多件商品和常见口语；例如“杨姥姥家的撒汤”“点一碗兰州牛肉面”“燕麦牛奶粥+茶叶蛋”都能形成当前回合的结构化清单。
- 起送价澄清仍严格续接原 taskId：角色列出煎饺、灌汤包等同店候选时，用户点名哪项就补哪项，说“都要”才补齐本轮明确列出的全部候选，不会重建任务或重复加购。
- 普通聊天、角色明确拒绝、旧消息、页面恢复、已完成或过期任务不能借这条宽松入口新建外卖任务；同一消息重复处理也不会再次启动。
- 角色可在任意当前真实模型回合基于人设和上下文自主决定点外卖，但必须明确输出本回合结构化动作；旧消息、页面恢复和普通聊天关键词都不能偷偷新建任务。
- 普通角色回复、朋友圈回复、后台通知、远控字幕和外置语音配置保持原线路。验证码、最终付款、支付密码和生物识别仍必须由本人完成。

## 在 Mac 上安装

1. 解压 ZIP，打开包内 `PhoneCompanionTest.xcodeproj`。
2. 在 Xcode 选择你自己的开发者 Team，并确认 Bundle Identifier 可签名。
3. 用数据线连接 iPhone，选择真机后运行。
4. 覆盖安装前不要删除旧 App；正常覆盖安装会保留原有本机数据。
5. 安装后在“设置”确认显示：网页 v1063、私人安装包 1.0.186（186）。

- 这个 ZIP 是可在 Mac/Xcode 编译的完整私人源工程，不是已经签名的 IPA。
- 本次在 Windows 完成源码、自动测试和包结构检查，没有在 Mac 编译、签名，也没有在真实 iPhone 安装验证。
