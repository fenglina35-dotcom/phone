# 第二百三十九次安装：v1118 / 私人 iOS 1.0.239（239）

本版集中修复主屏交互、角色锁定标识、婚书日期、社交内容控制与外卖云端故障提示。

- 主屏仍保留原生左右翻页；只有真正长按进入拖动后才接管移动，图标可横向拖放且不会一移动就弹回。
- 角色主动锁定 App 时，锁定页标题显示实际 App 名和实际角色名；每日限额继续使用独立标题，不会混淆锁定来源。
- 顶部心情开关移到“设置 → 界面与显示 → 顶部心情”，不伪造模型没有生成的心情。
- 婚书日期支持用户自定义，角色旧记忆、旧记录或后续推测不得把用户确认的日期改回去。
- 角色朋友圈与 X 内容支持原位重新生成；明确要求“发图并配文”时会走朋友圈图文发布，没有配置生图时使用现有图文卡回退。
- 外卖设备状态的瞬时超时、502/503/504 或断网不会把已知绑定误报为未绑定；配对码只对这类瞬时故障受控重试一次。

Windows 已完成专项、全量和安装包结构校验。本机没有 Mac 编译签名环境，因此没有声称完成真实 iPhone 编译、签名或真机锁定页验收。当前外卖云端数据库仍可能返回 502；本版修正的是客户端容错与准确提示，真实配对码仍需云数据库恢复后在线复测。
