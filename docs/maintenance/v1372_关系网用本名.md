# v1372 关系网用本名

问题：关系网里微信联系人用的是我给的备注（比如「哥哥」「先生^^」）。角色看到「死对头哥哥」会以为是自己亲哥哥，备注也只是我自己的叫法。

改动：
- 新增 `relPromptName`：给角色看的名字一律用本名（联系人 `name`），人物卡用人物名，我用自己的名字。
- 提示词里的名单、详细资料、在场关系（群聊/剧场）、合并调用的「家人朋友」、线下结束回看、推荐名片后自动立关系，都改用本名；详细资料里附「ta在North微信里的备注是「X」」。
- 他微信好友列表里关系网的人显示本名，旧的按备注存的好友会自动改过来，不会多出一个。
- 角色写 `[关系|名字|±n]` 用备注或本名都能认。
- 页面（选人、关系列表、角色关系页）显示「备注（本名）」，备注和本名一样时只显示一个。

测试：tests/relation-network-v1370.test.mjs 新增本名用例；permanent-fix-guard 加 v1372。
