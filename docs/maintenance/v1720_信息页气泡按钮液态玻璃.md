# v1720 电话 → 信息页气泡和按钮用液态玻璃（网页先试）

她看完 v1718 主屏说「一点材质都不带掉」，要求把电话 → 信息（iMessage）页的按钮和小气泡也换成这个材质。

## 做法

- 沿用 v1716/v1718 那一套：一个共用 WebGL 程序画进每个元素自己里面的 `.lg-canvas`，不拍快照、不监听 DOM。
- 只在信息页**换了聊天背景**（`.imsg.hasbg`）时生效；纯黑背景没东西可折射，保持原样。
- 套用：对方/自己的文字气泡、语音条、三个点、顶部返回/视频/名字胶囊、加号、发送键、输入框。
  发出去的图片（`.pic`）和隐形墨水（`.iminv`）不套。
- 聊天背景铺在 `.imsg` 上不动，气泡跟着 `.imsg-body` 滚：滚动时只重画露在屏幕上的气泡，位置用滚动距离推算（不读布局），0.6 倍分辨率；停下 140ms 后重新量位置、原分辨率画一遍。新出现的气泡在滚动帧里直接补上画布。
- 气泡形状仍是 `scripts/glass_ring_polygon.py` 生成的 clip-path，一点没改。着色器加了：
  - `uBox`：玻璃身子在画布里的范围（尾巴那一侧让出 7px）；
  - `uRad`：四个角分开的圆角（尾巴那个角是直角）；
  - `uTail`：尾巴那 10px 只铺背景、不弯、不加环光，否则接缝处会冒出一道线；
  - `uShade`：把 `.imsg.hasbg:before` 那层上下压暗也算进去，玻璃里和外面的背景对得上。
- 信息页字是白的，身子固定偏深（对方气泡/按钮染深灰），自己的气泡和发送键染 iMessage 蓝。
- **踩过的坑**：原来那圈细高光 `:before` 带 `backdrop-filter:brightness(1.72) saturate(1.68)`，
  压在新画布上时 Chromium 把整个气泡都提亮了（clip-path 剪的环没拦住），气泡又粉又白、字看不清。
  装好画布的元素上，`:before` 去掉 backdrop-filter，只留那条白渐变细环（透明度 .62），尾巴的描边还在。
- 壁纸贴图从一张改成最多两张（主屏壁纸 + 信息页背景），来回切换不用重新读图；主屏的画法、缓存、滑动都不变。
- 设置 → 液态玻璃的开关同时管主屏和信息页。

## 没动的

私人包（PhoneWeb.bundle）、原生桥、聊天逻辑、气泡 clip-path 和环的生成脚本。
