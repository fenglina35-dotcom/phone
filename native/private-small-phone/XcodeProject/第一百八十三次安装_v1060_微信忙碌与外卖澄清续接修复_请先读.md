# 第一百八十三次安装：v1060 微信忙碌与外卖澄清续接修复

本包版本：网页核心 v1060；私人 iOS 1.0.183（183）；原生桥 25。

## 这次更新了什么

- 角色微信设置新增“忙碌状态（测试）”。开启后角色在线但不立即回复普通消息；关闭后使用真实模型和角色完整人设统一回应等待消息。
- 外卖起送价不足时，角色列出“煎饺、灌汤包”等候选后，你说具体名称只加对应商品；说“都要、两个都要、全加”才把本轮列出的候选全部加入。
- 澄清回答继续原来的 taskId、门店、主商品和进度，不重新建任务，也不会因重复处理同一条消息而二次加购。
- 普通聊天和不明确回答不会启动外卖；验证码、最终付款、支付密码和生物识别仍必须由本人完成。

## 在 Mac 上安装

1. 解压 ZIP，打开包内 `PhoneCompanionTest.xcodeproj`。
2. 在 Xcode 选择你自己的开发者 Team，并确认 Bundle Identifier 可签名。
3. 用数据线连接 iPhone，选择真机后运行。
4. 覆盖安装前不要删除旧 App；正常覆盖安装会保留原有本机数据。
5. 安装后在“设置”确认显示：网页 v1060、私人安装包 1.0.183（183）。

## 必须知道

- 这个 ZIP 是可在 Mac/Xcode 编译的完整私人源工程，不是已经签名的 IPA。
- 本次在 Windows 完成源码、自动测试和包结构检查，没有在 Mac 编译、签名，也没有在真实 iPhone 安装验证。
- 不要把你的开发者证书、密码、验证码、Cookie、支付信息或私人语音 Key 发给别人。
