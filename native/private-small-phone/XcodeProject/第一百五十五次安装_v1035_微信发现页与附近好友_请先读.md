# 第一百五十五次安装：v1035 微信发现页与附近好友

## 版本

- 网页：v1035
- 私人 iOS：1.0.154（154）
- 原生桥：25
- 建议全新工程目录：`SmallPhone_v1035_WeChatDiscover_iOS154`

## 本包包含

- 微信发现页保留朋友圈、视频号、听一听、看一看、搜一搜、附近的人和游戏；移除直播、扫一扫和小程序。
- 朋友圈与游戏使用多色线条图标，听一听使用双音符图标，搜一搜使用线条放大镜；白天与夜间主题均有对应颜色。
- 视频号连接现有短视频流；听一听、看一看、搜一搜和游戏分别连接现有音乐、放映室、浏览器与游戏大厅。
- 附近的人支持刷新匿名好友、发送真实添加申请，并在十秒后自动通过；通过后联系人进入现有好友和聊天数据。
- 角色锁定外部软件后，发现页对应快捷入口同步变灰并禁止点击。
- 共同生活的“让TA回”仅在设置收起时出现；输入框首次点击可正确获得焦点，光标不会落到输入框外。
- 不复制图片里的系统时间、网络、电量或其他 iPhone 状态栏；继续使用私人 App 自己的原生状态显示。

## Mac 编译与覆盖安装

1. 解压唯一 ZIP，将顶层文件夹放到 Mac 全新目录，不要覆盖旧工程。
2. 打开 `PhoneCompanionTest.xcodeproj`，核对开发者账号、Team、Bundle ID、证书与描述文件。
3. 编译全部 Target，并使用与旧私人 App 相同的 Bundle ID 覆盖安装；不要卸载旧 App。
4. 打开设置核对：网页 v1035／私人 iOS 1.0.154（154）／原生桥 25。

## 真机验收

1. 逐一打开发现页七个入口，确认返回路径正确、页面不跳动，白天／夜间图标清晰。
2. 在附近的人刷新后添加一名匿名好友，等待十秒，确认自动通过并出现在联系人与聊天入口。
3. 锁定音乐、放映室、浏览器、游戏或短视频后回到发现页，确认对应入口变灰且无法点击；解除锁定后恢复。
4. 展开与收起共同生活设置，确认“让TA回”只在收起时显示；首次点击输入框即可正确输入。
5. 抽查原有聊天、角色回复、朋友圈、后台通知、外置语音、真实外卖、角色钱包和小手机好友没有回归。

Windows 自动复核完成后仍须在 Mac 编译、签名，并用真实 iPhone 覆盖安装验证。
