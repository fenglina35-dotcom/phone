# v1352（网页）/ v1357（私人源码）查手机与角色发文件修复

未打包；iOS 仍为 1.0.422 (422)。

## 角色发文件掉格式
- 原因：`msgToText` 没有给角色自己的文件消息单独处理，落到了用户文件那一句“[我给你发了文件「x」，文件正文如下：…]”。角色在历史里看到自己“这样发文件”，下次照抄，`ROLE_FILE_BLOCK` 认不出，正文被按行拆成文字气泡。
- 修复：角色自己的文件回给模型时用 `[文件|名字]…[/文件]`（`roleFileHistoryText`）；`roleFileExtract` 兜底收下照抄句式（`ROLE_FILE_ECHO`）和漏写 `[/文件]` 的长正文（`ROLE_FILE_OPEN`，要求文件名带扩展名且正文 ≥120 字，一行卡片不受影响）；提示词说明两种写法的区别。

## 查手机有人成功有人失败
- 原因：一次要写很长的 JSON，却只给 `max:1200`，话多的角色或会先思考的模型写到一半被截断，4 次都解析失败；最近聊天里的转账回执以 `system` 身份夹在对话中间，部分中转接口直接拒绝；所有失败都只显示“生成失败了”。
- 修复：额度 4000；历史里只用 user/assistant；失败提示显示接口报错或“没有按格式写完/返回空内容”。

回归：`tests/role-file-and-spy-v1352.test.mjs`（旧代码 3 项全失败）；永久修复登记表新增 3 条。

## 线下约会时间戳被切掉
- 原因：`message-beijing-time.js` 只按 `role==='user'` 判断是不是“我”的消息；线下约会、共同生活、角色扮演的消息用 `who==='me'`，于是我的时间按左对齐绝对定位，从右侧气泡列往外伸出屏幕，显示成「18:2」。
- 修复：`mine()` 同时认 `role==='user'` 和 `who==='me'`；脚本地址加 `&r=offline-me-1`，热修标签改为 v1352-web-offline-time-1 / v1357-private-offline-time-1。
- 回归：`tests/message-beijing-time.test.mjs` 新增一项（旧代码失败）。
