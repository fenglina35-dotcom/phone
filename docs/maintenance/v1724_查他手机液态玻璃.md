# v1724 查他手机用液态玻璃（网页先试）

她说「还有最后一个查他手机的」。和 v1720 信息页、v1722 线下同一套，加进 `LG_SCENES` 第三条。

## 做法

- 范围：`.spy-desktop` 里所有 `.spy-glass`：密码盘 0–9、顶上返回/刷新、资料卡下半截、
  主屏两页的应用图标、底部常用栏、重置存档。资料卡封面（图片）、头像、「取消」「⌫」文字键不套。
- 背景来源：页面里 `.spy-wallpaper img`（主屏用「手机壁纸」，密码盘用「拨号盘背景」）。
  **没换壁纸时**用 CSS 那张默认渐变——`lgDefaultWall('lg:spy')` 照着 `.spy-desktop` 的
  linear(160°) + 两个 radial 画进一张 1024×2048 画布当贴图，所以不设壁纸也有折射效果。
- 主屏图标在左右翻页的 `#spyHomePages` 里：几何多记一个 `sl`（当时的 scrollLeft），
  翻页时 `ox = g.x + g.sl - sl` 推算，横向露出来的才画；上下滚 `#spyAppScroll` 同 v1720。
- 染色：原来的 `rgba(58,76,86,.28)` 灰蓝，玻璃 tint `[0.23,0.3,0.34]`、浓度 ≥ .28。
- 圆角改成四个角分别读（资料卡下半截只有底下两个角圆），百分比圆角换算成像素。
- `.spy-glass:before` 那圈细环同样去掉 backdrop-filter，只留白渐变（否则整块被提亮）。

## 没动的

私人包、原生桥、查手机权限/密码/各 App 内容、角色手机外观设置。
