# 第二百四十九次安装：v1123 私人存档安全合并版

## 安装前先保护数据

1. 不要卸载手机里现有的“小手机”，不要清理缓存，也不要退出手机号。
2. 必须使用相同 Bundle ID 覆盖安装；先卸载会删除 App 容器和本机候选存档。
3. 请把 ZIP 解压到全新文件夹后再用 Xcode 打开，不要混进旧工程。

## 本次私人 App 更新

- 本机恢复新增“以这份为主，安全合并全部角色聊天”。角色、设置、主题、组件、朋友圈和记忆以选中的完整候选为基底；其他物理副本只追加同角色 ID、同账号的微信和通话记录。
- 合并会精确区分普通微信、通话行和通话场次；没有消息 ID 的重复内容采用完整内容指纹和出现次数，不用短哈希，也不会按角色名字误配。
- 预览和最终确认各自检查后台角色新消息。核对或确认期间出现新消息会立即中止，并要求重新预览，不会静默覆盖。
- 当前真人好友聊天库和真人群聊库始终以安装前本机内容为准。外置占位库读取失败或内容不完整时会中止恢复，不会用空对象覆盖。
- 写入前保存并回读校验完整撤回快照；正式写入先保存内联完整核心，再原子写入角色、好友、群聊外置库，最后写紧凑核心。失败会自动回到恢复前状态，手动撤回也走同一持久化链。
- 保留当前 v1123 的模型路线真实诊断、外卖连续消息识别和私人 App 既有功能；公开网页版没有随本次私人修复修改。

## 在 Mac 上编译安装

1. 打开 `PhoneCompanionTest.xcodeproj`。
2. 为主 App 和所有扩展选择同一个开发者团队，并选择真实 iPhone。
3. 直接运行覆盖现有 App，不要先卸载。

## 安装后验收

1. 先确认版本显示为 v1123、私人 iOS 1.0.249（249）。
2. 打开本机恢复候选列表，确认出现“安全合并全部角色聊天”，并先只看预览。
3. 预览应分别显示普通微信、通话行、通话场次、跳过的未知角色/账号数量。
4. 确认恢复后检查当前角色聊天、通话、真人好友、真人群聊、头像、图片、朋友圈、主题和组件。
5. 在确认内容正确前不要立即覆盖云备份；如结果不对，使用“撤回上次本机恢复”。

## 验证边界

Windows 侧能够验证 JavaScript 语法、私人专项测试、两个私人入口、版本链和 ZIP 内逐文件完整性；不能代替 Mac 编译、签名和真实 iPhone 覆盖安装，也不能证明真机历史存档一定具备可合并内容。
