## 问题与根因

用户询问“表情包在哪设置”，客服回答资料没有说明。旧 `WX_HELP` 没有表情包条目，导致本地匹配失败；模型接收的同一份资料也没有实际入口。已有帮助还把模型、真图等写成已移动的平级设置，真人好友入口与创建角色容易混淆。“微信 → 我 → 表情”确实仍是动态仓库开发中说明页，不能将它写成可用素材管理。
