# v1045／私人 iOS 1.0.165（165）安装说明

请只解压并打开本次唯一目录 `SmallPhone_v1045_WeChatStepsDeliveryRoutes_iOS165_MacReady`。不要把文件零散覆盖进旧工程；覆盖安装 App 时不要先删除手机里的旧 App，以保留角色、聊天、外置语音和登录数据。原生桥仍为 25。

## 本次整合内容

- 微信聊天首页恢复“微信运动”，使用本机 DeviceMotion 记录真实步数，支持启用、停用、每日零点刷新与保存，不生成模拟步数。
- 修复一次性线下约会顶部“让TA回／结束”重叠，以及角色编辑页“角色自称”横向溢出和文字左飘。
- 通话与回放能恢复 `idb:` 本地头像、背景，不把原始存储标识当图片地址显示；真实通话和角色回复线路未改。
- 亲属卡更新为立体卡面，原额度、本月已用和绑定数据继续沿用。
- 外卖新增奶茶、主食、咖啡、KFC 四类偏好。角色只使用本人先登记过的同品牌、同商品直达路线，最多核对三家；第一家打烊会继续核对下一家，全部打烊时把真实事实交给角色自然说明。
- 店内会再次精确搜索并匹配商品，例如“生椰拿铁”不会被普通“拿铁”替代；用户当次明确说出的糖度、冰度、口味、辣度、份量和加料始终优先。
- 角色不会自动全网搜店来绕过平台验证。平台强制登录、人机验证和支付宝付款仍由本人完成；系统不会识别、代点或规避验证码。

## Mac 编译

1. 在 Mac 上完整解压本 ZIP。
2. 打开 `PhoneCompanionTest.xcodeproj`，选择私人 App Target 和你的签名团队。
3. 执行 Clean Build Folder，再编译到真实 iPhone。
4. 直接覆盖安装，不要删除旧 App。

Windows 已完成自动回归与安装包结构校验。Mac 编译、签名和真实 iPhone 验证仍须执行；真机请重点检查真实步数、通话图片、约会按钮、角色编辑布局、亲属卡，以及外卖多门店打烊与精确商品选择。
