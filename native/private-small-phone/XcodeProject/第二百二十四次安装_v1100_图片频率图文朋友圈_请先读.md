# 第二百二十四次安装：v1100 / 私人 iOS 1.0.224（224）

本版在 v1099 稳定基线上新增可选的角色图片频率与朋友圈图文照片：

- 角色设置新增“发送图片频率”，升级后默认关闭；关闭时沿用原有行为。
- 开启后可选偶尔、经常或高频，只改变角色自然配图倾向，不允许捏造没有聊过的画面。
- 已配置且可用的生图模型继续生成真实图片；没有可用生图配置时才显示白色图文照片卡。
- 没有生图配置时，自动朋友圈的图文卡判断不额外调用模型，避免浪费额度。
- 用户朋友圈可分别选择真实照片或图文照片；角色能把图文照片当作图片理解，但不能补写描述里没有的视觉细节。
- 保留 v1099 的媒体播放、微信总结、通话终止、图片恢复，以及此前的共同生活、后台消息和真实外卖边界。

Windows 自动验证和 ZIP 结构校验不等于 Mac 编译、签名或真实 iPhone 验收；仍需在 Mac/Xcode 编译，并在真机验证开关默认关闭、三档频率、真实生图与图文卡两条路径。
