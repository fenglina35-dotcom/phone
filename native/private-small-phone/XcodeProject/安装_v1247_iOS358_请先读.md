# 小手机 v1247 / iOS 1.0.358（358）安装与验收

这是 Mac 待编译的私人源码覆盖包，不是 IPA。公开网页同步为 v1247（共同生活回复长度独立可调）；私人内置源码只同步了 v1246（共同生活旁白截断修复）和本次这两处最小必要改动，其余业务字节仍是 v1242 基线，不含 v1241/1244 期间网页单独发布过的其他修复。

## 本次改了什么

1. **共同生活旁白截断修复**（沿用自 v1246）：角色回复被模型输出长度截断时，最后一句如果正好是旁白（以【、（或(开头但没有等到闭合括号），以前会被当成普通台词、连同没闭合的括号一起显示成对话气泡；现在会正确识别为旁白并去掉多余的开头括号，不需要重新生成。

2. **共同生活/线下回复长度改为可以自己调，且跟线上聊天分开**：以前共同生活和线下约会的回复输出上限写死在代码里（600/650/700 tokens，按你消息长短自动挑），跟"设置 → 聊天模型"里的"回复长度"完全无关，调那个设置对共同生活没有任何效果，这也是回复经常被截断的一个主要原因。现在设置页里新增了一个单独的"回复长度（共同生活/线下）"输入框，跟原来的"回复长度（线上聊天）"各管各的，互不影响；共同生活/线下的实际输出上限取"按消息长短自动算出的基础值"和"你在这里填的数字"两者中较大的一个，你可以按需要往大调，不会因为调线上的而影响线下，也不会因为调线下的影响线上聊天。

## 安装步骤

1. 在 Mac 把压缩包解压到一个全新的目录。不要覆盖旧工程目录，也不要先删除 iPhone 上的旧小手机。
2. 打开 `PhoneCompanionTest.xcodeproj`，沿用原 Apple Account、Team、Bundle ID、签名和现有 entitlement（HomeKit、Screen Time、通知等不受影响）。
3. 核对所有 Target 的 Marketing Version 均为 `1.0.358`，Build 均为 `358`，原生桥契约仍为 `38`，然后覆盖安装到真实 iPhone。
4. 打开"设置 → 授权与数据"，核对版本显示为私人 `1.0.358 (358)`。

## 验收

- 打开"设置 → 聊天模型"，确认能看到两个独立的"回复长度"输入框，一个标"线上聊天"、一个标"共同生活/线下"，两个数字分别保存、互不覆盖。
- 把"回复长度（共同生活/线下）"调大一些（比如 1200），在共同生活里多聊几轮，看长回复被截断的频率是不是明显变少了。
- 完整闭合的旁白（【……】）继续按旁白样式显示；如果真的还是被截断，应该按旁白样式显示且开头不残留孤零零的【。
- 普通线上微信聊天不受影响，回复长度仍按"线上聊天"那个数字。

Windows 上已跑过全量自动化回归（除两项与本次改动无关的既有环境限制外全部通过）以及新增的单测；Mac 编译、签名和真实 iPhone 上的实际验收仍待完成，不能据此直接称真机已经修好。
