# 第三百零三次安装：v1177 主动消息与外卖单品清单修复

本包对应网页与私人版共同发布：网页源码为 v1177，私人内置页面为 v1177，私人 iOS 为 1.0.303 (303)，原生桥 35。请完整解压到新的目录后再用 Xcode 打开，不要覆盖或混用旧工程、旧 ZIP、旧 DerivedData 中的产物。

## 这次改了什么

- 普通主动消息同步结构化近期角色消息和已完成轮次边界，云端兼容当前中文日期格式，并优先使用更新的文字记录。已经被角色回复过的上一句不会再次作为主动消息的待回复内容。
- 普通主动任务如果模型仍只返回重复补答，最多再进行一次真实模型纠正；仍重复时保持静默并等待下一次正常计划，不用固定文字冒充角色。
- `reply_handoff` 仍保留真实未完成用户轮次的回复接力，不能被普通主动消息的去重复规则误伤。
- 共同生活按每条用户消息保存发送时选择的对象，整轮提示、第一回答者和后续演员顺序都绑定该快照。发送后切换下拉选择不会改变已经开始的这一轮。
- 被点名角色已离场时会显示明确提示，不会静默改由主角回答。原顺序继续保持：对配角说时配角先、主角后；对主角或所有人说时主角先、配角后。
- 真实外卖把明确的肯德基单品清单逐项搜索、逐项加入；不会自动改成四件套、多人套餐或重复同类。单点蛋挞在有可靠价格证据时选择合格单品中的最低价；无法确认单品时停止，不模糊代选。
- 网页与私人 Bundle 同步包含以上改动，并完整继承 v1176 的多人剧场署名、顺序、退场记忆、粤语翻译、HomeKit 直连和拦截记录入口。

## Mac 覆盖安装

1. 把 ZIP 完整解压到全新目录，不要直接在压缩包内打开工程。
2. 打开 `PhoneCompanionTest.xcodeproj`。
3. Target 版本必须显示 1.0.303、Build 303；签名使用原来的 Team 和 Bundle Identifier。
4. 不要先删除手机上的旧 App，直接对原来同一台 iPhone 执行 Run，以保留现有数据容器。
5. 启动后在版本页核对：网页核心 v1177、私人 iOS 1.0.303 (303)、原生桥 35。

## 本次重点验收

1. 在前台正常回复一句后等待普通主动消息，确认它不会重新回答上一句；再验证一次 App 真正中断的未完成回复仍可由 `reply_handoff` 接力。
2. 在共同生活选择“对 B 说”并立即切换选择框，确认已经发送的这一轮仍由 B 先回答，主角后回答；若 B 已离场，应提示目标离场而不是改成 A。
3. 明确要求肯德基汉堡、薯条、蛋挞、鸡翅，确认每项只加入一个对应单品，没有四件套、多人套餐或同类重复项；找不到确切单品时应停止。
4. 复核多人剧场关闭后的双人显示、历史配角署名、微信来客退场记忆与来信、粤语逐句普通话翻译、智能家电 HomeKit 直连和三个“查看上一轮拦截内容”入口。

当前只完成 Windows 代码、自动测试与源码 ZIP 内容检查；尚未在 Mac 编译、签名、覆盖安装，也尚未在真实 iPhone 验证主动消息、共同生活对象绑定或真实外卖下单。
