# 第一百八十四次安装：v1061 外卖同意直传与角色自主发起修复

本包版本：网页核心 v1061；私人 iOS 1.0.184（184）；原生桥 25。

## 这次更新了什么

- 用户已经明确说想吃什么后，角色在当前真实模型回合回复“好、行、可以、等着”等明确同意，却漏掉结构化外卖动作时，系统只做一次隐藏的真实模型动作补判；确认同意后立即把同一回合要求交给外卖自动化，不需要用户再说第二遍。
- 起送价澄清仍优先续接原 taskId：角色列出煎饺、灌汤包等候选时，用户点名哪项就补哪项，说“都要”才补齐本轮明确列出的全部候选，不会重建任务或重复加购。
- 角色可在任意当前真实模型回合基于人设和上下文自主决定点外卖，但必须明确输出本回合结构化动作；旧消息、页面恢复和普通聊天关键词都不能偷偷新建任务。
- 普通角色回复、朋友圈回复、后台通知、远控字幕和外置语音配置保持原线路。验证码、最终付款、支付密码和生物识别仍必须由本人完成。

## 在 Mac 上安装

1. 解压 ZIP，打开包内 `PhoneCompanionTest.xcodeproj`。
2. 在 Xcode 选择你自己的开发者 Team，并确认 Bundle Identifier 可签名。
3. 用数据线连接 iPhone，选择真机后运行。
4. 覆盖安装前不要删除旧 App；正常覆盖安装会保留原有本机数据。
5. 安装后在“设置”确认显示：网页 v1061、私人安装包 1.0.184（184）。

## 必须知道

- 这个 ZIP 是可在 Mac/Xcode 编译的完整私人源工程，不是已经签名的 IPA。
- 本次在 Windows 完成源码、自动测试和包结构检查，没有在 Mac 编译、签名，也没有在真实 iPhone 安装验证。
- 不要把你的开发者证书、密码、验证码、Cookie、支付信息或私人语音 Key 发给别人。
