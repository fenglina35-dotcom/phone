# 第一百八十一次安装：v1058 共同生活、存储散热、转账回复与约会输入修复版

## 版本

- 网页核心：v1058
- 私人 iOS：1.0.181（181）
- 原生桥：25
- 工程：`SmallPhone_v1058_CohabStorageTransferOfflineInput_iOS181_MacReady`

## 安装前

1. 把压缩包完整解压到一个全新目录，不要覆盖旧工程。
2. 保留旧 App 和旧工程，确认新版数据、聊天和语音配置正常后再处理旧版本。
3. 这是 Windows 生成并检查过结构的 MacReady Xcode 源码包，不是已经签名的 IPA。

## 在 Mac 上编译

1. 用当前正式版 Xcode 打开 `PhoneCompanionTest.xcodeproj`。
2. 在 Signing & Capabilities 中选择你自己的 Team，并确认 Bundle Identifier 可用。
3. 选择真实 iPhone，执行 Product → Clean Build Folder，再执行 Build / Run。
4. 系统询问通知、相机、麦克风、定位或家庭控制权限时，按实际需要授权。
5. 覆盖安装后核对：网页核心 v1058、私人 iOS 1.0.181（181）、原生桥 25。

## 必验项目

- 共同生活：开关重进后仍保存；在家和上班状态都能点返回、进入、测试状态；按钮不会整页失灵。
- 主动来电：未收到当前明确命令时角色不能自主打来；明确要求打电话后由真实模型决定打或不打。
- 温度与图片：连续打开主页、切换页面和恢复前台，图标不成片空白，点击不锁死，手机不持续异常升温。
- 存储：私人版不再把网页局部存储配额写成手机总空间快满；不要为此清缓存或卸载。
- 微信转账：收下和退还只结算一次、只改原卡片；角色结合真实上下文自然回应，不出现固定假话或重复卡片。
- 线下约会：输入超过两行会自然增高，光标高度正常，超过三行只在输入框内部滚动，聊天内容不被覆盖。
- 回归保护：普通角色回复、朋友圈、后台通知、远控字幕、真实外卖和已保存的外置语音 Base URL、Key、模型、音色均保持原样。

## 重要边界

- Windows 不能完成 Xcode 编译、签名或真实 iPhone 安装。本包只有源码、自动测试和结构检查通过，必须在 Mac 和真机完成最终验收。
- 不要为了安装清空 App 数据，也不要拿旧 Bundle 覆盖本包的 `PhoneWeb.bundle`。
